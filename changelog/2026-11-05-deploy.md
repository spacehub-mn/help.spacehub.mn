«Гэрээ шалгах» тоолуур, үнийн түүхийг шалгадаг болсон. AI Туслах гэрээг дугаараар хайна. Хуваарь, тоолуур, талбайн хэд хэдэн алдааг хаасан.

<!--truncate-->

### ✨ Шинэ
- **AI Туслах** — гэрээг дугаараар нь хайж олно. → [AI Туслах](/owner/ai-tuslah)
- **Гэрээ → «Гэрээ шалгах»** — тоолуурын заалт, тоолуур солилтыг шалгадаг болсон. Үйлчилгээний үнэ 0 байсан хугацааг ч заана. Сүүлийн 13 сарын толгой «YY.MM» хэлбэртэй болсон. → [Гэрээ шалгах](/owner/geree-shalgah)

### ✏️ Өөрчлөгдсөн
- **Алдангийн тохиргоо** — талбарын нэрс бүгд монгол, товч болсон. → [Алдангийн тохиргоо](/owner/aldangi-tohirgoo)
- **Гэрээ → «Драфт шинэчлэх»** — товчны мөрөнд нэрээрээ харагдана. → [Гэрээ](/owner/list/Contract_ListView)
- **Е-баримт → «Е-баримт буцаасан»** шүүлт баримтын төлвөөр шүүдэг болсон. → [Е-баримтын нөхцөл](/owner/concepts/e-barimt-nohtsol)
- Товчны тайлбар, алдааны мессежээс хуучин англи нэрс хасагдсан.
- **Гэрээ → «Е-баримт зөвшөөрөх» / «Е-баримт хориглох»** — асуулт, баганын нэр кирилл болсон. → [Гэрээ](/owner/list/Contract_ListView)
- **Нэхэмжлэхийн загвар** — байгууллага бүр өөрийн нэхэмжлэхийн загвартай болж болно. Бусад байгууллагынх өөрчлөгдөхгүй. → [Өөрийн нэхэмжлэхийн загвар](/owner/nehemjleh-tamga#oorin-zagvar)

### 🛡 Хамгаалалт
- **Тооцоотой сарын хуваарь** — гэрээ хадгалахад ч тооцоо гарсан сарын хуваарийн огноог шилжүүлэхгүй. → [Тодорхойлолт · Хаалт · Сунгалт](/owner/list/ContractSubLists)
- **Нэг сард нэг хуваарь** — гэрээнд давхцсан хуваарь хадгалагдахгүй. → [Төлбөрийн хуваарь](/owner/list/ContractPaymentChart_ListView)
- **Тоолуур солих** — шинэ тоолууртай сард хуучин тоолуурын эцсийн заалтаар хадгалахыг хаана. → [Тоолуур ашиглалт](/owner/list/ContractUtility_ListView)
- **Харагдахгүй харилцагч** — тийм харилцагчийн төлөлтөд е-баримт гаргах цонх нээгдэхгүй. → [Төлөлт](/owner/list/Sale_ListView)
- **Аппын нэвтрэлт** — буруу нууц үгийг олон удаа оруулбал түр хаагдана. → [Эрхгүй, нэвтэрч чадахгүй](/owner/erhgui-nevtreh)

### 🐞 Засагдсан
- **Гэрээний карт → «Талбай»** — талбай хасахад алдаа гардаг байсныг засав. Хассан өрөөний үйлчилгээ дахин асахгүй. → [Гэрээний талбай](/owner/geree-talbai)
