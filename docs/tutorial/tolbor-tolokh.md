> 📘 Сургалт · 🏠 Түрээслэгч, оршин суугч · Гар утасны апп · ⏱ 5 минут

```
Нэхэмжлэх харах → Төлөх → Баталгаажсаныг шалгах → е-баримт
```

## 1. Нэхэмжлэх харах
1. Олон гэрээтэй бол эхлээд гэрээний карт дээрх **⇄** дүрсээр гэрээгээ сонго. → [Гэрээ сонгох](/account/change-contract)
2. Аппын нүүрнээс **Төлбөр төлөх**-ийг дар. Төлөх нэхэмжлэлүүд жагсаалтаар гарна.
3. Нэхэмжлэл дээр дарвал **Нэхэмжлэл** дэлгэц нээгдэнэ. Задаргааг баруун дээд буланд байгаа **PDF** дүрсээр харна. → [Төлбөрийн задаргаа харах](/dashboard/payment-breakdown)
4. «Одоогоор төлөгдөөгүй нэхэмжлэл алга байна» гэж гарвал таны төлөх нэхэмжлэл алга.

## 2. е-баримтын мэдээллээ тохируулах (нэг удаа)
1. **Бүртгэл → Байгууллагын мэдээлэл** (орон сууцанд **Өрхийн мэдээлэл**) → **Хялбар бүртгэл**.
2. **Хувь хүн** эсвэл **Байгууллага**-г сонго. Аль алинд нь **регистр**-ээ заавал оруул.
3. Хувь хүн бол шаардлагатай үед **Хувь хүн татвар төлөгч (Сугалаагүй)** чагтыг тэмдэглэ.
4. Анхдагчаар төлөх бүрт **ebarimt шалгах** цонх гарна. Тэнд мэдээллээ шалгаж, өөрчилж болно.
- Захирал, нягтлан, менежер энэ утсан дээр **Төлбөр төлөх үед харуулах**-ыг унтрааж болно.

## 3. Төлөх
1. Төлөх сарынхаа **Төлөх** товчийг дар.
2. **QPay**, **Social Pay** эсвэл **Дансаар** төлнө. Дансаар бол **гүйлгээний утга**-д **гэрээний дугаар**-аа заавал бич. → [Төлбөр төлөх заавар](/)
3. Баталгаажвал «Амжилттай төлөгдлөө» гэж гарна. Төлсөн нэхэмжлэл **Төлбөр төлөх** жагсаалтаас алга болно.
4. Дансаар шилжүүлсэн бол **30 минутын** дараа шалга.

## 4. е-баримт харах
1. Нүүрнээс **Гэрээ харах** → **Төлөлт** таб.
2. Төлөлт дээр дар → **ebarimt харах**.
- Товч харагдахгүй бол баримт хараахан гараагүй байна. Баримтыг **байгууллага** гаргадаг. Өмнөх сарын баримт ихэвчлэн дараа сарын эхний долоо хоногт гарна. Удаан гарахгүй бол байгууллагадаа хандана уу.

## Асуудал гарвал
- Төлсөн ч нэхэмжлэл жагсаалтаас алга болохгүй байна — гүйлгээний утгаа шалгаад байгууллагадаа хандана уу.
- QPay харагдахгүй байна — таны байгууллага QPay тохируулаагүй байж болно. **Дансаар** төлнө үү.
- Апп алдаа заавал → [Апп ажиллахгүй үед](/app-ajillahgui)
