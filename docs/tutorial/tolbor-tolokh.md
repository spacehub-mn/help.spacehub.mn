# Нэхэмжлэх харж төлөх, баримт авах

> 📘 Сургалт · 🏠 Түрээслэгч, оршин суугч · Гар утасны апп · ⏱ 5 минут

```
Нэхэмжлэх харах → Төлөх → Баталгаажсаныг шалгах → е-баримт
```

## 1. Нэхэмжлэх харах
1. Апп-ын нүүрнээс **Төлбөр төлөх** хэсэгт ор. Олон гэрээтэй бол эхлээд **Гэрээ сонгох**.
2. **Нэхэмжлэл** хэсгээс тухайн сарын нэхэмжлэл дээр дар. Задаргааг (түрээс, ашиглалт, алданги…) харна. PDF-ийг баруун дээд буланд байгаа товчоор нээнэ. → [Төлбөрийн задаргаа харах](/dashboard/payment-breakdown)
3. «Одоогоор төлөгдөөгүй нэхэмжлэл алга байна» гэж гарвал таны төлөх нэхэмжлэл алга.

## 2. е-баримтын мэдээллээ тохируулах (нэг удаа)
1. **Бүртгэл → Байгууллагын мэдээлэл** (орон сууцанд **Өрхийн мэдээлэл**) → **Хялбар бүртгэл**.
2. **Хувь хүн**, **Байгууллага** эсвэл **Хувь хүн татвар төлөгч (Сугалаагүй)**-г сонго. Байгууллага бол **регистр**-ээ оруул.
3. **ebarimt шалгах** тохиргоо асаалттай бол төлөх бүрт энэ мэдээлэл харагдаж, шаардлагатай бол тэр дор нь өөрчилж болно.

## 3. Төлөх
1. Төлөх сарынхаа **Төлөх** товчийг дар.
2. **QPay**, **Social Pay** эсвэл **Дансаар** төлнө. Дансаар бол **гүйлгээний утга**-д **гэрээний дугаар**-аа заавал бич. → [Төлбөр төлөх заавар](/)
3. Баталгаажвал **Төлөх** товч **Төлсөн** болно. Дансаар шилжүүлсэн бол **30 минутын** дараа шалга.

## 4. е-баримт харах
1. Нүүрнээс **Гэрээ харах** → **Төлөлт** таб.
2. Төлөлт дээр дар → **ebarimt харах**.
- Товч харагдахгүй бол баримт хараахан гараагүй байна. Баримтыг **байгууллага** гаргадаг. Өмнөх сарын баримт ихэвчлэн дараа сарын эхний долоо хоногт гарна. Удаан гарахгүй бол байгууллагадаа хандана уу.

## Асуудал гарвал
- Төлсөн ч **Төлсөн** болохгүй байна — гүйлгээний утгаа шалгаад байгууллагадаа хандана уу.
- QPay харагдахгүй байна — таны байгууллага QPay тохируулаагүй байж болно. **Дансаар** төлнө үү.
- Апп алдаа заавал → [Апп ажиллахгүй үед](/app-ajillahgui)
