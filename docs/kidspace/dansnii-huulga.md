# Дансны хуулгаас төлөлт холбох — «Дансны хуулга»

> 🏢 Эрхлэгч, менежер · Вэб · Цэс: **Авто туслагч → Дансны хуулга**

## Энэ юу вэ {#ene-yu-ve}
Байгууллагын банкны дансны гүйлгээнүүд. Эцэг эхийн шилжүүлсэн мөнгийг хүүхдийн элсэлттэй холбож төлөлт болгоно.

## Хэзээ хэрэглэх {#hezee}
- Дансаар орсон төлбөрийг хүүхдэд оноох.
- Хоёр хүүхдийн төлбөрийг нэг гүйлгээгээр төлсөн бол хуваах.
- Буруу холбосон гүйлгээг салгах.

## Холболтын төлөв {#tolov}
- **Холбогдсон** — бүхэлдээ төлөлт болсон (ногоон).
- **Хэсэгчлэн** — нэг хэсэг нь холбогдоогүй.
- **Холбогдоогүй**

## Гүйлгээг автоматаар холбох {#avtomat}
1. **Авто туслагч → Дансны хуулга** цэсийг нээ.
2. **«Данс»**, **«Огноо»**-гоо сонго. **«Төлөлт»**-өөс «Холбогдоогүй»-г сонго.
3. Орлогын нэг мөрийг чагтал.
4. **«Төлөлт шалгах»** дар.

Гүйлгээний утгад гэрээний код байвал төлөлт шууд үүснэ.

## Гараар холбох {#garaar}
1. Орлогын нэг мөрийг чагтал.
2. **«Холбох»** дар.
3. **«Элсэлт»**, **«Багц»**, **«Дүн»**-гээ сонго.
4. Ах дүү хүүхдэд хуваах бол **«+ Шинэ»** эсвэл **«+ … (ах дүү)»** дараад мөр нэм.
5. «Хуваарилсан / Үлдэгдэл»-ийг шалгаад **«Холбох»** дар.

## Холбох цонхны шар анхааруулга {#anhaaruulga}

**«⚠ … холбогдоогүй үлдэнэ — хуулга «Хэсэгчлэн» төлөвтэй үлдэж…»**
Гүйлгээний дүнгийн нэг хэсгийг ямар ч хүүхдэд оноогоогүй байна. Тэр хэсэг хэний ч тооцоонд орохгүй.
- Олон сарын төлбөр нэг дор шилжүүлсэн бол **«Дүн»**-д гүйлгээний **бүтэн дүнг** оруул. Илүү нь дараагийн сарын урьдчилгаа болно.
- Ах дүү хоёрын төлбөр бол **«+ … (ах дүү)»**-гээр хоёр дахь хүүхдийг нэмж, үлдсэн дүнг оноо.
- Доод мөрөнд «Үлдэгдэл 0 ✓» болсны дараа **«Холбох»** дар.

**«⚠ Сонгосон «…» нь … сарын төлөлтийн багцаас зөрж байна»**
Сонгосон багц тэр сарын төлбөрийн багцтай таарахгүй байна. Багцаа шалгаад зөв бол холбоно.

## Excel хуулга оруулах {#excel}
1. **«+ Импорт»** дар.
2. **«Excel файл»**-аа сонго.
3. **«Урьдчилан харах»** дараад нийт, давхардал, тохирсон тоог шалга.
4. **«Баталгаажуулах»** дар.

Одоогоор зөвхөн **Хаан банкны** хуулга оруулна.

## Буруу холбосныг салгах {#salgah}
1. Холбогдсон мөрийг чагтал.
2. **«Төлөлт салгах»** дар.
3. **«Цуцлах шалтгаан»**-аа бичээд **«Төлөлт цуцалж салгах»** дар.
4. Зөв хүүхэдтэй дахин холбо.

## ⚠️ Анхаар {#anhaar}
- «Төлөлт шалгах», «Холбох», импорт нь **жинхэнэ төлөлт** үүсгэнэ.
- Данс автоматаар хуулга татаж байвал Excel **бүү оруул.** Нэг гүйлгээ давхар орж болно.
- Холбоогүй үлдсэн дүн хэний ч тооцоонд орохгүй.
- Хариу удаж байвал дахин бүү дар. Жагсаалтыг шинэчилж шалга.

## Түгээмэл асуулт {#asuult}

**«Банкны данс үүсгээгүй байна» гэж гарна.**
**Байгууллага → Банкны данс**-аас дансаа нэм.

**«Нэг хүүхдийг нэг хуулгад нэг л мөрөөр холбоно» гэж гарна.**
Нэг хүүхдийн мөрийг нэг болгож, дүнгээ нийлүүл.

**Хичээлийн жилүүдийн хооронд орсон гүйлгээ.**
**«Энэ хичээлийн жилд оноохыг баталж байна»**-г чагталж, шалтгаанаа бичнэ.
