# Элсэлтийн эхлэх огноо засах

> 🏢 Цэцэрлэгийн менежер · Вэб · Цэс: **Элсэлт → Бүртгэл** → хүүхдийн элсэлт

Хүүхдийн элсэлтийн **эхлэх огноог** буруу бүртгэсэн бол өөрсдөө засаж болно. Жишээ нь хүүхэд 9-р сарын 1-нээс ирж байхад элсэлтэд 9-р сарын 16 гэж бичигдсэн бол элсэлтийн «Ирц» таб 1–15-ны ирцийг тоолохгүй.

## Алхам
1. **Үндсэн → Элсэлт → Бүртгэл** цэсийг нээ.
2. Хүүхдээ олоод элсэлтийг нь нээ.
3. Дээд хэсгийн **«Эхлэх огноо засах»** товчийг дар.
4. Зөв огноогоо сонгоод **«Хадгалах»** дар.
5. «Эхлэх огноо солигдлоо» гэж гарвал болсон. Элсэлтийн «Ирц» таб шинэ огнооноос тоолж эхэлнэ.

Товч зөвхөн **Идэвхтэй** элсэлтэд, элсэлт удирдах эрхтэй хэрэглэгчид харагдана.

## Шар анхааруулга гарвал {#anhaaruulga}
Шинэ огноо аль хэдийн **төлбөр бодогдсон сарт** хамаарвал шар анхааруулга гарч, тэр сарууд жагсаагдана.

- Огноо солигдсон хэвээр, гэхдээ **тэр сарын бодогдсон төлбөр өөрөө өөрчлөгдөхгүй**.
- Төлбөрийг шинэ огноогоор бодуулах бол элсэлтийн **«Төлбөр»** табаас тэр сарын төлбөрийг **цуцлаад дахин бод**.
- Төлбөрийг өөрчлөх эсэхээ эрхлэгч шийднэ. Хэрэггүй бол **«Ойлголоо»** дараад орхиж болно.

## Хадгалахгүй байвал
- **«Шинэ огноо одоогийнхтой ижил байна»** — өөр огноо сонго.
- Огноо **дуусах огнооноос хойш** байвал — дуусах огнооноос өмнөх өдөр сонго.
- Огноог **хойшлуулахад** (жишээ нь 09-01 → 09-16) хасагдах өдрүүдэд ирц тэмдэглэгдсэн байвал хадгалагдахгүй. Эхлээд **Ирцийн журнал**-аас тэр өдрүүдийн тэмдэглэгээг цэвэрлэ.
- Өөр **гэрээтэй давхцаж** байвал — мессежид нэрлэгдсэн гэрээг шалга.
- **Хаагдсан** элсэлтийн огноог засах боломжгүй.

## Анхаар
- Буруу сольчихвол дахин **«Эхлэх огноо засах»**-аар өмнөх огноогоо буцааж тавина.
- Энэ нь зөвхөн **эхлэх** огноог засна. Дуусах огноог **Хаалт**-аар тохируулна.
