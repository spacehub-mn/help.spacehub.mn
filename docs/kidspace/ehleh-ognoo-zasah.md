# Элсэлтийн эхлэх огноо засах

> 🏢 Цэцэрлэгийн менежер · Вэб · Цэс: **Үндсэн → Элсэлт → Бүртгэл** → хүүхдийн элсэлт

Хүүхдийн элсэлтийн **эхлэх огноог** буруу бүртгэсэн бол өөрсдөө засаж болно. Жишээ нь хүүхэд 9-р сарын 1-нээс ирж байхад элсэлтэд 9-р сарын 16 гэж бичигдсэн бол элсэлтийн «Ирц» таб 1–15-ны ирцийг тоолохгүй.

## Алхам

![Элсэлтийн хуудас: «Эхлэх огноо засах» товч](/img/kidspace/ehleh-ognoo-zasah-1.webp)

*Зураг 1. Элсэлтийн хуудас: «Эхлэх огноо засах» товч.*

1. **Үндсэн → Элсэлт → Бүртгэл** цэсийг нээ.
2. Хүүхдээ олоод элсэлтийг нь нээ.
3. Дээд хэсгийн **«Эхлэх огноо засах»** товчийг дар.

![«Эхлэх огноо засах» цонх](/img/kidspace/ehleh-ognoo-zasah-2.webp)

*Зураг 2. «Эхлэх огноо засах» цонх.*

4. Зөв огноогоо сонгоод **«Хадгалах»** дар.
5. «Эхлэх огноо солигдлоо» гэж гарвал болсон. Элсэлтийн «Ирц» таб шинэ огнооноос тоолж эхэлнэ. **Төлбөр бичигдээгүй** сарууд шинэ огноогоор дахин бодогдоно.

Товч **Идэвхтэй** эсвэл **Түдгэлзүүлсэн** элсэлтэд, элсэлт удирдах эрхтэй хэрэглэгчид харагдана.

## Шар анхааруулга гарвал {#anhaaruulga}
Шинэ огноо аль хэдийн **төлбөр бодогдсон сарт** хамаарвал шар анхааруулга гарч, тэр сарууд жагсаагдана.

- Огноо солигдсон хэвээр, гэхдээ **тэр сарын бодогдсон төлбөр өөрөө өөрчлөгдөхгүй**.
- Төлбөрийг шинэ огноогоор бодуулах бол элсэлтийн **«Төлбөр»** табаас тэр сарын төлбөрийг **цуцлаад дахин бод**.
- Төлбөрийг өөрчлөх эсэхээ эрхлэгч шийднэ. Хэрэггүй бол **«Ойлголоо»** дараад орхиж болно.

Цуцлаад дахин бичих дараалал → [Төлбөр цуцлаад дахин үүсгэх](/kidspace/tolbor-jagsaalt#tsutslaad-dahin).

## Элсэх огноо өнгөрсөн бол {#ongorson-ognoo}
Хүүхэд өмнө нь ирж эхэлсэн ч элсэлтийг **хожуу** бүртгэвэл («Шинэ элсэлт»-ийн **«Элсэх огноо»**-г өнгөрсөн сараар сонговол, эсвэл энд огноог урагшлуулбал):
1. Элсэлтийн **«Хуваарь»** табыг нээ. Өнгөрсөн сар бүрийн мөр, төлөвийг шалга.
2. **«Төлөвлөсөн»** сарын төлбөр хараахан бичигдээгүй. Тэр сарын ирцээ [Ирцийн журнал](/kidspace/irts-zhurnal)-д тэмдэглэ. Дараа нь мөрийг чагтлаад **«Төлбөр үүсгэх»** → [Нэг хүүхдийн төлбөр үүсгэх](/kidspace/tolboriin-huvaar#tolbor-uusgeh).
3. **«Алгассан»** сар (0 ₮ гарсан) байвал → [«Алгассан» сарыг дахин нээх](/kidspace/tolboriin-huvaar#dahin-neeh).
4. **«Нэхэмжилсэн»** сар хуучин огноогоор бодогдсон бол → дээрх [шар анхааруулга](#anhaaruulga)-ын дараалал.

Ирцээс хамаардаг төлбөр бичигдсэн ирцээр бодогддог тул **эхлээд ирц, дараа нь төлбөр**.

## Хадгалахгүй байвал
- **«Шинэ огноо одоогийнхтой ижил байна»** — өөр огноо сонго.
- Огноо **дуусах огнооноос хойш** байвал — дуусах огнооноос өмнөх өдөр сонго.
- Огноог **хойшлуулахад** (жишээ нь 09-01 → 09-16) хасагдах өдрүүдэд ирц тэмдэглэгдсэн байвал хадгалагдахгүй. Эхлээд **Ирцийн журнал**-аас тэр өдрүүдийн тэмдэглэгээг цэвэрлэ.
- Өөр **гэрээтэй давхцаж** байвал — мессежид нэрлэгдсэн гэрээг шалга.
- **Хаагдсан** элсэлтийн огноог засах боломжгүй.

## Анхаар
- Буруу сольчихвол дахин **«Эхлэх огноо засах»**-аар өмнөх огноогоо буцааж тавина.
- Энэ нь зөвхөн **эхлэх** огноог засна. Дуусах огноог **Хаалт**-аар тохируулна.
