# Бүлгийн сарын тооцоо — «Тайлан → Сарын тооцоо»

> 🏢 Эрхлэгч, менежер · Вэб · Цэс: **Үндсэн → Тайлан → Сарын тооцоо**

## Энэ юу вэ {#ene-yu-ve}
Нэг бүлгийн нэг сарын төлбөр, төлөлт, өрийг хүүхэд бүрээр харуулдаг тайлан. Эрхлэгч багштай сар бүр тооцоо нийлэхэд хэрэглэнэ.

## Хэзээ хэрэглэх {#hezee}
- Сарын эцэст бүлгийн тооцоог багштай нийлэх.
- Өртэй хүүхдүүдийг гаргах.
- Тайланг хэвлэх.

## Тайлан харах {#harah}

![Сарын тооцоо тайлан](/img/kidspace/saryn-tootsoo-tailan-1.webp)

*Зураг 1. Сарын тооцоо тайлан.*

1. **Тайлан → Сарын тооцоо** цэсийг нээ.
2. **«Хичээлийн жил»**, **«Анги»**, **«Сар»**-аа сонго. Сар анхнаасаа өмнөх сар байна.
3. Хаагдсан гэрээтэй хүүхдийг оруулах бол **«Хаагдсан гэрээ»**-г чагтал.
4. Дээд картуудаас нийт төлбөр, төлөлт, өр, төлсөн хүүхдийн тоог хар.
5. Табаар шүү: **«Бүгд»**, **«Өртэй»**, **«Төлсөн»**. Таб бүрд хүүхдийн тоо харагдана.
6. **«Хэвлэх (PDF)»** дарвал тайлан шинэ цонхонд нээгдэнэ. Хэвлэж эсвэл хадгалж болно. Тайлан ачаалж дуустал товч саарал.

«Сар»-ын жагсаалтад зөвхөн сонгосон **хичээлийн жилийн** сарууд гарна. Хэд хэдэн цэцэрлэгтэй бол «Анги»-д «бүлэг · цэцэрлэг» гэж харагдана.

## Тайлангийн толгой, картууд {#kartuud}
- Толгой: «<бүлэг> бүлэг · <сар>», цэцэрлэг, хичээлийн жил, **«Багш:»** (томилоогүй бол «томилоогүй»).
- **«Нийт төлбөр»** — тэр сарын бүх хүүхдийн төлбөр, «N хүүхэд».
- **«Төлөлт (энэ сарын тооцоонд)»** — хэзээ орсноос үл хамааран тэр сарын төлбөрт хуваарилагдсан төлөлт.
- **«Өр»** — дутуу төлөлт; «Өргүй» эсвэл «өмнөх сарын …».
- **«Төлсөн»** — «бүрэн төлсөн/нийт» хүүхэд, «Илүү төлөлт …».

Баганууд: **«Дугаар»**, **«Элсэгч»**, **«Төлбөр»**, **«Төлөлт»**, **«Үлд(+/-)»**, **«Огноо»**, **«Төлсөн»**. Доод мөр «Нийт · N хүүхэд». Гэрээ нь хаагдсан хүүхдэд **«хаагдсан»** шошго.

## Дүнг унших {#unshih}
- **«Үлд(+/-)»**: «(-)700,000» = өр (улаан), «(+)50,000» = илүү төлөлт (ногоон), «-» = тэг.
- Доор нь жижгээр «өмнөх …» гарвал өмнөх сарын өр. Энэ мөрөнд ороогүй.
- **«Огноо»** — тэр сарыг хаасан төлөлтийн огноо. Шар = дараа сард орсон төлөлт, цэнхэр = урьдчилж төлсөн. Хулганаа аваачвал «Дараа сард орсон төлөлт» / «Урьдчилж төлсөн» гэж гарна.
- Бүрэн төлсөн мөр ногоон дэвсгэртэй.
- **«Дугаар»** дээр дарвал хүүхдийн элсэлт нээгдэнэ.

## ⚠️ Анхаар {#anhaar}
- **«Төлөлт»** нь хэзээ орсноос үл хамааран **тэр сарын тооцоонд** орсон төлөлтийг харуулна.
- Энэ тайлан зөвхөн харуулна. Төлбөр өөрчлөхгүй, эцэг эхэд юу ч илгээхгүй.
- Зөвхөн PDF-ээр хэвлэнэ. Excel татах боломжгүй.

## Түгээмэл асуулт {#asuult}

**Багш энэ цэсийг харахгүй байна.**
Тайланг зөвхөн эрхлэгч, менежер харна.

**«Энэ тайланг унших зөвшөөрөлгүй байна» гэж гарна.**
Таны нэвтрэх эрхэд төлбөр харах эрх алга. Эрхлэгчид хандана уу.

**«Энэ сард бүлэгт элсэгч алга.» эсвэл «Энэ шүүлтэд мөр алга.» гэж гарна.**
Сар, анги зөв эсэхийг шалга. «Өртэй»/«Төлсөн» таб дээр бол «Бүгд» таб руу шилж. Хаагдсан гэрээтэй хүүхэд бол «Хаагдсан гэрээ»-г чагтал.

**«Энэ хичээлийн жилд бүлэг алга» гэж гарна.**
«Хичээлийн жил»-ээ шалга. Бүлэг үүсгээгүй бол **Анги / Бүлэг** цэсээс үүсгэнэ.
