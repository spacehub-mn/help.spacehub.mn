# Нэхэмжлэх тохиргоо — имэйл, SMS, QPay

> 🏢 Эрхлэгч, менежер · Вэб · Цэс: **Үндсэн → Байгууллага** → **«Тохиргоо»** таб → **«Нэхэмжлэх тохиргоо»**

## Энэ юу вэ {#ene-yu-ve}
Нэхэмжлэхийг эцэг эх рүү **ямар сувгаар** (имэйл, SMS) явуулах, **QPay**-ээр төлүүлэх эсэхийг тохируулна. Гурван хэсэгтэй.

## Хэзээ хэрэглэх {#hezee}
- Цэцэрлэгээ анх тохируулахад. → [Эхний 7 хоног](/kidspace/nevtruulelt#odor-3)
- Нэхэмжлэх эцэг эхэд очихгүй байхад. → [SMS, нэхэмжлэх очоогүй](/kidspace/sms-ochoogui#tohirgoo)

## И-мэйл ба гүйлгээний утга {#imeil}
1. **«Илгээгчийн и-мэйл»** — нэхэмжлэх энэ хаягаас илгээгдэнэ.
2. **«Илгээх суваг»** — **«И-мэйлээр илгээх идэвхжүүлэх»**-ийг асаа.
3. **«Гүйлгээний утгын загвар»** — эцэг эх шилжүүлэхдээ бичих утга. **«Анхдагч гүйлгээний утгаар бөглөх»** нь системийн анхдагч загварыг оруулна.
4. Хадгал. «Хадгалагдлаа» гэж гарна.

Гүйлгээний утгад гэрээний дугаар орвол төлөлт дансны хуулгаас **автоматаар** холбогдоно. → [Төлөлт, дансны хуулга](/kidspace/asuult/tolult#tolsun)

## SMS {#sms}
1. **«SMS-ээр илгээх идэвхжүүлэх»**-ийг асаа.
2. **«Мессежийн загвар»**-ыг шалга. Буцаах бол **«Анхдагч руу буцаах»**.
3. **«Gateway түлхүүр»** — SMS үйлчилгээний түлхүүр. Солих бол **«Түлхүүр солих»**.
4. Хадгал.

⚠️ Түлхүүрийг **«Устгах»** бол SMS илгээхээ болино.

## QPay {#qpay}
1. **«QPay-ээр төлөх идэвхжүүлэх»**-ийг асаа.
2. **«Нэхэмжлэхийн код»** — QPay танай байгууллагад өгсөн merchant invoice code.
3. **«QPay нэвтрэх мэдээлэл»** — username, password. Идэвхжүүлэхэд нэхэмжлэхийн код, нэвтрэх нэр, нууц үг **гурвуулаа** шаардлагатай.
4. **«Эцэг эхийн төлөх шимтгэл (₮)»** — бүхэл тоо, 0-ээс багагүй.
5. **«Туршилтын горим (sandbox)»** — зөвхөн туршилтад. Бодит төлбөрт унтраалттай байх ёстой.
6. Хадгал.

Төлөв: **«Тохируулаагүй»**, **«Идэвхгүй»**, **«Идэвхтэй»**, **«Идэвхтэй · Туршилтын горим»**.

## ⚠️ Анхаар {#anhaar}
- Нууц үг, түлхүүрийг бусдад бүү дамжуул, дэлгэцийн зураг бүү явуул.
- «Энэ тохиргоог өөр хэрэглэгч зэрэг өөрчилжээ. Юу ч бичигдээгүй.» гарвал **«Шинэ төлөвийг ачаалах»** дараад өөрчлөлтөө дахин оруул.
- Сувгийг унтраавал төлбөрийн ажиллагааны тэр шатны илгээлт «… компанийн тохиргоогоор одоогоор идэвхгүй байна» гэж бичигдэнэ.
- «Тохиргоо» таб харагдахгүй бол эрх хүрэхгүй. → [«Эрхгүй», цэс харагдахгүй](/kidspace/erhgui#tses)

## Түгээмэл асуулт {#asuult}
**QPay идэвхжихгүй байна.**
Нэхэмжлэхийн код, username, password гурвуулаа бөглөгдсөн эсэхийг шалга.

**Эцэг эх нэхэмжлэхийн SMS аваагүй.**
SMS идэвхтэй, түлхүүр хадгалагдсан эсэхийг шалга. Дараа нь → [SMS, нэхэмжлэх очоогүй](/kidspace/sms-ochoogui)
