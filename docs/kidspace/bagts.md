# Багц

> 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Үндсэн → Байгууллага** → **«Тохиргоо»** таб → **«Багц»**

## Энэ юу вэ {#ene-yu-ve}
**Багц** нь хүүхдийн сар бүр төлөх үйлчилгээнүүдийн бүлэг (жишээ нь сургалт + хоол). Багц бүр **горимтой** («Дараа сард» эсвэл «Урьдчилж») ба **үнэ тохиргоотой**. → [Хуваарь → Төлбөр → Нэхэмжлэх](/kidspace/concepts/tolbor-urgal#gorim)

Компанийн **«Идэвхтэй»** сонголт элсэлтийн **анхдагч** багцуудыг тогтооно. Элсэлт болон хуваарийн сар дээр өөрчилж болно.

## Хэзээ хэрэглэх {#hezee}
- Цэцэрлэгээ анх тохируулахад. → [Эхний 7 хоног](/kidspace/nevtruulelt#odor-3)
- Шинэ үйлчилгээ (дугуйлан г.м.) сар бүрийн төлбөрт нэмэхэд.
- Горимыг солих, багцыг хаахад.

## Багц нэмэх {#nemeh}
1. **Байгууллага** → **«Тохиргоо»** таб → **«Багц»**.
2. **«+ Шинэ»** (эсвэл **«Багц нэмэх»**) дар.
3. Цонхны дагуу **«Нэр»**, үйлчилгээгээ оруул.
4. Багцын карт дээрх **«Үнэ тохиргоо нэмэх»**-ээр үнийг холбо.
5. **«Хадгалах»**. «… хадгалагдлаа.» гэж гарна.

## Багцын товчнууд {#tovch}
- **«Үндсэн болгох»** — шинэ элсэлтийн үндсэн багц болгоно. Үндсэн багцыг идэвхгүй болгох боломжгүй.
- **«Горим солих»** — «Дараа сард» ↔ «Урьдчилж». «Урьдчилж» руу шилжүүлэхэд тэр сард **хоёр төлбөр** гарна. → [«Урьдчилж» горим](/kidspace/tolbor-nehemjleh#uridchilj-tootsoo)
- **«Энэ сараас хойш бүх элсэлтэд асаах/унтраах»** — багцыг бүх элсэлтэд нэг дор.
- **«Багцаас хасах»** — үйлчилгээг хасна. **Сонгосон сараас** хүчинтэй.
- **«Хэрэглээний эхлэлийг засах»**, **«Түүх харах»**.

## ⚠️ Анхаар {#anhaar}
- Өөрчлөлт **сонгосон сараас** хойш хүчинтэй. Аль хэдийн бичигдсэн төлбөр өөрчлөгдөхгүй. → [Төлбөр цуцлаад дахин үүсгэх](/kidspace/tolbor-jagsaalt#tsutslaad-dahin)
- Нэг үнэ тохиргоог хамт ашигладаг багцуудыг нэг хугацаанд **зэрэг идэвхжүүлэхгүй**.
- Идэвхгүй болгохын өмнө одоогийн / ирээдүйн тохиргоог шилжүүлэх эсвэл хасна.
- Багцын нэр, төлөв, төлбөрийн тохиргоог **компанийн** түвшнээс өөрчилнө. Цэцэрлэгийн эрхээр зөвхөн харна.
- Хүүхэд бүрийн багц, сар бүрийн хөнгөлөлтийг элсэлтийн **«Тохиргоо» → «Багц»**-аас. → [Хөнгөлөлт](/kidspace/honglolt)

## Түгээмэл асуулт {#asuult}
**«Анхдагч идэвхийг өөрчлөх зөвшөөрөлгүй.»**
Таны үүрэгт багц өөрчлөх эрх алга. Эрхлэгчид хандана уу.

**«Үндсэн багц — идэвхгүй болгох боломжгүй.»**
Эхлээд өөр багцыг **«Үндсэн болгох»**.
