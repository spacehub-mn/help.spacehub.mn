# «Эрхгүй» гарах, цэс харагдахгүй

> 🔧 Асуудал · 🏢 Эрхлэгч, менежер, багш · Вэб

KidSpace цэс, таб, товчийг **таны үүргийн эрхээр** харуулна. Эрх хүрэхгүй бол цэс **огт харагдахгүй**, эсвэл товч дарахад мессеж гарна.

## Ийм мессеж гарвал {#messej}
| Мессеж | Утга | Хийх |
|---|---|---|
| «Энэ үйлдлийг хийх эрхгүй байна.» | Таны үүрэгт энэ товчны эрх алга | Эрхлэгчид хандана уу |
| «Хандах эрхгүй байна.» / «Энэ хүрээнд хандах эрхгүй.» | Энэ дэлгэц, цэцэрлэгт хандах эрх алга | Таныг зөв цэцэрлэгт бүртгэсэн эсэхийг шалгуул |
| «Менежерийн эрх шаардлагатай.» | Зөвхөн эрхлэгч, менежер хийнэ | Менежерт хандана уу |
| «Ирц бүртгэх эрхгүй байна.» | Ирц тэмдэглэх эрх алга | Эрхлэгчид хандана уу → [Ирц журнал](/kidspace/irts-zhurnal#asuult) |
| «Мэдээлэл хянах эрхгүй байна.» | Мэдээлэл хянах эрх алга | → [Мэдээлэл хянах](/kidspace/medeelel-hyanah) |
| «Элсэлт олдсонгүй эсвэл хандах эрхгүй байна.» | Элсэлт олдсонгүй, эсвэл өөр цэцэрлэгийнх | Дээд мөрний цэцэрлэгийг шалга |

## Цэс, таб харагдахгүй {#tses}
- **Тооцоо**, **Элсэлт → Хаалт** — зөвхөн эрхлэгч, менежерт. → [Эрхлэгч, менежер](/kidspace/role/menejer#zovhon)
- **Байгууллага**-ийн «Бараа үйлчилгээ», «Банкны данс», «Тохиргоо» табууд тус бүр **тусдаа эрх** шаарддаг. → [Байгууллага](/kidspace/baiguullaga#tabuud)
- Багш **өөрийн бүлгээ** харахгүй бол бүлэгт томилоогүй. → [Багш томилох](/kidspace/bulguud#bagsh-tomiloh)

## Эрх өгөх, солих {#erh-ogoh}
Эрхлэгч, менежер:
1. **Байгууллага** → **«Багш, ажилчид»** таб.
2. Ажилтны мөрийг нээ.
3. **«Үүрэг»**, **«Цэцэрлэг»**-ийг сольж хадгал. «Цэцэрлэг» хоосон бол бүх цэцэрлэг.

→ [Багш, ажилтан нэмэх](/kidspace/bagsh-ajilchid#uureg)
