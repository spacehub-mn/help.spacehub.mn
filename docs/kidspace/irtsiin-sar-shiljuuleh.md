# Ирцийн сар шилжүүлэх — өмнөх эсвэл тухайн сарын ирцээр бодох

> 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Нэг гэрээ: **Үндсэн → Элсэлт → Бүртгэл** → хүүхэд → **«Хуваарь»** таб · Бүх гэрээ: **Үндсэн → Байгууллага → «Цэцэрлэг»** → цэцэрлэг → **«Тохиргоо» → «Төлбөр дахин бодох»**

## Энэ юу вэ {#ene-yu-ve}
Сарын төлбөрийг аль сарын ирцээр бодохыг заана:
- **«Өмнөх сарын ирц»** — 11-р сарын төлбөрт 10-р сард ирсэн өдрүүд орно. Эхний сар бүтэн сараар (урьдчилгаа) бодогдоно.
- **«Тухайн сарын ирц»** — 11-р сарын төлбөрт 11-р сарын ирц орно.

Шилжүүлэхэд сонгосон сараас хойш **үүссэн төлбөр цуцлагдаж**, сонгосон ирцээр **шинээр үүснэ**. Төлөлт хөндөгдөхгүй — шинэ төлбөрт автоматаар хуваарилагдана.

## Хэзээ хэрэглэх {#hezee}
- Гэрээ буруу горимоор бодогдсон: «өмнөх сарын ирцээр» байх ёстой байтал тухайн сарын ирцээр гарсан, эсвэл эсрэгээрээ.
- Цэцэрлэг бүхэлдээ нэг горимд шилжих үед — бүх гэрээг нэг дор шилжүүлнэ.

## Нэг гэрээг шилжүүлэх {#neg-geree}
1. Хүүхдийн **«Хуваарь»** таб → шилжүүлж эхлэх **сарын мөрийг** сонго.
2. **«Ирцийн сар шилжүүлэх»** дар. Цонхны дээд хэсэгт **«Одоогийн чиглэл»** харагдана (жишээ нь «Одоо: тухайн сарын ирцээр», эсвэл саруудад өөр өөр бол «Одоо холимог»).
3. **«Чиглэл»**-ээс **«Өмнөх сарын ирц»** эсвэл **«Тухайн сарын ирц»**-ийг сонго. Аль хэдийн идэвхтэй чиглэлийн хажууд «· одоо идэвхтэй» гэж бичигдэнэ.
4. Урьдчилан харахад сар бүрээр юу болохыг харуулна: цуцлагдаж дахин үүсэх төлбөр, «нэхэмжлэгдээгүй» сар.
5. Төлсөн төлбөр цуцлагдах бол **«Төлөлттэй төлбөр цуцлагдана…»** гэсэн тэмдэглэгээг чагтал. Төлөлт хэвээр үлдэж шинэ төлбөрт хуваарилагдана.
6. **«Шалтгаан»** оруулаад **«Шилжүүлэх»**.
7. Үр дүнд сар бүрээр **хуучин код → шинэ код, шинэ дүн** гарна. **«Хаах»**-аар хаа.

Нэг сарын төлбөр «үүсээгүй — …» гэж гарвал тэр сарыг **«Хуваарь» → тэр сар → «Төлбөр үүсгэх»**-ээр гараар үүсгэ.

## Цэцэрлэгийн бүх гэрээг шилжүүлэх {#buh-geree}
Менежер ба түүнээс дээш эрхтэй хэрэглэгч хийнэ.

1. **Үндсэн → Байгууллага → «Цэцэрлэг»** таб → цэцэрлэгээ нээ → **«Тохиргоо»** таб → **«Төлбөр дахин бодох»**.
2. **«Чиглэл»** (Өмнөх / Тухайн сарын ирц) ба **«Эхлэх сар»**-ыг сонго → **«Урьдчилан харах»**.
3. Урьдчилан харахад:
   - **«N гэрээ × багц шилжинэ · N төлбөр · хуучин нийт …»** — хэдэн гэрээ хөдлөх, хуучин дүн. Төлсөн дүн байвал «үүнээс төлөгдсөн … (төлөлт хэвээр)».
   - **«Аль хэдийн …»** — тэр чиглэлд байгаа, хөндөгдөхгүй гэрээ.
   - **«Алгасах гэрээнүүд»** — хаагдсан сар, е-баримттай эсвэл хөнгөлөлттэй төлбөртэй гэрээ. Эдгээрийг систем хөндөхгүй — **гараар шалгана**.
   - **«Хожуу эхлэх гэрээнүүд»** — өмнөх сар нь хаагдсан тул дараагийн сараас эхэлж шилжинэ.
4. **«Шалтгаан»** оруул (жишээ: «Бүх гэрээ өмнөх сарын ирцээр бодогдоно») → **«Дахин бодох (N)»** → баталгаажуулах цонхонд **«Дахин бодох»**.
5. Явц «Дахин бодож байна… 12/66» гэж харагдана. Дуусахад **«N гэрээ дахин бодогдлоо · шинэ нийт …»**. Алдаатай гэрээ улаанаар жагсана — тэдгээрийг нэг гэрээгээр нь шилжүүл.

## ⚠️ Анхаар {#anhaar}
- **Нэхэмжлэх дахин үүсгэх шаардлагатай.** Цуцлагдсан төлбөрийн нэхэмжлэх хамт цуцлагдана. Шинэ төлбөрт нэхэмжлэх өөрөө үүсэхгүй — **«Тооцоо → Төлбөр»** → төлбөр **нэг нэгээр** чагтлаад **«Нэхэмжлэх үүсгэх»**. → [Нэхэмжлэх үүсгэх](/kidspace/tolbor-jagsaalt#nehemjleh-uusgeh)
- **Гараар бичсэн хөнгөлөлт** нь урьдчилан харахад «Алгасах» болж үлдэнэ. Хөнгөлөлтийг цуцлаад шилжүүлж, дараа нь шинэ төлбөр дээр хөнгөлөлтөө дахин бич. → [Хөнгөлөлт](/kidspace/honglolt)
- «Өмнөх сарын ирц» рүү шилжихэд **эхний сар бүтэн сараар** бодогдоно — энэ бол урьдчилгаа, алдаа биш. → [«Урьдчилж» горим](/kidspace/tolbor-tsutslahaas-omno#uridchilj-butend)
- Тайлант үе хаагдсан сарын төлбөр хөдлөхгүй. → [Тайлант үе хаах](/kidspace/tailant-uye-haah)

## Түгээмэл асуулт {#asuult}
**«Ирцийн сар шилжүүлэх» товч идэвхгүй байна.**
Товч дээр хулганаа барихад шалтгаан нь гарна. Ихэвчлэн тэр сарын төлбөр хараахан үүсээгүй, эсвэл өөр ажил явж байна.

**Шилжүүлсний дараа өр нэмэгдсэн харагдаж байна.**
Энэ хэвийн. «Өмнөх сарын ирц» рүү шилжихэд эхний сар бүтэн сарын урьдчилгаа болдог. Дараагийн сарын төлбөрт тасалсан өдрүүд хасагдана.

**Шилжүүлэлт дундаа тасарсан.**
Цонхыг дахин нээ. Тасарсан сар «тасалдсан шилжүүлэлтийг үргэлжлүүлнэ» гэж харагдана — дахин **«Шилжүүлэх»** дар.
