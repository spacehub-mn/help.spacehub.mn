# Цэс бүрийн хуудас

> 📋 Жагсаалтууд · 🏢 Эрхлэгч, менежер, багш · Вэб

KidSpace-ийн зүүн цэсний дэлгэц бүр ямар хуудастай вэ. Апп дээрх **«Тусламж»** товч тухайн дэлгэцийн хуудсыг шууд нээнэ.

> 💡 Жагсаалт бүрийн **шүүлт** хаягт хадгалагдана. Мөр нээгээд **«Буцах»** дарахад сүүлийн шүүлттэй жагсаалт руугаа буцна. Төлбөр, хөнгөлөлт, нэхэмжлэхийн жагсаалтын **«Хуваарь»** багана аль сарынх болохыг харуулна (2026.11).
