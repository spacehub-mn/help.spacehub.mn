# Эхний 7 хоног — KidSpace-ийг анх тохируулах

> 🚀 Эхлэх · 🏢 Эрхлэгч, менежер · Вэб

KidSpace-ийг шинээр ашиглаж эхэлж буй цэцэрлэгт зориулсан **дараалал**. Алхам бүр өмнөхөөсөө хамаарна — дарааллыг бүү алгас.

## Өдөр 1 · Байгууллага {#odor-1}
1. **Байгууллага → «Байгууллагын мэдээлэл»** — нэр, хаяг, **төлбөр хийх хугацаа**. → [Байгууллага](/kidspace/baiguullaga)
2. **«Цэцэрлэг»** таб — салбар бүрээ **«Шинэ»**-ээр нэм.
3. **«Банкны данс»** таб — хуулга татах данс. → [Дансны хуулга](/kidspace/dansnii-huulga)

## Өдөр 2 · Хүмүүс {#odor-2}
1. **«Багш, ажилчид»** таб — ажилтан бүрийг нэвтрэх утас, түр нууц үг, **үүрэгтэй** нь нэм. → [Багш, ажилтан нэмэх](/kidspace/bagsh-ajilchid#shine)
2. Хэн юу хийхийг [Дүрээр](/kidspace/role/menejer) хэсгээс шалга.

## Өдөр 3 · Хичээлийн жил, үйлчилгээ, үнэ {#odor-3}
1. **«Тохиргоо» → «Хичээлийн жил»** — эхлээд жилээ. Нэг жил **«Идэвхтэй»** байх ёстой. → [Хичээлийн жил](/kidspace/hicheeliin-jil)
2. **«Бараа үйлчилгээ»** таб — төлбөрт орох үйлчилгээ (нэр, нэгж, татвар).
3. **«Тохиргоо»** → **«Үнэ тохиргоо»**, **«Багц»** — сарын багц, горим («Дараа сард» эсвэл «Урьдчилж»). → [Төлбөр хэрхэн бодогддог](/kidspace/concepts/tolbor-urgal#gorim)
4. **«Тохиргоо» → «Нэхэмжлэх тохиргоо»** — имэйл, SMS, QPay.

## Өдөр 4 · Бүлэг {#odor-4}
1. **Анги / Бүлэг → Бүлгүүд** — бүлэг бүрийг үүсгэж **«Элсэлт нээлттэй»**-г асаа. → [Шинэ бүлэг](/kidspace/bulguud#shine-buleg)
2. Бүлэгт багш томил. → [Багш томилох](/kidspace/bulguud#bagsh-tomiloh)

## Өдөр 5 · Хүүхэд элсүүлэх {#odor-5}
1. **Элсэлт → Бүртгэл → «+ Шинэ»** — хүүхэд бүрийг бүлэгт, **зөв элсэх огноотой** элсүүл. → [Хүүхэд элсүүлэх](/kidspace/elselt-burtgel#shine-huuhed)
2. Ах, эгчтэй бол **гэр бүлд** нэм. → [Гэр бүлд нэмэх](/kidspace/elselt-burtgel#ger-bul)
3. Хүүхэд бүрийн элсэлтийн **«Тохиргоо» → «Багц»**-ийг шалга. Багшийн хүүхэд, ах дүүгийн хөнгөлөлтийг энд оруул. → [Хөнгөлөлт](/kidspace/honglolt)

## Өдөр 6 · Хуваарь шалгах {#odor-6}
**Тооцоо → Хуваарь** — хүүхэд бүрд сар бүрийн **«Төлөвлөсөн»** мөр гарсан эсэхийг шалга. «Хуваарийн мөр алга» гэвэл элсэлтийн үнэ, багц дутуу. → [Төлбөрийн хуваарь](/kidspace/tolboriin-huvaar)

## Өдөр 7 · Анхны сарын төлбөр {#odor-7}
1. **Авто туслагч → Төлбөрийн ажиллагаа → «Шинэ»** — цэцэрлэг бүрд. Эхлээд **шалгаад** дараа нь илгээ. → [Эхлээд шалгаад дараа нь илгээх](/kidspace/tolboriin-ajillagaa#shalgaad)
2. **Тооцоо → Нэхэмжлэх** — эцэг эхэд очсон эсэхийг шалга. → [Нэхэмжлэх илгээх](/kidspace/nehemjleh-ilgeeh)
3. Багш нар **Ирц журнал**-аа өдөр бүр бөглөж эхэл — ирцээр бодогддог багц ирцээс хамаарна. → [Ирц журнал](/kidspace/irts-zhurnal)

Дараа нь сар бүр: [Сар бүрийн ажил](/kidspace/tutorial/sar-buriin-ajil).
