# Толгойн мөр

> 📋 Лавлах · 🏢 Эрхлэгч, менежер, багш · Вэб

Дэлгэц бүрийн дээд мөрөнд байдаг хэрэгслүүд. Утсан дээр, эсвэл зай багатай үед эдгээр нь **⋮ (Бусад)** товч дотор нэг жагсаалт болж эвхэгдэнэ.

| Хэрэгсэл | Юу хийх |
|---|---|
| **Хичээлийн жил** | Ажиллаж буй хичээлийн жилээ сонгоно → [доор](#jil) |
| **Гэрэл / харанхуй** | Гэрэл, харанхуй горимын хооронд шилжинэ |
| **Тусламж** (?) | **Энэ дэлгэцийн** тусламжийн хуудсыг шинэ цонхонд нээнэ |
| **🔔 Урилга** | Танд ирсэн урилгын тоо (9-өөс олон бол «9+»). Дарахад урилгын жагсаалт нээгдэнэ → [Урилга хүлээн авах](/kidspace/ajlyn-talbar#urilga) |
| **⚙ Тохиргоо** | Өөрийн мэдээлэл, нууц үг, ажлын талбар → [Хувийн бүртгэл](/kidspace/huviin-burtgel) |

## Хичээлийн жил сонгох {#jil}
Сонгосон жил бүх дэлгэцэд үйлчилнэ. Жагсаалтад:
- **Тод** бичигдсэн нь — **идэвхтэй** хичээлийн жил.
- **✓** тэмдэгтэй нь — **одоо харж байгаа** жил.

Хаагдсан жилийг сонгож өмнөх мэдээллээ харж болно. Тэр үед **Тооцоо → Төлбөр** дэлгэцийн **«Хөнгөлөлт»**, **«Нэхэмжлэх үүсгэх»**, **«Цуцлах»** товч идэвхгүй болно. Байгууллагад хичээлийн жил огт үүсгээгүй бол энэ сонголт харагдахгүй. → [Хичээлийн жил](/kidspace/hicheeliin-jil)

> 💡 «Жагсаалт хоосон», «хүүхэд харагдахгүй» гэвэл эхлээд толгойн мөрийн **Хичээлийн жил**-ийг шалга.
