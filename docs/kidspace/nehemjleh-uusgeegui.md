# Төлбөр, нэхэмжлэх үүсээгүй

> 🔧 Асуудал · 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Тооцоо**

Эхлээд **аль нь** алга болохыг ол: төлбөр үү, нэхэмжлэх үү. → [«Төлбөр» ба «Нэхэмжлэх» ялгаа](/kidspace/tolbor-nehemjleh)

## Төлбөр ч алга {#tolbor-alga}
1. **Ажиллагаа үүссэн үү.** Систем сар бүрийн ажиллагааг **өөрөө үүсгэдэггүй**. **Авто туслагч → Төлбөрийн ажиллагаа**-д тэр цэцэрлэг × сарын ажил байгаа эсэхийг хар. → [Шинэ ажиллагаа](/kidspace/tolboriin-ajillagaa#shine)
2. **Ажиллагааны «Алгассан» тоо, шалтгаан.** Цөөхөн хүүхдэд үүссэн бол 5 шалтгааныг шалга. → [Цөөхөн хүүхдэд үүссэн](/kidspace/tolbor-nehemjleh#tsoohon)
3. **Хүүхдийн хуваарь.** Элсэлтийн **«Хуваарь»** табд тэр сар:
   - **«Төлөвлөсөн»** — төлбөр хараахан бичигдээгүй. Нэг хүүхдэд → [Нэг хүүхдийн төлбөр үүсгэх](/kidspace/tolboriin-huvaar#tolbor-uusgeh)
   - **«Алгассан»** (0 ₮) — → [«Алгассан» сарыг дахин нээх](/kidspace/tolboriin-huvaar#dahin-neeh). Өмнөх сар бүтэн өвчтэй байсан бол → [«Энэ сараар үүсгэх»](/kidspace/tolboriin-huvaar#ene-saraar)
   - **Мөр алга** — табд «Төлбөрийн хуваарь алга.» эсвэл «Төлбөрийн хуваарийн мөр алга.» гарна (**Тооцоо → Хуваарь** дэлгэцэд «Хуваарийн мөр алга. Үнэ тохиргоог шалгана уу.»). → элсэлтийн «Тохиргоо» табын үнэ, багц.
4. **Тайлант үе.** Хаагдсан үед шинэ төлбөр бичихгүй. → [Тайлант үе хаах](/kidspace/tailant-uye-haah)

## Төлбөр бий, нэхэмжлэх алга {#nehemjleh-alga}
- Ажиллагааны **«Дуусах төлөв»** «Төлбөр үүсгэх» байсан — нэхэмжлэх үүсгэх шат хийгдээгүй. **«Дуусах төлөв өөрчлөх»**. → [Эхлээд шалгаад дараа нь илгээх](/kidspace/tolboriin-ajillagaa#shalgaad)
- Нэг төлбөрт гараар: **Тооцоо → Төлбөр** → төлбөрийг чагтал → **«Нэхэмжлэх үүсгэх»** → урьдчилан хараад **«Хадгалах»**. → [Нэхэмжлэх үүсгэх](/kidspace/tolbor-jagsaalt#nehemjleh-uusgeh)

## ⚠️ Анхаар {#anhaar}
- Хүчинтэй нэхэмжлэхтэй төлбөрт дахин хадгалбал **хоёр дахь** нэхэмжлэх үүснэ. Эхлээд шалга.
- **Тооцоо → Төлбөр**-д сарын шүүлт байхгүй — сарыг **«Хуваарь»** баганаас хар.
