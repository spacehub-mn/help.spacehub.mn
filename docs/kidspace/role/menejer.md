# Эрхлэгч, менежер

> 👥 Дүрээр · 🏢 Эзэн / Захирал, менежер · Вэб

**Эзэн / Захирал** болон **Менежер** үүрэгтэй хүн **бүх цэсийг** харна. Ажилтанд үүргийг **Байгууллага → «Багш, ажилчид»**-аас өгнө. → [Багш, ажилтан нэмэх](/kidspace/bagsh-ajilchid#uureg)

## Таны ажлууд {#ajluud}
| Хэзээ | Ажил | Хуудас |
|---|---|---|
| Анх | Байгууллага, цэцэрлэг, ажилтан, багц, хичээлийн жил, бүлэг | [Эхний 7 хоног](/kidspace/nevtruulelt) |
| Өдөр бүр | Элсэлтийн хүсэлт, санал хүсэлт, мэдээлэл хянах | [Хүсэлт](/kidspace/elseltiin-huselt) · [Санал хүсэлт](/kidspace/sanal-huselt) · [Мэдээлэл хянах](/kidspace/medeelel-hyanah) |
| Хүүхэд ирэх, гарах | Элсүүлэх, анги шилжүүлэх, гэрээ хаах | [Элсэлт](/kidspace/elselt-burtgel) · [Шилжүүлэх](/kidspace/angi-shiljuuleh-devshuuleh) · [Хаалт](/kidspace/elseltiin-haalt) |
| Сар бүр | Төлбөрийн ажиллагаа, нэхэмжлэх, төлөлт холбох | [Сар бүрийн ажил](/kidspace/tutorial/sar-buriin-ajil) |
| Сарын эцэс | Сарын тооцоо, тайлант үе хаах | [Сарын тооцоо](/kidspace/saryn-tootsoo-tailan) · [Тайлант үе](/kidspace/tailant-uye-haah) |
| Жилийн эцэс | Шинэ хичээлийн жил, бүлэг хуулах, анги дэвшүүлэх | [Хичээлийн жил](/kidspace/hicheeliin-jil) |

## Зөвхөн танд харагдах {#zovhon}
- **Тооцоо** цэс (хуваарь, төлбөр, нэхэмжлэх, төлөлт) — багш харахгүй.
- **Элсэлт → Хаалт**.
- **Байгууллага**-ийн «Бараа үйлчилгээ», «Банкны данс», «Тохиргоо» табууд — тус бүр тусдаа эрх шаарддаг. Харагдахгүй бол эрх хүрэхгүй байна.

## ⚠️ Анхаар {#anhaar}
- Анги солиход гэрээ **бүү хаа** — «Анги шилжүүлэх». → [Хичээлийн жил, бүлэг, элсэлт](/kidspace/concepts/elselt-buleg-jil#neg-geree)
- Багш ирц журналд хандаж чадахгүй бол бүлэгт **томилоогүй** эсвэл ирц бүртгэх **эрхгүй**. → [Багш](/kidspace/role/bagsh)
