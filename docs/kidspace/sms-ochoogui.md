# SMS, нэхэмжлэх эцэг эхэд очоогүй

> 🔧 Асуудал · 🏢 Эрхлэгч, менежер · Вэб · Цэс: **Тооцоо → Нэхэмжлэх** · **Авто туслагч → Төлбөрийн ажиллагаа**

Эцэг эх «нэхэмжлэх ирээгүй» гэвэл доорх дарааллаар шалга.

## 1. Нэхэмжлэх үүссэн үү {#uussen-uu}
**Тооцоо → Нэхэмжлэх**-ээс хүүхдээ хай. Нэхэмжлэх алга бол илгээх зүйл байхгүй. → [Нэхэмжлэх үүсээгүй](/kidspace/nehemjleh-uusgeegui)

## 2. Ажиллагаа илгээх хүртэл явсан уу {#ajillagaa}
**Авто туслагч → Төлбөрийн ажиллагаа** → тэр сарын ажиллагааг нээ.
- **«Дуусах төлөв»** нь «Төлбөр үүсгэх» эсвэл «Нэхэмжлэх үүсгэх» бол нэхэмжлэх **илгээгдэхгүй**. **«Дуусах төлөв өөрчлөх»**-өөр «Нэхэмжлэх илгээх» болго. → [Эхлээд шалгаад дараа нь илгээх](/kidspace/tolboriin-ajillagaa#shalgaad)
- **«Үе шатны явц»** табаас алдаатай тоог хар. Ажиллагаа **«Алдаатай дууссан»** бол **«Дахин оролдох»**. → [Явцыг харах](/kidspace/tolboriin-ajillagaa#yavts)

## 3. SMS тохиргоо асаалттай юу {#tohirgoo}
Алдааны шалтгаанд «… компанийн тохиргоогоор одоогоор идэвхгүй байна» гэж бичигдсэн бол байгууллагын SMS (эсвэл имэйл) унтраалттай байна. **Байгууллага → «Тохиргоо» → «Нэхэмжлэх тохиргоо»**-г шалга. → [Байгууллага](/kidspace/baiguullaga#tabuud)

## 4. Утас, имэйл зөв үү {#utas}
Асран хамгаалагчийн утас, имэйлийг **Гэр бүл → Сурагчид**-аас шалгаж засна. → [Хүүхдийн мэдээлэл засах](/kidspace/suragchid#zasah)

Зассан утас **аль хэдийн үүссэн** нэхэмжлэхэд орохгүй — тэр нэхэмжлэхийг доорх 5-р алхмаар шинэ дугаар руу **дахин илгээ**.

## 5. Нэг хүүхдэд дахин илгээх {#dahin}
1. **Тооцоо → Нэхэмжлэх** цэсийг нээ.
2. «Идэвхтэй» нэг нэхэмжлэхийг чагтал.
3. **«SMS илгээх»** эсвэл **«И-мэйл илгээх»** дар.
4. Утас, имэйлийг шалгаад **«Илгээх»**. Энд өөрчилбөл зөвхөн энэ илгээлтэд хэрэглэнэ.

→ [SMS эсвэл имэйлээр илгээх](/kidspace/nehemjleh-ilgeeh#ilgeeh)

## ⚠️ Анхаар {#anhaar}
- SMS үйлчилгээ хүлээж аваагүй үед систем дахин илгээж болох ч **шөнө дахин илгээдэггүй** — Улаанбаатарын 08:00–21:00 цагт л. Бусад алдаанд өөрөө дахин илгээхгүй — 5-р алхмаар илгээ.
- Цуцлагдсан эсвэл төлөгдсөн нэхэмжлэхийн SMS-ийг дахин илгээхгүй.
- «Хариу удаж байна — сервер хадгалсан байж магадгүй» гарвал **дахин бүү дар**. Жагсаалтыг шинэчилж илгээгдсэн эсэхийг шалга.
- Эцэг эх нэхэмжлэхийг **нийтийн холбоосоор** ч харж болно. → [Нийтийн холбоос](/kidspace/nehemjleh-ilgeeh#holboos)
