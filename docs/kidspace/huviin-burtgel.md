# Хувийн бүртгэл (Тохиргоо)

> 🏢 Эрхлэгч, менежер, багш · Вэб · Толгойн мөрийн **⚙ Тохиргоо** (утсан дээр **⋮ → Тохиргоо**)

Өөрийн нэр, зураг, нууц үг, ажлын талбараа энд харна. Бусдын мэдээллийг биш, **зөвхөн өөрийнхийгөө** засна. Энэ дэлгэцийг хүн бүр нээнэ, эрх шаардлагагүй.

Дэлгэцийн гарчиг **«Хувийн бүртгэл»**, гурван хэсэгтэй: **Миний мэдээлэл** · **Аюулгүй байдал** · **Ажлын талбар**.

## Миний мэдээлэл {#medeelel}
| Талбар | Засах уу | Тайлбар |
|---|---|---|
| Нэр | ✅ | Заавал. 128 тэмдэгт хүртэл |
| Овог | ✅ | 128 тэмдэгт хүртэл |
| Төрсөн огноо | ✅ | |
| Хүйс | ✅ | Эрэгтэй / Эмэгтэй |
| Имэйл | ✅ | Буруу хэлбэртэй бол «Зөв имэйл хаяг оруулна уу.» |
| Утас | ❌ | Нэвтрэх дугаар тул энд солихгүй |
| Үүрэг | ❌ | Эзэн / Захирал · Менежер · Багш · Ажилтан |
| Цэцэрлэг | ❌ | Хоосон бол **«Бүх салбар»** |
| Ажлын талбар | ❌ | Байгууллага |

**Үүрэг**, **Цэцэрлэг**-ийг эрхлэгч, менежер **Байгууллага → «Багш, ажилчид»**-аас сольдог. → [Эрх өгөх, солих](/kidspace/erhgui#erh-ogoh)

### Профайл зураг {#zurag}
1. **«Зураг сонгох»** (зурагтай бол **«Зураг солих»**) дарж файлаа сонго.
2. «Шинэ зураг · Хадгалаагүй» гэж харагдана. **Хадгалах** дарж байж солигдоно.
3. Зургаа авахыг хүсвэл **«Зураг хасах»** → Хадгалах.

Файл: JPG, JPEG, PNG, GIF, WEBP, HEIC · **10 МБ хүртэл**. «Зураг байршуулж чадсангүй» гарвал холболтоо шалгаад дахин оролд.

## Аюулгүй байдал {#ayulgui}
**«Нууц үг солих»** товч нууц үг солих хуудсыг нээнэ. → [Нууц үг солих, мартсан](/kidspace/nuuts-ug)

## Ажлын талбар {#ajlyn-talbar}
Таны ажилладаг байгууллага, цэцэрлэгүүдийн жагсаалт. Одоо ажиллаж байгаа нь **«Идэвхтэй»** тэмдэгтэй. Нэгээс олон бол **«Ажлын талбар солих»** товч гарна. → [Ажлын талбар, урилга](/kidspace/ajlyn-talbar)
