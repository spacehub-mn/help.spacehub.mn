# Ирцээр бодох төлбөр

> 💡 Ойлголт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб

Зарим үйлчилгээ (жишээ нь хоол) сарын дүнгээ **Ирц журнал**-ын бүртгэлээс бодно. Тиймээс **ирц буруу бол төлбөр буруу**.

## Үйлчилгээний 4 тохиргоо {#tohirgoo}
| Талбар | Утга |
|---|---|
| **«Ирцийн тооцоолол»** | **«Сарын үнийн харьцаа»** — өдрийн үнэ = сарын үнэ ÷ тухайн сарын ажлын өдөр; **«Өдрийн үнээр»** — «Өдрийн үнэ (₮)»-д бичсэнээр |
| **«Тоологдох ирц»** | Ирцийн аль төлөвийг ирсэн өдөрт тоолох |
| **«Бүтэн сарын нөхцөл»** | «Ирсэн», «Ирээгүй» эсвэл «Идэвхгүй» (босгогүй) |
| **«Босго өдөр»** | Бүтэн сар болох өдрийн тоо |

**Жишээ:** «Ирсэн» + босго 13 → 13 ба түүнээс олон өдөр ирсэн бол **бүтэн сарын** үнэ, цөөн бол **өдрийн үнэ × ирсэн өдөр**. «Ирээгүй» бол ирээгүй өдрийн тоо босгод хүрэхэд бүтэн сар.

→ Дэлгэрэнгүй: [Ирцээр бодогдох төлбөр](/kidspace/tolbor-nehemjleh#irtsiin-tolbor)

## Аль сарын ирц вэ {#al-sar}
Багцын **горимоос** хамаарна:
- **«Дараа сард (тухайн сарын ирцээр)»** — сар дууссаны дараа тэр сарын ирцээр.
- **«Урьдчилж (өмнөх сарын ирцээр)»** — 11-р сарын нэхэмжлэх = 10-р сарын ирц. Анхны сар бүтэн сараар.

→ [«Урьдчилж» горим](/kidspace/tolbor-nehemjleh#uridchilj-tootsoo)

## Ирц зассан бол {#zassan}
Бичигдсэн төлбөр **өөрөө өөрчлөгдөхгүй**:
1. Нэхэмжлэхгүй төлбөр → элсэлтийн «Төлбөр» таб → **«Ирцээр дахин бодох»**.
2. Нэхэмжлэхтэй → эхлээд нэхэмжлэхээ цуцал, дараа нь 1.
3. 0 ₮ гарч «Алгассан» болсон → **«Дахин нээх»**.

→ [Төлбөр цуцлаад дахин үүсгэх](/kidspace/tolbor-jagsaalt#tsutslaad-dahin) · [«Алгассан» сар](/kidspace/tolboriin-huvaar#dahin-neeh)

## ⚠️ Анхаар {#anhaar}
- Хожуу бүртгэсэн хүүхдэд **эхлээд ирц, дараа нь төлбөр**. → [Элсэх огноо өнгөрсөн бол](/kidspace/ehleh-ognoo-zasah#ongorson-ognoo)
- Бүтэн сар өвчтэй байсан хүүхдийн дараагийн сар 0 ₮ гарч болно. → [«Энэ сараар үүсгэх»](/kidspace/tolboriin-huvaar#ene-saraar)
