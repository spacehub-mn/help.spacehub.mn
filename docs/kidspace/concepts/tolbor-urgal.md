# Хуваарь → Төлбөр → Нэхэмжлэх → Төлөлт

> 💡 Ойлголт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Тооцоо**

Нэг хүүхдийн сарын мөнгө дөрвөн шатаар явна:

```
Хуваарь (төлөвлөсөн)  →  Төлбөр (төлөх ёстой)  →  Нэхэмжлэх (эцэг эх рүү)  →  Төлөлт (төлсөн)
```

| Шат | Цэс | Юу вэ | Хэн үүсгэх |
|---|---|---|---|
| **Хуваарь** | Тооцоо → Хуваарь | Хүүхэд × сар × багц тутмын төлөвлөгөө | Систем — элсэлтийн «Тохиргоо» табын багц, үнээс |
| **Төлбөр** | Тооцоо → Төлбөр | Тухайн сарын дүн. Хөнгөлөлт тусдаа баримт, **«Төлөх»** = дүн − хөнгөлөлт | Төлбөрийн ажиллагаа эсвэл хуваарийн мөрөөс гараар |
| **Нэхэмжлэх** | Тооцоо → Нэхэмжлэх | Төлбөрөөс гаргаж SMS, имэйлээр явуулах баримт | Төлбөрийн ажиллагаа эсвэл «Нэхэмжлэх үүсгэх» |
| **Төлөлт** | Тооцоо → Төлөлт | Эцэг эхийн төлсөн мөнгө | Гараар эсвэл дансны хуулгаас холбох |

Буцаах мөнгийг **Тооцоо → Буцаалт**-д бүртгэнэ.

## Систем сар бүр өөрөө бодох уу {#ooroo}
Үгүй. **Төлбөрийн ажиллагааг** менежер сар бүр, цэцэрлэг бүрд үүсгэнэ. Нэг ажиллагаа = нэг цэцэрлэг × багц (эсвэл «Бүгд») × сар. → [Төлбөрийн ажиллагаа](/kidspace/tolboriin-ajillagaa)

## Хоёр горим {#gorim}
Багц бүр аль нэг горимоор бодогдоно (багцын жагсаалтын **«Горим»** багана):
- **«Дараа сард (тухайн сарын ирцээр)»** — сар дууссаны дараа тэр сарын ирцээр.
- **«Урьдчилж (өмнөх сарын ирцээр)»** — анхны сар бүтэн сараар, дараагийн сар бүр өмнөх сарын ирцээр. Хүүхэд гарах, жил дуусах, эсвэл горимыг «Дараа сард» болгоход бүтэн сарын дүнг бодит дүнтэй тулгаж, илүүг **«Кредит-нот»**-оор буцаана.

→ Дэлгэрэнгүй: [«Урьдчилж» горим ба эцсийн тооцоо](/kidspace/tolbor-nehemjleh#uridchilj-tootsoo) · [Ирцээр бодогдох төлбөр](/kidspace/tolbor-nehemjleh#irtsiin-tolbor)

## Хөнгөлөлт хаана орох вэ {#honglolt}
- **Сар бүрийн** (багшийн хүүхэд, ах дүү) — элсэлтийн **«Тохиргоо» → «Багц»**-д. Ирээдүйн төлбөрт орно.
- **Нэг удаагийн** — **Тооцоо → Төлбөр** дээр нэг төлбөрт.

→ [Хөнгөлөлт](/kidspace/honglolt)

## Буруу болсныг засах дараалал {#zasah}
Урвуу дарааллаар: илүү **нэхэмжлэх** цуцлах → **төлбөр** цуцлах → дахин үүсгэх. Төлсөн мөнгийг **төлөлт**, **буцаалтаар** зохицуулна.
