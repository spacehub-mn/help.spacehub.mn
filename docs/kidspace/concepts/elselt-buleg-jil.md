# Хичээлийн жил, бүлэг, элсэлт

> 💡 Ойлголт · 🏢 Эрхлэгч, менежер · Вэб

KidSpace-ийн бүх зүйл гурван давхаргаар уялдана:

```
Хичээлийн жил  →  Бүлэг (тухайн жилийн анги)  →  Элсэлт (хүүхэд × бүлэг × жил = гэрээ)
```

- **Хичээлийн жил** — нэг л жил **«Идэвхтэй»**. Шинэ элсэлт идэвхтэй жилд үүснэ.
- **Бүлэг** — жил бүрд тусдаа. Шинэ жилд **«Дараагийн жилд хуулах»**-аар хуулна (хүүхэд хуулагдахгүй).
- **Элсэлт** — хүүхдийн гэрээ. Төлбөрийн хуваарь, төлбөр, хөнгөлөлт, ирц бүгд **элсэлтэд** уягдана.

## Нэг хүүхэд — нэг жилд нэг гэрээ {#neg-geree}
Жилийн дунд бүлэг солиход **гэрээг хааж шинээр бүү нээ**. Төлбөрийн түүх, үлдэгдэл хуучин гэрээнд үлдэж, шинэ нь хоосон эхэлнэ. Оронд нь:

| Нөхцөл | Хийх зүйл |
|---|---|
| Жилийн дунд өөр бүлэгт | **«Анги шилжүүлэх»** — гэрээ, ирц хэвээр шилжинэ |
| Дараагийн хичээлийн жилд | **«Анги дэвшүүлэх»** — шинэ жилд шинэ гэрээ |
| Хүүхэд цэцэрлэгээс гарсан | Элсэлтийн **«Үйлдэл ▾» → «Гэрээ хаах»** |
| Андуурч хоёр бүртгэл үүссэн | **«Давхар хүүхэд нэгтгэх»** |

→ [Анги шилжүүлэх, дэвшүүлэх](/kidspace/angi-shiljuuleh-devshuuleh) · [Гэрээ хаах](/kidspace/elseltiin-haalt) · [Давхар хүүхэд нэгтгэх](/kidspace/davhar-huuhed-negtgeh)

## Элсэх огноо {#elseh-ognoo}
Төлбөрийн хуваарь элсэх огнооноос эхэлнэ. Огноо буруу бол гэрээг хаалгүй **огноог засна**. → [Эхлэх огноо засах](/kidspace/ehleh-ognoo-zasah)

## Шинэ хичээлийн жил {#shine-jil}
1. Шинэ жилийг **бэлтгэх** («Бэлтгэж буй»). → [Хичээлийн жил](/kidspace/hicheeliin-jil)
2. Бүлгээ **хуулах**. → [Бүлгүүд](/kidspace/bulguud#huulah)
3. Хүүхдүүдээ **дэвшүүлэх**. → [Анги дэвшүүлэх](/kidspace/angi-shiljuuleh-devshuuleh#devshuuleh)
