# Хөнгөлөлт, кредит-нот, буцаалт — ялгаа

> 💡 Ойлголт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Тооцоо**

Дөрвөн өөр зүйл **төлөх дүнг** багасгадаг ч утга, хаанаас хийх нь өөр:

| | Юу вэ | Хаанаас | Төлбөрийн «Дүн» |
|---|---|---|---|
| **Сар бүрийн хөнгөлөлт** | Багшийн хүүхэд, ах дүү — ирээдүйн сар бүрт | Элсэлт → «Тохиргоо» → «Багц» | Хэвээр, хөнгөлөлт тусдаа баримт |
| **Нэг удаагийн хөнгөлөлт** | Нэг төлбөрт төгрөгөөр | Тооцоо → Төлбөр → «Хөнгөлөлт» | Хэвээр, хөнгөлөлт тусдаа баримт |
| **Кредит-нот** | «Урьдчилж» горимын илүү нэхэмжилсэн дүнг систем буцаан бууруулна | Систем өөрөө (эцсийн тооцоонд) | — |
| **Төлбөр цуцлах** | Буруу бичигдсэн төлбөрийг бүхэлд нь хүчингүй болгох | Тооцоо → Төлбөр → «Цуцлах» | Төлбөр хүчингүй |

**«Төлөх»** = дүн − хөнгөлөлт. → [Хөнгөлөлт](/kidspace/honglolt)

## Буцаалт — мөнгө гарах {#butsaalt}
**Буцаалт** нь эцэг эхэд **мөнгө буцааж өгснийг бүртгэх**. Мөнгийг та өөрсдөө (бэлнээр, дансаар) шилжүүлнэ — систем шилжүүлэхгүй.
- Илүү төлсөн → **Тооцоо → Буцаалт** эсвэл төлөлтөөс. → [Буцаалт](/kidspace/butsaalt) · [Төлөлтөөс буцаалт](/kidspace/tolult#butsaalt)
- Хаагдсан гэрээний илүү төлөлт → элсэлтийн **«Хаалт»** табаас. → [Гэрээ хаах](/kidspace/elseltiin-haalt)

## Аль нь вэ {#al-ni}
- Төлбөр **буруу** бичигдсэн (ирц, огноо, үнэ) → **цуцлаад дахин үүсгэ**, хөнгөлөлт бүү хий. → [Төлбөр цуцлаад дахин үүсгэх](/kidspace/tolbor-jagsaalt#tsutslaad-dahin)
- Зөв төлбөрийг **санаатайгаар** багасгах → **хөнгөлөлт**.
- Эцэг эх **илүү төлсөн** → дараагийн сарын үлдэгдэлд үлдээх эсвэл **буцаалт**.
- Ах дүүгийн хөнгөлөлт автоматаар бодогдохгүй — хүүхэд бүрд гараар.

## ⚠️ Анхаар {#anhaar}
- Баталгаажсан төлбөрт ашигласан хөнгөлөлтийг цуцлах боломжгүй.
- Хаагдсан тайлант үеийн баримтыг засахгүй. → [Тайлант үе хаах](/kidspace/tailant-uye-haah)
