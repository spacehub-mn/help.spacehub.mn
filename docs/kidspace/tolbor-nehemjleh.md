# «Төлбөр» ба «Нэхэмжлэх» — ялгаа, хаанаас харах

> 🏢 Цэцэрлэгийн менежер, нягтлан · Вэб · Цэс: **Тооцоо**

## Ялгаа
- **Төлбөр** (**Тооцоо → Төлбөр**) — хүүхэд бүрийн **сар × багц** тутмын тооцоо. Баганууд: «Хүүхэд, Багц, Тайлбар, Дүн, Хөнгөлөлт, Төлөх, Төлөх хугацаа, Төлөв, Нэхэмжлэх».
- **Нэхэмжлэх** (**Тооцоо → Нэхэмжлэх**) — эцэг эх рүү **явуулах** баримт. Төлбөрөөс үүснэ. Эндээс «Хэвлэх», «И-мэйл илгээх», «SMS илгээх».

Өөрөөр хэлбэл: эхлээд **төлбөр** бодогдоно, дараа нь түүнээс **нэхэмжлэх** гаргаж илгээнэ. Төлбөр үүссэн ч нэхэмжлэх нь үүсээгүй байж болно.

## Хэрхэн үүсдэг {#hereh-uusdeg}
- **Авто туслагч → Төлбөрийн ажиллагаа** — нэг ажил = нэг **цэцэрлэг** × **багц** (эсвэл «Бүх багц») × **төлбөрийн сар**. Анхдагчаар төлбөр үүсгэж, нэхэмжлэх үүсгээд, илгээнэ.
- Систем ажиллагааг **өөрөө үүсгэдэггүй**. Сар бүр, цэцэрлэг бүрд менежер «Шинэ»-ээр үүсгэнэ.
- Гараар: **Тооцоо → Төлбөр** → нэг төлбөрийг чагталж **«Нэхэмжлэх үүсгэх»**. Урьдчилан харсны дараа **«Хадгалах»**.

## «Энэ сарын төлбөр цөөхөн хүүхдэд үүссэн» {#tsoohon}
Дараахыг шалга:
1. **Ажиллагаа бүх цэцэрлэг, багцад үүссэн үү.** Нэг ажил зөвхөн нэг цэцэрлэг, нэг багцын (эсвэл «Бүх багц») нэг сарыг хамарна.
2. **Багц «сар дууссаны дараа» бодогддог уу.** Ийм багцын сарын төлбөр **тэр сар дууссаны дараа** л үүснэ. Урьдчилж бодогддог багц нэхэмжлэх өдрөөсөө үүснэ.
3. **Өмнөх сар нь бодогдоогүй хүүхэд** алгасагдана. Ажиллагааны **«Алгассан»** тоо, шалтгаанаас хар. Өмнөх сарыг бодсоны дараа ажиллагааг дахин ажиллуул.
4. Тэр сар нь **цуцлагдсан эсвэл хөлдөөсөн** хүүхэд «Алгассан» болно.
5. Хүүхдийн багц **унтраалттай** бол төлбөр үүсэхгүй.

Жагсаалтын талаас:
- **Тооцоо → Төлбөр**-д **сарын шүүлт байхгүй**. Сарыг **«Тайлбар»** баганаас хар. Анхдагч шүүлт: «Хичээлийн жил» = одоогийн, «Төлөв» = «Идэвхтэй» (цуцалсан нь нуугдана).
- Доод нийлбэр нь **дэлгэцэнд харагдаж буй** мөрүүдийнх л.
