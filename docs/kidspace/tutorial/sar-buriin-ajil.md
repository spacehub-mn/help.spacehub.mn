# Сар бүрийн ажил

> 📘 Сургалт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб

Цэцэрлэг тохируулагдсаны дараа сар бүр давтагдах ажил. Анх тохируулж байгаа бол эхлээд [Эхний 7 хоног](/kidspace/nevtruulelt)-ийг уншина уу.

## Өдөр бүр {#odor-bur}
- **Багш** — **Ирц журнал**-аа бөглөнө. Ирцээр бодогддог багцын төлбөр үүнээс бодогдоно. → [Ирц журнал](/kidspace/irts-zhurnal)
- **Менежер** — **Элсэлт → Хүсэлт**, **Харилцаа → Санал хүсэлт**-ийг шалгана. → [Элсэлтийн хүсэлт](/kidspace/elseltiin-huselt) · [Санал хүсэлт](/kidspace/sanal-huselt)

## Нэхэмжлэх өдөр {#nehemjleh-odor}
1. **Авто туслагч → Төлбөрийн ажиллагаа → «Шинэ»** — **цэцэрлэг бүрд** нэг. Систем өөрөө үүсгэдэггүй. → [Шинэ ажиллагаа](/kidspace/tolboriin-ajillagaa#shine)
2. Ажиллагааны **«Алгассан»** тоо, шалтгааныг хар. Цөөхөн хүүхдэд үүссэн бол → [шалгах 5 зүйл](/kidspace/tolbor-nehemjleh#tsoohon).
3. **Тооцоо → Нэхэмжлэх** — эцэг эхэд очсон эсэх. → [Нэхэмжлэх илгээх](/kidspace/nehemjleh-ilgeeh)

## Төлөлт орж ирэхэд {#tolult}
1. **Авто туслагч → Дансны хуулга** — «Холбогдоогүй» гүйлгээг **«Төлөлт шалгах»**-аар холбо. Гүйлгээний утгад гэрээний код байвал шууд холбогдоно. → [Дансны хуулга](/kidspace/dansnii-huulga#avtomat)
2. Бэлэн, картаар төлсөн бол **Тооцоо → Төлөлт**-д гараар бүртгэ. → [Төлөлт бүртгэх](/kidspace/tolult#burtgeh)
3. Хуулга татагдаагүй бол **Авто туслагч → Хуваарьт ажил**-аас ажилласан эсэхийг хар. → [Хуваарьт ажил](/kidspace/huvaariin-ajil)

## Сарын эцэс {#sar-etses}
1. **Тайлан → Сарын тооцоо** — бүлгийн тооцоог багштай нийлж, өртэй хүүхдийг гарга. → [Сарын тооцоо](/kidspace/saryn-tootsoo-tailan)
2. Гарсан хүүхдийн гэрээг **Элсэлт → Хаалт**-аар хаа. → [Гэрээ хаах](/kidspace/elseltiin-haalt)
3. Нягтлан тайлангаа гаргасны дараа **тайлант үеийг хаана** — хуучин сарын тоо өөрчлөгдөхгүй. → [Тайлант үе хаах](/kidspace/tailant-uye-haah)

## ⚠️ Анхаар {#anhaar}
- Нэг төлбөрт хоёр дахь нэхэмжлэх үүсгэвэл өмнөх нь хэвээр үлдэнэ — илүүг цуцал. → [Нэхэмжлэх цуцлах](/kidspace/nehemjleh-ilgeeh#tsutslah)
- «Хариу удаж байна — сервер хадгалсан байж магадгүй» гарвал **дахин бүү дар**. Жагсаалтыг шинэчилж шалга.
