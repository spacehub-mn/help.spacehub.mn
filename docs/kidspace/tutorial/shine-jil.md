# Шинэ хичээлийн жилд шилжих

> 📘 Сургалт · 🏢 Эрхлэгч, менежер · Вэб

Жил бүрийн эцэст хийх дараалал. **Дарааллыг бүү солих** — идэвхжүүлэхэд хуучин жил хаагдана.

## 1. Шинэ жилийг бэлтгэх {#beltgeh}
**Байгууллага → «Тохиргоо» → «Хичээлийн жил» → «Шинэ жил бэлтгэх»**. Шинэ жил **«Бэлтгэж буй»** төлөвтэй үүснэ, одоогийн жил идэвхтэй хэвээр. Бүлэг, элсэлт, тохиргоо **автоматаар хуулагдахгүй**. → [Шинэ жил бэлтгэх](/kidspace/hicheeliin-jil#beltgeh)

## 2. Бүлгээ хуулах {#buleg}
Бүлгийн карт → **«Дараагийн жилд хуулах»**. Хүүхэд хуулагдахгүй. Шинэ бүлэг нэмэх бол → [Шинэ бүлэг](/kidspace/bulguud#shine-buleg)

## 3. Хүүхдүүдээ дэвшүүлэх {#devshuuleh}
Бүлгийн карт → **«Анги дэвшүүлэх»** (бүлгийн бүх хүүхэд) эсвэл **Элсэлт → Бүртгэл**-ээс чагтлаад.
1. **«Зорилтот жил»** = шинэ жил.
2. **«Урьдчилан харах»** — хүүхэд бүр **Дэвшсэн / Төгссөн / Алгассан**. Энэ үед юу ч хадгалагдахгүй.
3. **«Дэвшүүлэх»**. Бэлтгэл бүлэгт **«Төгсгөх»**.

Дэвшсэн хүүхэд бүрд шинэ жилийн **шинэ гэрээ**, шинэ **төлбөрийн хуваарь** үүснэ. → [Анги дэвшүүлэх](/kidspace/angi-shiljuuleh-devshuuleh#devshuuleh)

## 4. Урьдчилгаа төлбөр (заавал биш) {#uridchilgaa}
Шинэ жилийн урьдчилгааг шинэ жилд оноох бол жилээ чагталаад **«Элсэлт эхлэх огноо»**. Тэр өдрөөс орсон төлөлт шинэ жилд оноогдоно. → [Элсэлт эхлэх огноо](/kidspace/hicheeliin-jil#elselt-ehleh)

## 5. Шинэ жилийг идэвхжүүлэх {#idevhjuuleh}
Бүлэг, элсэлт бэлэн болсны **дараа** «Бэлтгэж буй» жилийг чагтлаад **«Идэвхжүүлэх»**. Одоогийн идэвхтэй жил **хаагдана**. → [Идэвхжүүлэх](/kidspace/hicheeliin-jil#idevhjuuleh)

## 6. Шалгах {#shalgah}
- **Тооцоо → Хуваарь** — шинэ жилийн саруудад «Төлөвлөсөн» мөр гарсан эсэх.
- Гарах хүүхдүүдийн гэрээг **Элсэлт → Хаалт**-аар хаа. → [Хүүхэд гарахад](/kidspace/tutorial/huuhed-garah)

## ⚠️ Анхаар {#anhaar}
- Жилийн **дунд** «Анги дэвшүүлэх» хийвэл хүүхэд энэ жилийн бүлэгтээ үлдэнэ. Жилийн дунд бүлэг солих бол «Анги шилжүүлэх».
- Дахин ажиллуулахад давхар гэрээ **үүсэхгүй** — аль хэдийн дэвшсэн хүүхэд «Алгассан» гарна.
