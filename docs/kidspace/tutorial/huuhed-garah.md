# Хүүхэд гарахад

> 📘 Сургалт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Үндсэн → Элсэлт**

Хүүхэд цэцэрлэгээс гарахад хийх дараалал. Өөр **ангид шилжиж** байгаа бол гэрээ **бүү хаа** — «Анги шилжүүлэх». → [Анги шилжүүлэх](/kidspace/angi-shiljuuleh-devshuuleh#shiljuuleh)

## 1. Сүүлийн өдрүүдийн ирцээ бөглө {#irts}
Хаах сарын төлбөр өдрөөр (ирцээр бодох үйлчилгээ ирцээр) бодогдоно. Эхлээд ирцээ гүйцээ. → [Ирц журнал](/kidspace/irts-zhurnal)

## 2. Гэрээ хаах {#haah}
Элсэлтийн хуудас → **«Үйлдэл ▾» → «Гэрээ хаах»**.
1. **«Хаах огноо»** — хүүхдийн сүүлийн өдөр нь хаах огнооны **өмнөх** өдөр.
2. **«Шалтгаан»** — «Төгссөн», «Шилжсэн», «Эцэг эхийн хүсэлт», «Төлбөр», «Бусад».
3. **«Хаалтын үр дагавар»**-ыг уншаад **«Гэрээ хаах»**.

→ [Гэрээ хаах](/kidspace/elseltiin-haalt#geree-haah)

## 3. Аль хэдийн гарсан төлбөрийг шалга {#tolbor}
Хаах огнооноос хойш **шинэ** төлбөр бодогдохгүй. Харин **аль хэдийн гарсан** төлбөр өөрөө өөрчлөгдөхгүй — хаах цонхонд жагсаасан төлбөрийг элсэлтийн **«Төлбөр»** табаас хүчингүй болгох эсвэл хөнгөлөлтөөр зас. → [Гэрээ хаах — Анхаар](/kidspace/elseltiin-haalt#anhaar)

«Урьдчилж» горимд систем бүтэн сарын төлбөрийг бодит дүнтэй **дараагийн нэхэмжлэх өдөр** тулгаж, илүүг **кредит-нот**-оор бууруулна. → [Эцсийн тооцоо](/kidspace/tolbor-nehemjleh#uridchilj-tootsoo)

## 4. Өр эсвэл илүү төлөлт {#uldegdel}
Элсэлтийн **«Хаалт»** табаас шийднэ. Илүү төлсөн мөнгийг эцэг эхэд буцаасан бол **«Буцаах»**. → [Хөнгөлөлт, кредит-нот, буцаалт](/kidspace/concepts/honglolt-butsaalt#butsaalt)

## 5. Андуурч хаасан бол {#sergeeh}
**Элсэлт → Хаалт** → мөрийг чагтлаад **«Сэргээх»**. Цуцлагдсан сарууд хуваарьт буцна. Хаалтын үед хийсэн өр хасалт, шилжүүлэг **буцахгүй**. → [Сэргээх](/kidspace/elseltiin-haalt#sergeeh)

## ⚠️ Анхаар {#anhaar}
- Сарын 1-нд хаавал тэр сар бүхэлдээ цуцлагдана.
- Хаах огноо ирээдүйд, эсвэл гэрээ эхэлсэн өдрөөс өмнө байж болохгүй. Эхлээгүй гэрээг хаахгүй — огноог засна. → [Эхлэх огноо засах](/kidspace/ehleh-ognoo-zasah)
