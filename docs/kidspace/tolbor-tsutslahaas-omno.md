# Төлбөр цуцлахаас өмнө — «Урьдчилж» горим ба багц солих

> 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Үндсэн → Элсэлт → Бүртгэл** → хүүхэд → **«Төлбөр»** / **«Хуваарь»** / **«Хаалт»** таб

Төлбөрийг цуцлаад дахин үүсгэх нь заримдаа асуудлыг шийдэхгүй, харин шинэ асуудал үүсгэдэг. Энэ хуудас хамгийн түгээмэл 2 тохиолдлыг тайлбарлана.

## 1. «Урьдчилж» горимд төлбөр бүтэн дүнгээр гарсан {#uridchilj-butend}
«Урьдчилж (өмнөх сарын ирцээр)» горимтой багцад:
- **Горимын анхны сар бүтэн сараар** бодогдоно — энэ нь урьдчилгаа. Цуцлаад дахин үүсгэсэн ч **дахиад бүтэн дүн** гарна.
- Тухайн сарын **ирц дараагийн сарын төлбөрт** хэмжигдэнэ. Жишээ нь 10-р сард ирсэн өдрүүд **11-р сарын** төлбөрт орно.
- Хүүхэд гарахад систем урьдчилгааг сүүлийн сарын бодит дүнтэй **эцсийн тооцоогоор** тулгана.

**Тухайн сарын ирсэн өдрөөр (хоногоор) бодуулах бол:**
1. **«Хуваарь»** таб → ирцийг нь хэмжих **дараагийн сарыг** сонго (10-р сарын ирц бол 2026.11).
2. **«Төлбөр загвар»** → **«Хоногоор»**.
3. Тэр сарын төлбөр аль хэдийн гарсан бол **«Төлбөр»** таб → тэр төлбөрийг сонгоод **«Ирцээр дахин бодох»**.
4. Урьдчилан харахад **ирсэн өдөр × хоногийн төлбөр** гарна — дүнг шалгаад баталгаажуул.

⚠️ Урьдчилгаа сарын төлбөрийг **цуцлаад орхиж болохгүй**. Тэр сар «Төлөвлөсөн» хэвээр үлдвэл дараагийн сарын төлбөр **гарахгүй**. Систем «Эхлээд … сарын төлбөрийг бичнэ үү» гэж алгасна. Цуцалсан бол **«Хуваарь» → тэр сар → «Төлбөр үүсгэх»**-ээр буцааж үүсгэ.

→ Дэлгэрэнгүй: [«Урьдчилж» горим ба эцсийн тооцоо](/kidspace/tolbor-nehemjleh#uridchilj-tootsoo) · [Ирцээр бодох төлбөр](/kidspace/concepts/irts-tolbor#al-sar)

## 2. Хөнгөлөлтийн багц сольсны дараа өр харагдсан {#bagts-solih}
Хүүхдийг өөр багц руу (жишээ нь «Сургалтын багц» → «Сургалтын багц - 5%») шилжүүлэхдээ хуучин багцын төлбөрийг цуцлаад шинэ багцад үүсгэвэл:
- Төлсөн мөнгө **хуучин багцад «илүү төлөлт»** болж үлдэнэ.
- Шинэ багцын төлбөр **«өр»** болж харагдана — нийт дүнгээр өргүй ч тайлан, «Сарын тооцоо»-нд өр гарна.

Баланс **багц тус бүрээр** бодогддог тул мөнгийг шинэ багц руу шилжүүлнэ:

1. Хүүхдийн **«Хаалт»** таб → илүү төлөлттэй багцын мөрөнд **«Шилжүүлэх»**.
2. «Илүү төлөлт шилжүүлэх» цонхонд **«Багц»**-аас шинэ багцаа сонго.
3. Дүн, шалтгаан, огноо оруулаад **«Шилжүүлэх»**. Идэвхтэй гэрээнд мөнгө зөвхөн **тухайн гэрээний өөр багц** руу шилжинэ (хос баримт үүснэ).

⚠️ Цуцалсан саруудын төлбөр шинэ багцад **өөрөө гарахгүй** байж болно. «Хуваарь» табаас сар бүрийг шалга. «Төлөвлөсөн» үлдсэн сарыг **«Төлбөр үүсгэх»**-ээр үүсгэ.
