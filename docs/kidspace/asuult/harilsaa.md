# Түгээмэл асуулт: эцэг эхтэй харилцаа

> ❓ Түгээмэл асуулт · 🏢 Эрхлэгч, менежер, багш · Вэб · Цэс: **Үндсэн → Элсэлт → Хүсэлт** · **Үндсэн → Харилцаа**

## Эцэг эхийг апп-д яаж урих вэ {#urilga}
**Элсэлт → Хүсэлт**-ээс урилга үүсгэнэ. SMS «илгээж чадсангүй» гэвэл холбоосыг **«Хуулах»**-аар хуулж өөрөө явуул. Холбоосоо хуулалгүй хаавал дахин харах боломжгүй — урилгыг цуцлаад шинээр үүсгэ. → [Эцэг эхэд урилга явуулах](/kidspace/elseltiin-huselt#urilga)

## Хүсэлт зөвшөөрөхөд «Энэ утасны дугаар аль хэдийн бүртгэлтэй байна» {#utas}
Ийм утастай асран хамгаалагч бүртгэлтэй. **Элсэлт → Бүртгэл**-д хүүхэд байгаа эсэхийг шалга. Байхгүй бол «+ Шинэ» → «Бүртгэлтэй хүүхэд», эсвэл «Энэ утсаар бүртгэлтэй гэр бүлд хүүхэд нэмэх». → [Элсэлтийн хүсэлт](/kidspace/elseltiin-huselt#asuult)

## Санал хүсэлтэд хариу бичиж болохгүй байна {#hariu}
«Энэ хүсэлт хаагдсан — хариу бичих боломжгүй» — хүсэлт аль хэдийн шийдвэрлэгдсэн. Жагсаалтад харагдахгүй бол «Хичээлийн жил»-ийг «Бүх жил» болгож, «Хариуцагч», «Төлөв» шүүлтийг шалга. → [Санал хүсэлт](/kidspace/sanal-huselt)

## Чөлөөний хүсэлт ирлээ {#chuluu}
Санал хүсэлтээс зөвшөөрнө. → [Чөлөөний хүсэлт зөвшөөрөх](/kidspace/sanal-huselt#chuluu)

## Нийтлэлийн «Шинэ» товч алга / «Бүлэг сонгоно уу» {#niitlel}
Нийтлэл бичих эрх таны үүрэгт алга — эрхлэгчид хандана уу. «Бүлэг» хүрээтэй бол бүлгээ заавал сонго. → [Нийтлэл](/kidspace/niitlel)

## Нуусан нийтлэл, сэтгэгдлээ хаанаас олох вэ {#nuusan}
**Харилцаа → Нуусан агуулга**-аас. Тэндээс сэргээнэ. → [Нуусан агуулга](/kidspace/nuusan-aguulga)

## Эцэг эх зохисгүй зүйл мэдээлсэн {#medeelel}
**Харилцаа → Мэдээлэл хянах**-аас шийдвэрлэнэ (зөвхөн эрхлэгч, менежерт). → [Мэдээлэл хянах](/kidspace/medeelel-hyanah)
