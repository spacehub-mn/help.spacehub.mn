# Түгээмэл асуулт: төлөлт, дансны хуулга

> ❓ Түгээмэл асуулт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Авто туслагч → Дансны хуулга** · **Тооцоо → Төлөлт**

## Эцэг эх төлсөн ч «төлөөгүй» харагдаж байна {#tolsun}
Гүйлгээ хүүхэдтэй **холбогдоогүй**. Систем гүйлгээний утгаас **«Гэрээний №»** (6 оронтой) эсвэл нэхэмжлэхийн кодыг хайдаг. **Дансны хуулга** → «Холбогдоогүй» → мөрийг чагтлаад **«Холбох»**. → [Төлсөн ч төлөөгүй харагдах](/kidspace/tolbor-nehemjleh#tolsun-ch-ulaan)

## Ах дүү хоёрын төлбөр нэг гүйлгээгээр орсон {#ah-duu}
«Холбох» цонхонд **«+ Шинэ»** эсвэл «+ … (ах дүү)»-гээр хоёр дахь хүүхдийг нэмж, дүнг хуваа. «Үлдэгдэл 0 ✓» болсны дараа **«Холбох»**. → [Шар анхааруулга](/kidspace/dansnii-huulga#anhaaruulga)

## Олон сарын төлбөрийг нэг дор шилжүүлсэн {#olon-sar}
**«Дүн»**-д гүйлгээний **бүтэн** дүнг оруул. Илүү нь дараагийн сарын урьдчилгаа болно.

## Гүйлгээ «Хэсэгчлэн» төлөвтэй үлдсэн {#heseg}
Дүнгийн нэг хэсгийг ямар ч хүүхдэд оноогоогүй — тэр хэсэг хэний ч тооцоонд орохгүй. Мөрийг дахин нээж үлдсэнийг оноо.

## Буруу хүүхэдтэй холбочихлоо {#buruu}
Мөрийг чагталж **«Төлөлт салгах»** → шалтгаанаа бичээд **«Төлөлт цуцалж салгах»**. → [Буруу холбосныг салгах](/kidspace/dansnii-huulga#salgah)

## Хуулга татагдаагүй / «Холбогдож чадсангүй» {#tatagdaagui}
**Авто туслагч → Хуваарьт ажил**-аас «Сүүлийн үр дүн»-г хар. Дараагийн ажиллалтыг хүлээ; давтагдвал, эсвэл «DNS алдаа», «Крон серверийн алдаа» гэвэл Spacehub багт хандана уу. → [Хуваарьт ажил](/kidspace/huvaariin-ajil#asuult)

## Excel хуулга оруулах уу {#excel}
**«+ Импорт»** → Excel файл → **«Урьдчилан харах»** → **«Баталгаажуулах»**. Одоогоор зөвхөн **Хаан банкны** хуулга. → [Excel хуулга](/kidspace/dansnii-huulga#excel)

## «Банкны данс үүсгээгүй байна» {#dans}
**Байгууллага → «Банкны данс»**-аас дансаа нэм.

## Бэлнээр төлсөн {#belen}
**Тооцоо → Төлөлт**-д гараар бүртгэ. «Хэлбэр»-ийг заавал сонго. → [Төлөлт бүртгэх](/kidspace/tolult#burtgeh)

## Эцэг эхэд хэлэх зөвлөмж {#zovlomj}
Гүйлгээний утгад нэхэмжлэх дээрх **«Гэрээний №»**-ийг бусад тоо, үсгээс **зайгаар** тусгаарлаж бич. Нэг гүйлгээнд нэг хүүхэд. **QPay**-ээр төлбөл код автоматаар орно.
