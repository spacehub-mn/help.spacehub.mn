# Түгээмэл асуулт: төлбөр, нэхэмжлэх

> ❓ Түгээмэл асуулт · 🏢 Эрхлэгч, менежер, нягтлан · Вэб · Цэс: **Тооцоо**

## Ирц, огноо, үнийг засчихлаа — төлбөр өөрчлөгдөхгүй байна {#dahin-bodoh}
Бичигдсэн төлбөр өөрөө өөрчлөгдөхгүй. Элсэлтийн **«Төлбөр»** табаас **«Ирцээр дахин бодох»**. Нэхэмжлэхтэй бол эхлээд нэхэмжлэхээ цуцал. → [Төлбөр цуцлаад дахин үүсгэх](/kidspace/tolbor-jagsaalt#tsutslaad-dahin)

## Сарын төлбөр 0 ₮ гараад «Алгассан» боллоо {#algassan}
Элсэлтийн **«Хуваарь»** табаас тэр сарыг **«Дахин нээх»** → ирцээ засах → **«Төлбөр үүсгэх»**. «Дахин нээх» эцэг эхэд юу ч илгээхгүй. → [«Алгассан» сарыг дахин нээх](/kidspace/tolboriin-huvaar#dahin-neeh)

## Энэ сарын төлбөр цөөхөн хүүхдэд үүссэн {#tsoohon}
Ажиллагаа бүх цэцэрлэг, багцад үүссэн эсэх, багц «сар дууссаны дараа» бодогддог эсэх, өмнөх сар нь бодогдоогүй хүүхэд байгаа эсэхийг шалга. → [Шалгах 5 зүйл](/kidspace/tolbor-nehemjleh#tsoohon)

## Эцэг эх төлсөн ч төлөөгүй харагдаж байна {#tolsun}
Гүйлгээ хүүхэдтэй **холбогдоогүй**. **Авто туслагч → Дансны хуулга** → «Холбогдоогүй» → **«Холбох»**. Эцэг эх гүйлгээний утгад **«Гэрээний №»**-ийг бичвэл автоматаар холбогдоно. → [Төлсөн ч төлөөгүй харагдах](/kidspace/tolbor-nehemjleh#tolsun-ch-ulaan)

## Нэг төлбөрт хоёр нэхэмжлэх үүсчихлээ {#hoyor-nehemjleh}
Илүүг **Тооцоо → Нэхэмжлэх**-ээс цуцал. → [Нэхэмжлэх цуцлах](/kidspace/nehemjleh-ilgeeh#tsutslah)

## Хүүхэд нэг сар ирээгүй — дараа сарын төлбөр 0 гарсан {#ireegui}
«Урьдчилж» горимын ирцээр бодогддог багцад энэ нь зөв: сар бүрийн төлбөр **өмнөх сарын ирцээр** бодогдоно. → [«Урьдчилж» горим](/kidspace/tolbor-nehemjleh#uridchilj-tootsoo)

## Ах дүүгийн хөнгөлөлт автоматаар бодогдох уу {#ah-duu}
Үгүй. Хүүхэд бүрийн элсэлтийн **«Тохиргоо» → «Багц»**-д гараар. Нэг удаагийнхыг **Тооцоо → Төлбөр** дээр. → [Хөнгөлөлт](/kidspace/honglolt)

## «Архивласан жил — засах боломжгүй» гэж гарна {#arhiv}
Хуучин хичээлийн жилийн төлбөрийг засах боломжгүй. Мөн **тайлант үе хаагдсан** бол хаасан огнооноос өмнөх баримтыг засахгүй. → [Тайлант үе хаах](/kidspace/tailant-uye-haah)

## «Хариу удаж байна — сервер хадгалсан байж магадгүй» {#udaj}
**Дахин бүү дар.** Жагсаалтыг шинэчилж орсон эсэхийг шалга. Давхар орсон бол илүүг цуцал. → [Төлөлт](/kidspace/tolult#asuult)

## Олон хүүхдэд нэг дор нэхэмжлэх илгээх үү {#olon}
**Авто туслагч → Төлбөрийн ажиллагаа**. Эхлээд «Төлбөр үүсгэх» хүртэл ажиллуулж шалгаад, дараа нь «Нэхэмжлэх илгээх» болго. → [Эхлээд шалгаад илгээх](/kidspace/tolboriin-ajillagaa#shalgaad)
