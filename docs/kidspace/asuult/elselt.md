# Түгээмэл асуулт: элсэлт, анги

> ❓ Түгээмэл асуулт · 🏢 Эрхлэгч, менежер · Вэб · Цэс: **Үндсэн → Элсэлт**

Цэцэрлэгүүдээс хамгийн их ирдэг асуултууд. Дэлгэрэнгүйг холбоосоор нь уншина уу.

## Хүүхэд өөр ангид шилжлээ. Шинэ элсэлт үүсгэх үү? {#shiljuuleh}
**Үгүй.** Элсэлтийн **«Үйлдэл» → «Анги шилжүүлэх»**. Гэрээ, төлбөрийн түүх, ирц хэвээр шинэ бүлэгт шилжинэ. Шинэ элсэлт үүсгэвэл хүүхэд хоёр болж, түүх хуучин гэрээнд үлдэнэ. → [Анги шилжүүлэх](/kidspace/angi-shiljuuleh-devshuuleh#shiljuuleh)

## Андуурч шинэ элсэлт үүсгэчихсэн — хүүхэд хоёр боллоо {#davhar}
**«Давхар хүүхэд нэгтгэх»** — хуучин бүртгэлийн ирц, хөгжлийн тэмдэглэлийг үлдэх хүүхэд рүү шилжүүлээд давхар бүртгэлийг устгана. → [Давхар хүүхэд нэгтгэх](/kidspace/davhar-huuhed-negtgeh)

## Шинэ хичээлийн жилд хүүхдүүдээ яаж оруулах вэ {#shine-jil}
Шинэ жил бэлтгэх → бүлгээ **«Дараагийн жилд хуулах»** → хүүхдүүдээ **«Анги дэвшүүлэх»**. Жилийн дунд «Анги дэвшүүлэх» хийвэл хүүхэд энэ жилийн бүлэгтээ үлдэнэ. → [Хичээлийн жил, бүлэг, элсэлт](/kidspace/concepts/elselt-buleg-jil#shine-jil)

## Элсэх огноо буруу байна {#ognoo}
Гэрээг хаалгүй **огноог засна**. Хүүхэд өмнө нь ирж эхэлсэн бол эхлээд өнгөрсөн сарын **ирцээ** тэмдэглэ, дараа нь тэр сарын **төлбөрийг** үүсгэ. → [Эхлэх огноо засах](/kidspace/ehleh-ognoo-zasah) · [Элсэх огноо өнгөрсөн бол](/kidspace/ehleh-ognoo-zasah#ongorson-ognoo)

## «Элсүүлэх» товч идэвхгүй байна {#elsuuleh}
Од (*) тэмдэгтэй талбар бөглөгдөөгүй, эсвэл элсэх огноо хичээлийн жилээс гадуур. → [Хүүхэд элсүүлэх](/kidspace/elselt-burtgel#asuult)

## «Идэвхтэй хичээлийн жил байхгүй» / «…элсэлт нээлттэй бүлэг алга» {#jil-buleg}
Нэг хичээлийн жил **«Идэвхтэй»** байх ёстой. Бүлгийн **«Элсэлт нээлттэй»** асаалттай байх ёстой. → [Хичээлийн жил](/kidspace/hicheeliin-jil) · [Шинэ бүлэг](/kidspace/bulguud#shine-buleg)

## Хүүхэд жагсаалтад харагдахгүй байна {#haragdahgui}
«Төлөв»-ийг «Бүгд» болго. Дээд талын хичээлийн жил, «Цэцэрлэг», «Бүлэг»-ийг шалга. → [Жагсаалтыг шүүх](/kidspace/elselt-burtgel#shuuh)

## Хүүхэд гарлаа. Яах вэ {#garsan}
Элсэлтийн **«Үйлдэл ▾» → «Гэрээ хаах»**. Андуурч хаасныг **Элсэлт → Хаалт**-аас **«Сэргээх»**-ээр буцаана. Эхлээгүй гэрээг хаах боломжгүй — огноог засна. → [Гэрээ хаах, сэргээх](/kidspace/elseltiin-haalt)

## Ах дүү хоёрыг нэг гэр бүлд яаж холбох вэ {#ah-duu}
Элсүүлэхдээ ах, эгчийнх нь **гэр бүлд нэмнэ**. → [Гэр бүлд нэмэх](/kidspace/elselt-burtgel#ger-bul). Ах дүүгийн хөнгөлөлт автоматаар бодогдохгүй — багцад гараар. → [Хөнгөлөлт](/kidspace/honglolt)
