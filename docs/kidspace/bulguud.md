# Бүлэг үүсгэх, багш томилох — «Анги / Бүлэг → Бүлгүүд»

> 🏢 Эрхлэгч, менежер · Вэб · Цэс: **Үндсэн → Анги / Бүлэг → Бүлгүүд**

## Энэ юу вэ {#ene-yu-ve}
Цэцэрлэгийн бүлгүүдийн жагсаалт. Бүлэг үүсгэх, багтаамж тохируулах, багш томилох, шинэ хичээлийн жилд бүлгээ хуулах газар.

## Хэзээ хэрэглэх {#hezee}
- Шинэ бүлэг нээх.
- Бүлгийн суудлын тоо (багтаамж) өөрчлөх.
- Бүлэгт багш томилох, чөлөөлөх.
- Шинэ хичээлийн жилд бүлгүүдээ бэлдэх.

## Түвшин {#tuvshin}
**Бага → Дунд → Ахлах → Бэлтгэл.** Анги дэвшүүлэхэд энэ дарааллаар шилжинэ. Бэлтгэл бүлгийнхэн төгсөнө.

## Шинэ бүлэг үүсгэх {#shine-buleg}
1. Дээд талд бүлэг үүсгэх **хичээлийн жилээ** сонго.
2. **Анги / Бүлэг → Бүлгүүд** цэсийг нээ.
3. **«+ Шинэ»** товчийг дар.
4. **«Нэр»**, **«Цэцэрлэг»**, **«Түвшин»**, **«Багтаамж»**-ийг бөглө.
5. Хүүхэд элсүүлэх бол **«Элсэлт нээлттэй»**-г асаа.
6. **«Хадгалах»** дар.

## Багтаамж өөрчлөх {#bagtaamj}
1. Бүлгийн карт дээр дарж нээ.
2. **«Бүлгийн мэдээлэл»** табаас **«Багтаамж»**-ийг өөрчил.
3. **«Хадгалах»** дар.

Багтаамж дүүрвэл картанд «Ангид элсэлт авч байгаа: Үгүй» гарна.

## Багш томилох {#bagsh-tomiloh}
1. Бүлгийг нээгээд **«Багш нар»** таб руу ор.
2. **«Томилох»** дар.
3. **«Ажилтан»**, **«Төрөл»** («Багш» эсвэл «Туслах багш»), **«Эхлэх огноо»**-г сонго.
4. **«Томилох»** дар.

Багш ажлаасаа гарвал мөрийн **«Чөлөөлөх»** дараад **«Дуусах огноо»** тавина. Тэр өдрийг дуустал эрх хүчинтэй, түүх устахгүй.

## Шинэ хичээлийн жилд бүлгээ хуулах {#huulah}
1. Эхлээд шинэ хичээлийн жил үүссэн, идэвхтэй эсэхийг шалга (**Байгууллага → Хичээлийн жил**).
2. **«Хүснэгт»** харагдац руу шилж.
3. Хуулах бүлгүүдээ чагтал.
4. **«Дараагийн жилд үүсгэх (N)»** → **«Үүсгэх»** дар.

Нэр, түвшин, багтаамж, цэцэрлэг, ажиллаж буй багш хуулагдана. **Хүүхэд, хуваарь, төлбөр хуулагдахгүй.** Хүүхдүүдийг дараа нь **«Анги дэвшүүлэх»**-ээр шилжүүлнэ: [Аль нь хэзээ](/kidspace/angi-shiljuuleh-devshuuleh)

Нэг цэцэрлэгийн бүх бүлгийг зэрэг хуулах бол «Цэцэрлэг»-ээ сонгоод **«Бүлгүүдийг хуулах»** → **«Урьдчилан харах»** → **«Хуулах»** дар.

## ⚠️ Анхаар {#anhaar}
- Бүлэг дээд талд сонгосон **хичээлийн жилд** үүснэ. Өөр жилд үүсгэх бол эхлээд жилээ соль.
- Бүлгийн **«Тохиргоо»** табын «Үнэ тохиргоо» төлбөрт нөлөөлнө.
- **«Бүгдэд тэмдэг олгох»**-д «Байгаа тэмдгийг ч солих»-г чагталбал одоогийн тэмдэг бүгд солигдоно. **Буцаах боломжгүй.**
- Ангийн амралтыг энд биш, [Ирц журнал](/kidspace/irts-zhurnal#angiin-amralt)-аас зарлана.

## Түгээмэл асуулт {#asuult}

**Бүлэг жагсаалтад харагдахгүй байна.**
Дээд талын хичээлийн жилийг шалга. Жагсаалт тэр жилийн бүлгийг харуулна.

**«Дараагийн жилд үүсгэх» товч идэвхгүй байна.**
«Хүснэгт» харагдац руу шилжээд бүлгээ чагтал.

**«…хичээлийн жил үүсээгүй/хаагдсан байна» гэж гарна.**
**Байгууллага → Хичээлийн жил**-ээс шинэ жилээ үүсгэж идэвхжүүл.

**«Анги дэвшүүлэх» идэвхгүй, «түвшин оноогоогүй» гэж гарна.**
Бүлгийн «Түвшин»-г тохируул.
