# Санал хүсэлт бичих 

> 🏠 Түрээслэгч, оршин суугч · Гар утасны апп

:::info
Видео заавар шинэчлэгдэж байна.
:::

1. **Санал хүсэлт** хэсэг дээр дарах.
2. Баруун дээд буланд байгаа нэмэх тэмдэг дээр дарах.
3. **Санал хүсэлт илгээх** цонхонд шаардлагатай зүйлсийг бөглөх.
4. **Хадгалах** товч дарах.
