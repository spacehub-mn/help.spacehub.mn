# Санал хүсэлт бичих

> 🏠 Түрээслэгч, оршин суугч · Гар утасны апп

:::caution
Дэлгэцийн зураг шинэчлэгдэж байна.
:::

## Энэ юу вэ
Түрээслүүлэгч, байгууллагадаа асуудал эсвэл санал хүсэлтээ аппаар илгээнэ.

## Хэзээ хэрэглэх
- Сантехник, цахилгаан, цахилгаан шатны асуудал гарсан үед.
- Засвар үйлчилгээ хүсэх, бараа оруулах хүсэлт гаргах үед.
- Ерөнхий санал хүсэлт өгөх үед.

## Алхам
1. Аппын нүүрнээс **Санал хүсэлтүүд**-ийг дарна.
2. Баруун дээд буланд байгаа **+** дүрсийг дарна.
3. Гарч ирсэн жагсаалтаас хүсэлтийнхээ төрлийг сонгоно.
4. **Санал хүсэлт илгээх** цонхонд хүсэлтээ бичнэ (300 тэмдэгт хүртэл).
5. Шаардлагатай бол зураг нэмнэ (5 хүртэл).
6. **Нийтлэх** товчийг дарна.

## ⚠️ Анхаар
- Төрлийг буруу сонгосон бол цонхны дээд талын төрөл дээр дарж солино.
- Илгээсэн хүсэлтүүд **Санал хүсэлтүүд** жагсаалтад харагдана.
- Хүсэлт сонгосон гэрээний объект руу явна. Өөр объект бол **⇄** дүрсээр гэрээгээ сольж илгээнэ.
