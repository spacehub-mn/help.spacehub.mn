# Төлбөр төлөх заавар

> 🏠 Түрээслэгч, оршин суугч · Гар утасны апп

:::info
Видео заавар шинэчлэгдэж байна.
:::

1. Апп-ын нүүрнээс **Төлбөр төлөх** хэсэг рүү орно.
2. Төлөх сарынхаа **Төлөх** товчийг дарна. Төлөх нэхэмжлэл байхгүй бол «Одоогоор төлөгдөөгүй нэхэмжлэл алга байна» гэж гарна.
3. Төлбөрийн хэрэгслээ сонгоно:
   - **QPay-ээр төлөх** — банкны апп-аа сонгох эсвэл **QR код**-ыг уншуулна. Төлсний дараа **Үргэлжлүүлэх** товчийг дарна.
   - **Social Pay-ээр төлөх**.
   - **Дансаар төлөх** — **Банк**, **Хүлээн авагч**, **Дансны дугаар**, **Гүйлгээний утга** (таны **гэрээний дугаар**) гарна. Гүйлгээний утгад гэрээний дугаараа **яг ингэж** бичнэ. Ингэвэл төлбөр автоматаар таны гэрээнд бүртгэгдэнэ.
   - QPay, Social Pay нь таны байгууллага тохируулсан үед л харагдана. Харагдах ёстой атал алга бол апп-аа **шинэчил**, эсвэл **Дансаар төлөх**-ийг ашигла. Дансаар төлөх нь үргэлж харагдана.
4. Төлбөр баталгаажвал «Амжилттай төлөгдлөө» гэж гарна. Хараахан баталгаажаагүй бол «Хараахан баталгаажаагүй байна» гэж гарна. Түр хүлээгээд дахин шалга.
5. Төлбөр төлөгдсөн бол **Төлөх** товч **Төлсөн** болж өөрчлөгдөнө.

:::tip Дансаар шилжүүлсэн бол
Шилжүүлсэн төлбөр баталгаажсан эсэхийг **30 минутын дараа** шалгана уу. Удаан хугацаанд «Төлсөн» болохгүй бол байгууллагадаа гүйлгээний баримтаа илгээнэ үү.
:::
