# Нэхэмжлэл үүсгэж илгээх

> 🏢 Owner, менежер · Гар утасны апп

:::caution 2023 оны заавар
Спейсхаб аппын (ҮХХ эзэмшигч) 2023 оны хувилбарын заавар. Дэлгэц өөрчлөгдсөн байж болно — зураг/видеог шинэчилж байна.
:::

1. Гэрээ хэсгийг сонгох.
2. Нэхэмжлэх үүсгэх гэж буй түрээслэгчийн гэрээг сонгох.
3. Хуваарь хэсгийг сонгох.
4. Нэхэмжлэл үүсгэх сарын баруун талд байгаа 3 цэг дээр дарж **Нэхэмжлэх** хэсгийг сонгох.
5. «Та нэхэмжлэлийн урьдчилсан задаргааг харж байна» гэсэн дэлгэцэд задаргаагаа шалга. **Утасруу илгээх**, **Мэйлрүү илгээх** чагт **анхдагчаар тэмдэглэгдсэн** байдаг. Илгээхгүй бол чагтаа ав.
6. **Нэхэмжлэх** товч дээр дар.

:::caution
**Нэхэмжлэх** дармагц харилцагчид **SMS, имэйл шууд явна**. Баталгаажуулах асуулт гарахгүй, буцаах боломжгүй. Илгээхгүй бол дарахаас өмнө чагтаа ав.
:::
