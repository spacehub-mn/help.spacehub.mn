# Тоолуурын заалт оруулах

> 🏢 Owner, менежер · Гар утасны апп

:::caution 2023 оны заавар
Спейсхаб аппын (ҮХХ эзэмшигч) 2023 оны хувилбарын заавар. Дэлгэц өөрчлөгдсөн байж болно — зураг/видеог шинэчилж байна.
:::

1. Апп-ын нүүрнээс **Тоолуурын заалт** хэсгийг сонго. Тоолуур бүрээр бүртгэдэг бол **Өрөөний тоолуур** хэсгийг сонго ❔ (аль хэсэг аль системд бичдэгийг батлаагүй).
2. Заалт оруулах **объект** болон **сар**-аа сонго.
3. Хүний нэр, тоот, гэрээгээр хайж айлаа ол. Шүүлтээр **Бүртгэсэн / Бүртгээгүй / Бүгд**-ийг харж болно. Дээд талд «Бүртгэсэн нийт», «Бүртгээгүй нийт» тоо гарна.
4. **Одоо. заалт** талбарт энэ сарын заалтыг оруул. **Өмнөх заалт** харагдана. Хэрэглээ өөрчлөгдөөгүй бол **Өмнөх сарын утга оруулах**-аар хуулж болно («Өмнөх сарын утгыг хуулах уу?»).
5. Шаардлагатай бол тоолуурын зургийг хавсарга.
6. **Хадгалах** товч дар. «**Тоолуурын заалтыг амжилттай хадгаллаа**» гэж гартал хүлээ.

:::caution «Өмнөх сарын тоолуурын заалтыг эхлээд оруулна уу»
Ийм мессеж эсвэл «Энэ хэрэглэгчийн ашиглалтын мэдээлэл алдаатай байна» гэж гарвал:
- хамгийн эхний тоолуурын заалтыг бүртгээгүй, эсвэл
- өмнөх сарын заалтыг хугацаандаа оруулаагүй байна.

Эхлээд өмнөх сарын заалтыг оруулна. Анх эхэлж байгаа бол вэб дээр **Төлбөрийн хуваарь → «Тоолуур [»**-аар эхлэл заалт оруулна. → [Тоолуур нэмэх, солих, цуцлах](/owner/tooluur)
:::

Зөвлөмж: Тоолуурын заалт оруулахдаа тоолуурын заалт оруулах он сар солих, тоолуурын заалт оруулах объектыг сонгох мөн гэрээний дугаараар хайх, шүүлтүүрүүдээр сайн шүүж ашиглана уу.
