# Зар оруулах

> 🏢 Эзэмшигч, менежер · Гар утасны апп

## Энэ юу вэ
Объектынхоо оршин суугчид, түрээслэгчдэд зар, мэдээлэл нийтлэх заавар.

## Хэзээ хэрэглэх
- Объект доторх хүмүүст мэдээлэл түгээх үед.
- Объект дотроо зар сурталчилгаа тавих үед.

## Алхам
![Бизнес зар цэс, нэмэх товч](/img/lessor/post-a-post-1.webp)

*Зураг 1. Бизнес зар цэс, нэмэх товч. Улаан дугаар = алхмын дугаар.*

1. Доод цэсний **Бизнес зар** хэсгийг сонго. Зарим бүртгэлд энэ нь **Мэдээ** гэж харагдана.
2. Баруун доод буланд байгаа нэмэх тэмдэг дээр дар.
![Шинэ зар дэлгэц](/img/lessor/post-a-post-2.webp)

*Зураг 2. Шинэ зар дэлгэц. Улаан дугаар = алхмын дугаар.*

3. **Шинэ зар** дэлгэц нээгдэнэ.
4. «Та юу бодож байна?» талбарт зарынхаа текстийг бич.
5. Шаардлагатай бол **Ангилал нэмэх**, зураг, **Хавсралтууд**-ыг нэм.
6. **Нийтлэх** товч дар.
7. Олон объекттой бол **Объект сонгох** цонхонд объектоо сонгоод **Хадгалах** дар.
8. «Бүх объект руу амжилттай илгээгдлээ» гэж гарна.

## ⚠️ Анхаар
- Текст 300 тэмдэгт хүртэл байна.
- Шинэ зард ихдээ 5 зураг оруулна.
- Зар тухайн объектын оршин суугчид болон эзэмшигчид харагдана.
