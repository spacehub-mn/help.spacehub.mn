# Зар оруулах

> 🏢 Owner, менежер · Гар утасны апп

:::caution 2023 оны заавар
Спейсхаб аппын (ҮХХ эзэмшигч) 2023 оны хувилбарын заавар. Дэлгэц өөрчлөгдсөн байж болно — зураг/видеог шинэчилж байна.
:::

1. Доод цэсний **Бизнес зар** (зарим бүртгэлд **Мэдээ**) хэсгийг сонгох.
2. Зар тавих гэж буй объектыг сонгох.
3. Баруун дээд буланд байгаа нэмэх тэмдэг дээр дарах.
4. Шаардлагатай хэсгүүдийг бөглөж “Хадгалах” товч дарах.
