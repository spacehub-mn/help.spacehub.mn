# Нийтлэгчийг блоклох

> 🏢 Эзэмшигч, менежер · Гар утасны апп

## Энэ юу вэ
Зохисгүй зар нийтэлсэн хэрэглэгчийг блоклож, түүний нийтлэлийг цаашид харахгүй болгох заавар.

## Хэзээ хэрэглэх
- Хэрэглэгч спам, зохисгүй зар тавьсан үед.
- Тодорхой хэрэглэгчийн нийтлэлийг харахыг хүсэхгүй үед.

## Алхам
![Бизнес зар цэс, зар, 3 цэг](/img/lessor/block-user-1.webp)

*Зураг 1. Бизнес зар цэс, зар, 3 цэг. Улаан дугаар = алхмын дугаар.*

1. Доод цэсний **Бизнес зар** хэсгийг сонго. Зарим бүртгэлд энэ нь **Мэдээ** гэж харагдана.
2. Блоклох хэрэглэгчийн зар дээр дар.
3. Баруун дээд булангийн 3 цэг дээр дар.
![Нийтлэгчийг блоклох](/img/lessor/block-user-2.webp)

*Зураг 2. Нийтлэгчийг блоклох. Улаан дугаар = алхмын дугаар.*

4. **Нийтлэгчийг блоклох**-ыг сонго.
5. **Шалтгаан** талбарт шалтгаанаа бич. Энэ талбар заавал бөглөнө.
6. **Блоклох** товч дар.
7. «Хэрэглэгчийн блоклолоо» гэж гарна.

## ⚠️ Анхаар
- **Нийтлэгчийг блоклох** нь зөвхөн бусдын зард гарна.
- Блоклосны дараа тухайн хэрэглэгчийн нийтлэлийг харах боломжгүй болно.
- Блокийг **Бүртгэл** → **Тохиргоо** → **Блоклосон хэрэглэгчид**-ээс гаргана.
