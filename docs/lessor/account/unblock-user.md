# Блоклосон хэрэглэгч гаргах

> 🏢 Байгууллага, менежер · Гар утасны апп

:::caution 2023 оны заавар
Спейсхаб аппын (ҮХХ эзэмшигч) 2023 оны хувилбарын заавар. Дэлгэц өөрчлөгдсөн байж болно — зураг/видеог шинэчилж байна.
:::

1. “Бүртгэл” хэсгийг сонгох.
2. **Блоклосон хэрэглэгчид** хэсгээс блокийг гаргах хэрэглэгч дээр дарж **Блок гаргах**-ыг сонгох.
3. «… блокийг гаргахдаа итгэлтэй байна уу?» гэж асуухад **OK** дарах. «… блокийг гаргалаа» гэж гарна.
