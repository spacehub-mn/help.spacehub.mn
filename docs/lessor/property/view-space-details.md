# Талбайн мэдээлэл харах

> 🏢 Эзэмшигч, менежер · Гар утасны апп

## Энэ юу вэ
Объектын талбайнуудын төлөв, хэмжээ, үнэ, түрээслэгчийг харах заавар.

## Хэзээ хэрэглэх
- Сул талбай хайх үед.
- Тухайн талбайг хэн түрээсэлж байгааг шалгах үед.

## Алхам
![Объект цэс, объектын карт](/img/lessor/view-space-details-1.webp)

*Зураг 1. Объект цэс, объектын карт. Улаан дугаар = алхмын дугаар.*

1. Доод цэсний **Объект** хэсгийг сонго.
2. Талбайг нь харах объектоо сонго. Ганц объекттой бол шууд нээгдэнэ.
![Шүүлтүүр, талбай](/img/lessor/view-space-details-2.webp)

*Зураг 2. Шүүлтүүр, талбай. Улаан дугаар = алхмын дугаар.*

3. Талбайн жагсаалтыг **Төлөв**, **Талбайн төрөл**, давхраар шүүж болно.
4. Талбай дээр дар.
5. Сул эсвэл зар тавьсан талбай бол талбайн дэлгэц нээгдэнэ. Талбай, үнэ, давхар, багтаамжийг хар.
![Түрээслэгдсэн талбайн цонх](/img/lessor/view-space-details-3.webp)

*Зураг 3. Түрээслэгдсэн талбайн цонх. Улаан дугаар = алхмын дугаар.*

6. Түрээслэгдсэн, зарагдсан, лизингдсэн бол доороос жижиг цонх гарна.
7. Цонхонд **Талбай**, **Түрээслэгч** гарна. Гэрээг **Гэрээ харах**-аар нээнэ.
8. Талбайн бүх мэдээллийг **Засварлах** товчоор нээж харна.

## Түгээмэл асуулт
**Талбайн өнгө юуг заадаг вэ?**
- Саарал: Сул
- Шар: Зар тавьсан (сул)
- Улбар шар: Түрээслэгдсэн
- Хөх ногоон: Зарагдсан
- Ногоон: Лизингдсэн

Энэ тайлбарыг объектын дэлгэц дээрх асуултын тэмдгээс харж болно. Харанхуй загварт зарагдсан, лизингдсэн талбай ижил өнгөтэй.
