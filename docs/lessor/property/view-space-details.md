# Талбайн мэдээлэл харах

> 🏢 Байгууллага, менежер · Гар утасны апп

:::caution 2023 оны заавар
Спейсхаб аппын (ҮХХ эзэмшигч) 2023 оны хувилбарын заавар. Дэлгэц өөрчлөгдсөн байж болно — зураг/видеог шинэчилж байна.
:::

1. “Объект” хэсгийг сонгох
2. Аль сул талбай харах гэж буй объектыг сонгох

Зөвлөмж:

* Саарал өнгө: Сул талбай
* Улбар шар: Түрээслэгдсэн талбай
* Ногоон өнгө: Зар тавьсан талбай
