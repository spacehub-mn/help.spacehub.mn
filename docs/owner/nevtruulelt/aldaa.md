> 🚀 Систем нэвтрүүлэлт · 🏢 Нягтлан, менежер · Нэвтрүүлэлтийн **3-р үе (шалгах)** — эхний тооцооноос (4-р үе) өмнө

## Энэ юу вэ
Шинэ байгууллагыг нэвтрүүлэхэд **эхний тооцоог** хамгийн их эвддэг алдаанууд. Бүгд бодит нэвтрүүлэлт дээр гарсан. Мэдээлэл оруулсны дараа, эхний тооцоо гаргахын **өмнө** дарааллаар нь шалга.

## Хэзээ хэрэглэх
- Spacehub баг «бүртгэл дууслаа» гэж мэдэгдсэний дараа.
- Эхний тооцоо **хоосон**, **0₮** эсвэл **хэт их** гарсан үед.

## 1. Талбай ба гэрээ
1. **Талбайн тоо** таны бүртгэлтэй тэнцүү эсэхийг шалга. Талбайн **кодгүй** мөр бүртгэгдэхгүй. **м²** хоосон байсан талбай **0 м²**-аар орно — тэр өрөөний м²-ийг шалга. → [Дашборд](/owner/list/Dashboards)
2. Өрөө бүр **Түрээс** үйлчилгээтэй холбогдсон эсэхийг шалга — өрөөний картын «Түрээсийн үйлчилгээ» талбар хоосон бол тооцоонд түрээс орохгүй.
3. **Гэрээний тоо** таны бүртгэлтэй тэнцүү эсэх. Огнооны шүүлтийн ✕ дарж бүх огноог харуул. → [Гэрээ](/owner/list/Contract_ListView)

## 2. Үнэ ба үйлчилгээ
1. Гэрээ бүрийн **үйлчилгээ «Ашиглах»** төлөвтэй эсэх. «Ашиглахгүй» бол тооцоо **хоосон** гарна.
2. Түрээсийн **үнэ 0 биш** эсэх. 0 бол засна. → [Үнэ өөрчлөх](/owner/une-oorchloh)
3. Үнийн мөрөнд **огноо** бөглөгдсөн эсэх. Огноогүй үнэ сарын дундах өөрчлөлтөд буруу тооцогдоно.
4. Түрээсийн дүн **бутархай** («…000.08₮») бол нийт дүнгээр нь бүхэл болгож засна.

## 3. Эхний үлдэгдэл
1. **Тооцоо → Эхний үлдэгдэл**-ээс өр («Дутуу»), илүү төлөлт («Илүү») тус бүрийг өөрийн бүртгэлтэй тулга. → [Эхний үлдэгдэл](/owner/list/BeginBalance_ListView)
2. Илүү төлөлттэй гэрээний **өр нэмэгдээгүй** эсэхийг шалга — илүү төлөлт өр болж орсон тохиолдол гарч байсан.
3. Үлдэгдлийн огноогоос хойш орсон **банкны гүйлгээ** давхар бүртгэгдээгүй эсэх. → [Хуулгаас төлбөр бүртгэх](/owner/huulga-tolbor)

## 4. Хэрэглэгч ба холболт
1. Хэрэглэгч бүр **нэвтэрч** чадаж байгаа эсэх. Нууц үг тохируулаагүй хэрэглэгч нэвтэрч чадахгүй. → [Эрхгүй, нэвтэрч чадахгүй](/owner/erhgui-nevtreh)
2. **Е-баримтын тохиргоо** хийгдсэн эсэх (НӨАТ төлөгч бол заавал). → [Е-баримтын тохиргоо](/owner/e-barimt)
3. **SMS** түлхүүр бөглөгдсөн эсэх — хоосон бол нэхэмжлэх SMS явахгүй. → [Owner-ийн тохиргоо](/owner/tohirgoo)

## ⚠️ Анхаар
- Алдаа олдвол **тооцоог гараар бүү зас**. Шалтгааныг (талбай, үнэ, үйлчилгээ, үлдэгдэл) засаад «Төлбөр шинэчлэх» дар. → [Төлбөр](/owner/list/Bill_ListView)
- Импортын «амжилттай N» гэсэн тоо **давхар** тоологдож болно — жагсаалтын бодит тоог хар.
- Эхний үлдэгдлийг засах бол **нэг удаа, бүгдийг нь** — хэсэгчлэн олон удаа оруулбал давхардана.

## Түгээмэл асуулт
- **Эхний тооцоо бүгд 0₮ гарсан.** 2-р хэсгийн 1, 2 (үйлчилгээ «Ашиглахгүй», үнэ 0).
- **Нэг гэрээний өр хэт их гарсан.** 3-р хэсгийн 2 (илүү төлөлт өр болж орсон эсэх).
- **Ажилтан нэвтэрч чадахгүй.** 4-р хэсгийн 1.
