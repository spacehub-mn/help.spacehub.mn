> 📘 Сургалт · 🏢 Байгууллага, нягтлан · Вэб (app.spacehub.mn)

Сар бүр давтагддаг 6 ажил, ойролцоогоор хэдний өдөр хийх дарааллаар. Яг огноо нь танай гэрээний нөхцөл, авто ажлын тохиргооноос хамаарна.

```
① Тоолуур → ② Тооцоо → ③ Нэхэмжлэх → ④ Сануулга → ⑤ Тулгалт → ⑥ Хаалт
```

## ① Тоолуурын заалт (сарын эхэн)
- Ашиглалттай гэрээнд энэ сарын заалтыг оруулна:
  - **Тооцоо → Төлбөрийн хуваарь** → «Тоолуур +» (нэг гэрээ) — [Тоолуур](/owner/list/ContractPaymentChart_ListView#tooluur);
  - **Тоолуур татах** (Excel, олон айл) — [Тоолуур татах](/owner/list/UtilitySheet_ListView);
  - **Дашборд → Тоолуур/Сар** — [Тоолуур/Сар](/owner/list/Dashboards#tooluur-sar). Зөвхөн энэ ба өмнөх сар засагдана;
  - утасны апп — «Тоолуурын заалт» хэсэг.
- **Шалгах:** «Тоолуур/Сар» дашбордын **?** (багассан / 0) ба **!** (өөрчлөгдөөгүй) тэмдэгтэй нүднүүд.

## ② Сарын тооцоо
- **Авто ажил** тохируулсан бол тооцоо автоматаар гарна. **Автоматжуулалт → Авто ажил**-аас тухайн сарын ажил «Ажиллаж байна» эсэхийг шалга. Ажил алга бол «Next Auto Job +» → «Job Create». → [Авто ажил](/owner/list/AutoJob_ListView)
- Гараар бол → [Сарын тооцоо гаргах](/owner/sar-tootsoo)
- **Шалгах:** **Дашборд → Сарын тооцоо**-д бүх гэрээнд тооцоо гарсан эсэх. Гараагүй бол → [Авто тооцоо гараагүй](/owner/avto-tootsoo-garaagui)

## ③ Нэхэмжлэх илгээх
- Авто ажлын төрөл «…илгээх(SMS/Email)» бол автоматаар явна. Үгүй бол **Тооцоо → Нэхэмжлэх → «SMS илгээх» → «Жирийн»**. → [Нэхэмжлэх илгээх](/owner/nehemjleh-ilgeeh)
- **Шалгах:** **Илгээлт** багана. «Алгассан» мессежийн шалтгааныг хар. Дүн зөрвөл → [Нэхэмжлэхийн дүн зөрж байна](/owner/nehemjleh-dun-zoroh)

## ④ Сануулга (төлөх хугацаанаас хойш)
- Төлөөгүй айлд **«SMS илгээх» → «Төлөөгүй»** загвараар сануул. Төлсөн айлыг систем автоматаар алгасна.
- ⚠️ «Нэхэмжлэх дахиж явуулах тохиргоо»-ны автомат сануулга **одоогоор ажиллахгүй** байна. Гараар илгээ. → [Нэхэмжлэх дахиж явуулах](/owner/list/NotificationToDueInvoiceBillsConfig_ListView)

## ⑤ Тулгалт (долоо хоног бүр)
1. **Дашборд → Хуулга монитор** — хуулга өдөр бүр татагдаж байгаа эсэх. → [Хуулга монитор](/owner/list/Dashboards#huulga-monitor)
2. **Дансны хуулга** — **«Төлбөр бүртгээгүй»** шүүлтээр цагаан мөрүүдийг «ХУРДАН ТӨЛӨХ»-өөр бүртгэ. Ягаан (хэсэгчлэн хуваасан) мөрийн үлдэгдлийг зөвхөн «ХУРДАН ХУВААХ»-аар. → [Дансны хуулга](/owner/list/Statement_ListView)
   - Бэлэн мөнгийг **Тооцоо → Төлөлт → «Шинэ»**-ээр бүртгэ.
3. **Төлөлт** — хуваарилагдаагүй үлдэгдэлтэй төлөлтийг «Хуваарилах...». → [Төлөлт](/owner/list/Sale_ListView)
4. Төлөв буруу харагдвал гэрээн дээр **«Төлбөрийн төлөв шинэчлэх»**. → [Гэрээ](/owner/list/Contract_ListView)

## ⑥ Сарын хаалт (дараа сарын 1–7)
1. **Е-баримт:** өмнөх сарын бүх төлөлтөд баримт гарсан эсэхийг **Тооцоо → Төлөлт → «Ebarimt гараагүй»** шүүлтээр шалга. **Дараа сарын 7-ны** дотор гарга, 8-наас хойш автоматаар гарахгүй. → [Е-баримт гарах нөхцөл](/owner/concepts/e-barimt-nohtsol)
2. **Алданги:** чөлөөлөх айлд «Алданги цуцлах». → [Алданги](/owner/concepts/aldangi)
3. **Тайлан:** «01. Нэгтгэл — Хурдан». → [Тайлан](/owner/list/Reports)
4. **Талбай/Сар нэгтгэл**-ээс сул талбай, үлдэгдэлтэй айлыг хар. → [Дашборд](/owner/list/Dashboards#talbai-sar)
5. Дуусах дөхсөн гэрээг сунга. → [Гэрээ](/owner/list/Contract_ListView)
