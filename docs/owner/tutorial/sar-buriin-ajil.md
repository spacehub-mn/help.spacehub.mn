## Энэ юу вэ
Сар бүрийн тооцоо, нэхэмжлэхийг **авто ажил** өөрөө гаргаж, илгээнэ. Таны ажил нь авто ажил ажилласан эсэхийг шалгах. Гараар тооцоо гаргах нь зөвхөн онцгой тохиолдолд.

```
① Авто тооцоо, нэхэмжлэх → ② Тоолуур → ③ Илгээлт шалгах → ④ Сануулга → ⑤ Тулгалт → ⑥ Хаалт
```

## ① Авто тооцоо, нэхэмжлэх (сарын эхэн)
**Нэг удаа тохируулна:**
- Байгууллага, объект, гэрээ гурвууланд **«Автомат ажил»** тэмдэглэгдсэн байх ёстой. → [Авто тооцоо — 3 түвшин](/owner/concepts/avto-3-tuvshin)
- Авто ажлын **Авто ажил төрөл**-ийг сонгоно:
  - **Төл, Нэх үүсгэж, илгээх(SMS/Email)** — тооцоо гаргаад харилцагчид шууд илгээнэ;
  - **Төл, Нэх үүсгэх** — зөвхөн гаргана, илгээлтийг та хийнэ.

**Сар бүр шалгана:**

![Авто ажил жагсаалт: цэс, Авто ажил статус, Next Auto Job +, Job Create](/img/owner/tutorial/sar-buriin-ajil-2.webp)

*Зураг 1. Автоматжуулалт → Авто ажил жагсаалт. Энэ жишээнд ажил алга. Улаан дугаар = алхмын дугаар. Дарвал томорно.*

1. **Автоматжуулалт → Авто ажил** цэсийг нээнэ.
2. Тухайн сарын ажлын **Авто ажил статус** «Ажиллаж байна» эсэхийг шалгана.
3. Ажил алга бол өмнөх сарын ажлыг сонгоод **«Next Auto Job +»** дарна.
4. Шинэ ажлыг сонгоод **«Job Create»** дарна. Статус «Ажиллаж байна» болно.
5. **Дашборд → Сарын тооцоо**-оос бүх гэрээнд тооцоо гарсан эсэхийг шалгана.

- Зарим айлд гараагүй бол → [Авто тооцоо гараагүй](/owner/avto-tootsoo-garaagui)
- Товч бүрийн тайлбар → [Авто ажил](/owner/list/AutoJob_ListView)

:::tip Тоолууртай гэрээ
Ус, цахилгаантай гэрээнд энэ сарын заалт оруулсны дараа л тооцоо бүрэн гарна. → ②
:::

## ② Тоолуурын заалт (сарын эхэн)
- Ашиглалттай гэрээнд энэ сарын заалтыг оруулна:
  - **Тооцоо → Төлбөрийн хуваарь** → «Тоолуур +» (нэг гэрээ) — [Тоолуур](/owner/list/ContractPaymentChart_ListView#tooluur);
  - **Тоолуур татах** (Google Sheet, олон айл) — [Тоолуур татах](/owner/list/UtilitySheet_ListView);
  - **Дашборд → Тоолуур/Сар** — [Тоолуур/Сар](/owner/list/Dashboards#tooluur-sar). Зөвхөн энэ ба өмнөх сар засагдана;
  - утасны апп — «Тоолуурын заалт» хэсэг.
- **Шалгах:** «Тоолуур/Сар» дашбордын **?** (багассан / 0) ба **!** (өөрчлөгдөөгүй) тэмдэгтэй нүднүүд.

## ③ Нэхэмжлэх илгээгдсэн эсэх
- Авто ажлын төрөл «…илгээх(SMS/Email)» бол нэхэмжлэх өөрөө явна.
- **Тооцоо → Нэхэмжлэх**-ийн **Илгээлт** баганыг шалгана. «Алгассан» мессежийн шалтгааныг харна.
- Дүн зөрвөл → [Нэхэмжлэхийн дүн зөрж байна](/owner/nehemjleh-dun-zoroh)

## ④ Сануулга (төлөх хугацаанаас хойш)
- Төлөөгүй айлд **«SMS илгээх» → «Төлөөгүй»** загвараар сануулна. Төлсөн айлыг систем өөрөө алгасна.
- ⚠️ «Нэхэмжлэх дахиж явуулах тохиргоо»-ны автомат сануулга **одоогоор ажиллахгүй** байна. Гараар илгээнэ. → [Нэхэмжлэх дахиж явуулах](/owner/list/NotificationToDueInvoiceBillsConfig_ListView)

## ⑤ Тулгалт (долоо хоног бүр)
1. **Дашборд → Хуулга монитор** — хуулга өдөр бүр татагдаж байгаа эсэх. → [Хуулга монитор](/owner/list/Dashboards#huulga-monitor)
2. **Дансны хуулга** — **«Төлбөр бүртгээгүй»** шүүлтээр цагаан мөрүүдийг «ХУРДАН ТӨЛӨХ»-өөр бүртгэнэ. Ягаан (хэсэгчлэн хуваасан) мөрийн үлдэгдлийг «ХУРДАН ХУВААХ»-аар. → [Дансны хуулга](/owner/list/Statement_ListView)
   - Бэлэн мөнгийг **Тооцоо → Төлөлт → «Шинэ»**-ээр бүртгэнэ.
3. **Төлөлт** — хуваарилагдаагүй үлдэгдэлтэй төлөлтийг «Хуваарилах...». → [Төлөлт](/owner/list/Sale_ListView)
4. Төлөв буруу харагдвал гэрээн дээр **«Төлбөрийн төлөв шинэчлэх»**. → [Гэрээ](/owner/list/Contract_ListView)

## ⑥ Сарын хаалт (дараа сарын 1–7)
1. **Е-баримт:** **Тооцоо → Төлөлт → «Ebarimt гараагүй»** шүүлтээр шалгана. **Дараа сарын 7-ны** дотор гаргана. 8-наас хойш автоматаар гарахгүй. → [Е-баримт гарах нөхцөл](/owner/concepts/e-barimt-nohtsol)
2. **Алданги:** чөлөөлөх айлд «Алданги цуцлах». → [Алданги](/owner/concepts/aldangi)
3. **Тайлан:** «01. Нэгтгэл — Хурдан». → [Тайлан](/owner/list/Reports)
4. **Талбай/Сар нэгтгэл**-ээс сул талбай, үлдэгдэлтэй айлыг харна. → [Дашборд](/owner/list/Dashboards#talbai-sar)
5. Дуусах дөхсөн гэрээг сунгана. → [Гэрээ](/owner/list/Contract_ListView)

## Онцгой тохиолдол: гараар тооцоо, нэхэмжлэх
Авто ажил ашигладаггүй объект, эсвэл нэг айлд тусад нь тооцоо гаргах үед л гараар хийнэ.
- Тооцоо гаргах → [Сарын тооцоо гаргах](/owner/sar-tootsoo)
- Нэг гэрээнд төлбөр нэмэх: **Тооцоо → Төлбөрийн хуваарь** → «Төлбөр +». → [Төлбөрийн хуваарь](/owner/list/ContractPaymentChart_ListView)
- Нэхэмжлэх илгээх: **Тооцоо → Нэхэмжлэх → «SMS илгээх» → «Жирийн»**. → [Нэхэмжлэх илгээх](/owner/nehemjleh-ilgeeh)
