# 🧮 Нягтлан

> 🏢 Нягтлан бодогч · Вэб (app.spacehub.mn)

Мөнгө орж ирсэн бүрийг **төлөлт** болгож, **е-баримт** гаргах, сарыг **тулгах** нь таны үүрэг.

## Өдөр бүр
- **Дансны хуулга** — «Төлбөр бүртгээгүй» шүүлтээр цагаан мөрүүдийг «ХУРДАН ТӨЛӨХ». → [Хуулгаас төлбөр бүртгэх](/owner/huulga-tolbor) · [Дансны хуулга](/owner/list/Statement_ListView)
- Бэлэн мөнгө → **Төлөлт → «Шинэ»**. → [Төлөлт](/owner/list/Sale_ListView)

## Долоо хоног бүр
- Хуваарилагдаагүй үлдэгдэлтэй төлөлт → «Хуваарилах...». → [Төлөлт](/owner/list/Sale_ListView)
- Хуулга татагдаж байгаа эсэх. → [Хуулга монитор](/owner/list/Dashboards#huulga-monitor)
- Е-баримт гараагүй төлөлт. → [Е-баримт](/owner/e-barimt) · [Төлөлтийн е-баримт](/owner/list/SaleEbarimt_ListView)

## Сар бүр
- **Сарын хаалт** — е-баримт (дараа сарын 7-ны дотор), алданги, тайлан. → [Сар бүрийн ажил ⑥](/owner/tutorial/sar-buriin-ajil)
- Тайлан. → [Тайлан](/owner/list/Reports)

## Хааяа
- **Эхний үлдэгдэл** («Дутуу» / «Илүү») — ⚠️ хадгалахад тэр сар хүртэлх тооцоо цуцлагдана. → [Эхний үлдэгдэл](/owner/list/BeginBalance_ListView)
- Нэхэмжлэхийн дүн зөрөх. → [Нэхэмжлэхийн дүн зөрж байна](/owner/nehemjleh-dun-zoroh)
- Ойлголт: [Төлбөр → Нэхэмжлэх → Төлөлт](/owner/concepts/tootsoo-nehemjleh-toloh) · [Е-баримт гарах нөхцөл](/owner/concepts/e-barimt-nohtsol)
