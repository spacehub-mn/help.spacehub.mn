# Е-баримт гарах нөхцөл

> 💡 Ойлголт · 🏢 Эзэмшигч, менежер, нягтлан · Вэб (app.spacehub.mn)

Е-баримтыг **төлөлтөөс** гаргана, нэхэмжлэхээс биш. 3 замтай:
- **Нэг бүрчлэн (гараар):** **Тооцоо → Төлөлт** → «И-Баримт → Баримт гаргах».
- **Олноор:** **Тооцоо → Төлөлт** → «Е-баримт олноор гаргах» (20 хүртэл).
- **Автоматаар:** **Автоматжуулалт → Авто eBarimt** (өдөр бүр).

## Автомат ба олноор гаргах нөхцөл
Дараах **бүгд** биелсэн үед л гарна:
- төлбөрийн хэлбэр **бэлэн мөнгө** эсвэл **данс**. QPay гэх мэт бусад хэлбэрт автоматаар гарахгүй;
- гэрээ **хаагдаагүй**;
- **гэрээ** ба **барилга** хоёулаа е-баримт гаргахыг зөвшөөрсөн;
- харилцагч **автоматаар е-баримт** авах тохиргоотой («И-Баримт тохргоо»), **И-Баримт байгууллага** нэр нь бөглөгдсөн;
- байгууллагын е-баримтын тохиргоо (ТТД, дүүргийн код) бүрэн;
- тухайн төлөлтөд баримт аль хэдийн **гараагүй**;
- **сугалаатай (иргэн)** харилцагчид «Хялбар бүртгэлийн тохиргоо» хийгдсэн;
- **орон сууцны түрээс ба ашиглалтыг хамт** нэхэмжилдэг гэрээ биш. Ийм гэрээнд НӨАТ-тай ба НӨАТ-гүй 2 баримт гарах тул нэг бүрчлэн гаргана.

## Хугацааны хязгаар
- Өмнөх сарын төлөлтийн баримтыг автоматаар **дараа сарын 7-ны өдрийг дуустал** гаргана. **8-наас** эхлэн автоматаар гарахгүй.

## Сугалаатай ба Сугалаагүй
- **Сугалаатай (Иргэн)** — хувь хүнд. Сугалааны кодыг SMS-ээр илгээж болно (**И-Баримт → «Мэссэж илгээх»**).
- **Сугалаагүй (Байгууллага, Иргэн)** — байгууллагад. **Харилцагч → «Баримт тохиргоо (Сугалаагүй)»** нь зөвхөн байгууллагад зориулагдсан.

## Буруу баримт
- Устгадаггүй, **буцаадаг** (татварт хүчингүй болгодог). **Тооцоо → Төлөлт → «И-Баримт → Буцаах»** нь баталгаажуулах асуулттай тул тэндээс хий.
- Хүчинтэй баримттай төлөлтийг **цуцлахаас өмнө** баримтаа буцаа.
- Буцаасан төлөлтийг олноор гаргахаар дахин гаргахгүй, **нэг бүрчлэн** гарга.
