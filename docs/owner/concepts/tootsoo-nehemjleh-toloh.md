# Төлбөр → Нэхэмжлэх → Төлөлт

> 💡 Ойлголт · 🏢 Эзэмшигч, менежер, нягтлан · Вэб (app.spacehub.mn)

Spacehub-ийн мөнгөний урсгал 4 алхамтай. «Яагаад төлөөгүй харагдаж байна?» гэсэн асуулт ихэнхдээ **4-р алхам дутуугаас** болдог.

```
① Төлбөр (тооцоо)  →  ② Нэхэмжлэх  →  ③ Төлөлт  →  ④ Хуваарилалт
  төлөх ёстой          илгээх баримт     орсон мөнгө     мөнгийг төлбөрт холбох
```

1. **Төлбөр** (апп дээр «Төлбөр», баримтад «тооцоо») — гэрээний нэг сарын **төлөх ёстой** дүн. Төлбөрийн хуваариас үүснэ.
2. **Нэхэмжлэх** — төлбөрөөс үүсэх, харилцагчид **илгээх** баримт (SMS, имэйл, апп). Нэг төлбөрт хэд хэдэн нэхэмжлэх байж болно.
3. **Төлөлт** — харилцагчийн **төлсөн** мөнгө. Дансны хуулга, QPay эсвэл гараар бүртгэнэ.
4. **Хуваарилалт** — төлөлтийн мөнгийг аль төлбөрт тооцохыг холбоно. Алдангийн төлбөрт эхэлж, дараа нь бусад төлбөрт. Хуваарилсны дараа төлбөр **Төлсөн / Дутуу** болно.

## Төлөвийн өнгө
- **Төлбөр** ба **Нэхэмжлэх** ижил өнгөтэй: **ногоон** = төлсөн, **улбар шар** = дутуу, **улаан** = төлөөгүй.
- Мөнгө орсон ч төлбөр **улаан** хэвээр байвал төлөлт хуваарилагдаагүй эсвэл төлөв шинэчлэгдээгүй байж магадгүй.

## «Төлсөн боловч төлөөгүй харагдаж байна» — шалгах дараалал
1. **Дансны хуулга** — гүйлгээ орсон эсэх, төлөлт бүртгэгдсэн эсэх (цагаан мөр = бүртгэгдээгүй).
2. **Төлөлт** — тэр гэрээнд төлөлт байгаа эсэх. Байвал «Хуваарилах...» (товч идэвхтэй бол хуваарилагдаагүй үлдэгдэл бий). Цуцалсан төлөлтийг хуваарилахгүй.
3. **Нэхэмжлэх** — «Төлөв шалгах»-аар үлдэгдлээр дахин бодуул.
