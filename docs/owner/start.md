# Эхлэх: эхний сар

> 🏢 Owner, менежер, нягтлан · Вэб (app.spacehub.mn)

Spacehub-д шинээр орсон бол энэ хуудсыг эхлээд уншаарай. Сар бүр давтагддаг ажлыг дарааллаар нь харуулна.

## 1. Spacehub баг юу тохируулж өгөх вэ
Эхний тохиргоог **Spacehub баг** таны өгсөн мэдээллээр хийж өгнө:
- байгууллага, банкны данс;
- хэрэглэгчид (нэвтрэх эрх);
- объект, өрөө/талбай;
- гэрээ, үйлчилгээ;
- тоолуурын эхлэл заалт;
- эхний үлдэгдэл.

Тохиргоо дууссаны дараа доорх **3 зүйлийг заавал шалга**:
1. **Менежмент → Гэрээ** — бүх гэрээ байгаа эсэх, үнэ, талбай нь зөв эсэх. Огнооны шүүлтийн **✕** дарж «📅 Бүх огноо» болго. → [Хугацаа зөв сонгох](/owner/hugatsaa-songoh)
2. **Тооцоо → Эхний үлдэгдэл** — өмнөх өр («Дутуу») ба илүү төлөлт («Илүү») зөв орсон эсэх.
3. Нэвтэрч чадахгүй, эсвэл цэс дутуу харагдвал → [Эрхгүй, нэвтэрч чадахгүй](/owner/erhgui-nevtreh)

Програмын ерөнхий ажиллагааг (цэс, жагсаалт, карт, шүүлт) **Програм ашиглах** хуудаснаас үз.

## 2. Сар бүрийн ажил — дарааллаар
```
Тоолуур → Сарын тооцоо → Нэхэмжлэх → Хуулга / Төлөлт → Е-баримт
```

**① Тоолуурын заалт (ашиглалттай бол).** Цахилгаан, усны заалтыг 3 замын нэгээр оруулна:
- **Тооцоо → Төлбөрийн хуваарь** жагсаалтын «Тоолуур +» товч;
- **Автоматжуулалт → Тоолуур татах** (Excel);
- утасны апп.

Оруулсны дараа **Тооцоо → Тоолуур ашиглалт** жагсаалтаас шалга.

**② Сарын тооцоо гаргах.** Гэрээ бүрийн энэ сарын **төлбөр** үүснэ. → [Сарын тооцоо гаргах](/owner/sar-tootsoo)
- Шалгах газар: **Тооцоо → Төлбөр**.
- Дүн буруу бол заалт, хөнгөлөлтөө засаад «Төлбөр шинэчлэх» дар.

**③ Нэхэмжлэх илгээх.** **Тооцоо → Нэхэмжлэх**-ээс «SMS илгээх», «Имэйл илгээх» эсвэл «Мэдэгдэл». → [Нэхэмжлэх илгээх](/owner/nehemjleh-ilgeeh)
- Нэхэмжлэх дээрх **Илгээлт** баганаас явсан эсэхийг хар.

**④ Төлбөр бүртгэх.** Айлууд төлөхөд мөнгө **Автоматжуулалт → Дансны хуулга**-д орж ирнэ. → [Хуулгаас төлбөр бүртгэх](/owner/huulga-tolbor)
- Гэрээний дугаартай гүйлгээ автоматаар **төлөлт** болно.
- Цагаан (бүртгэгдээгүй) мөрийг **«ХУРДАН ТӨЛӨХ»**-өөр гараар бүртгэ.
- Ягаан (хэсэгчлэн хуваасан) мөрийн үлдэгдлийг зөвхөн **«ХУРДАН ХУВААХ»**-аар бүртгэ.
- Бэлэн мөнгийг **Тооцоо → Төлөлт → «Шинэ»**-ээр бүртгэ.
- Төлбөр «төлсөн» болохгүй бол төлөлтөө **«Хуваарилах...»**.

**⑤ Е-баримт.** **Тооцоо → Төлөлт**-өөс «И-Баримт → Баримт гаргах» (нэг бүрчлэн) эсвэл «Е-баримт олноор гаргах». → [Е-баримт](/owner/e-barimt)
- ⚠️ Өмнөх сарын төлөлтийн е-баримтыг **дараа сарын 7-ны дотор** гарга. Түүнээс хойш автоматаар гарахгүй.

## 3. Эхний сард анхаарах 5 зүйл
- **Төлбөр ≠ Төлөлт.** «Төлбөр» нь төлөх ёстой дүн, «Төлөлт» нь төлсөн мөнгө.
- **Устгах биш, цуцал.** Төлбөр, нэхэмжлэх, төлөлтийг устгадаггүй, «Цуцлах» товчоор цуцалдаг.
- **Е-баримттай төлөлтийг цуцлахын өмнө** баримтаа «И-Баримт → Буцаах».
- **Мөр алга болвол** эхлээд огнооны 📅 шүүлтээ шалга. → [Жагсаалт хоосон](/owner/jagsaalt-hooson-shuult)
- **Товч бүрийн тайлбар** хэрэгтэй бол тухайн жагсаалтын **«?»** товчийг дар.
