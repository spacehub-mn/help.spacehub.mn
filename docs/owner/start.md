> 🏢 Owner, менежер, нягтлан · Вэб (app.spacehub.mn)

Spacehub-д шинээр орсон бол энэ хуудсыг эхлээд уншаарай. Юуг Spacehub баг тохируулдаг, юуг та шалгах ёстойг, мөн 2 сургалт руу хөтөлнө.

## 1. Spacehub баг юу тохируулж өгөх вэ
Эхний тохиргоог **Spacehub баг** таны өгсөн мэдээллээр хийж өгнө:
- байгууллага, банкны данс;
- хэрэглэгчид (нэвтрэх эрх);
- объект, өрөө/талбай;
- гэрээ, үйлчилгээ;
- тоолуурын эхлэл заалт;
- эхний үлдэгдэл.

Тохиргоо дууссаны дараа доорх **3 зүйлийг заавал шалга**:
1. **Менежмент → Гэрээ** — бүх гэрээ байгаа эсэх, үнэ, талбай нь зөв эсэх. Огнооны шүүлтийн **✕** дарж «📅 Бүх огноо» болго. → [Хугацаа зөв сонгох](/owner/hugatsaa-songoh)
2. **Тооцоо → Эхний үлдэгдэл** — өмнөх өр («Дутуу») ба илүү төлөлт («Илүү») зөв орсон эсэх.
3. Нэвтэрч чадахгүй, эсвэл цэс дутуу харагдвал → [Эрхгүй, нэвтэрч чадахгүй](/owner/erhgui-nevtreh)

Програмын ерөнхий ажиллагааг (цэс, жагсаалт, карт, шүүлт) **Програм ашиглах** хуудаснаас үз.

## 2. Сар бүрийн ажил — дарааллаар
```
Тоолуур → Сарын тооцоо → Нэхэмжлэх → Хуулга / Төлөлт → Е-баримт
```
- 📘 Алхам алхмаар → [Сар бүрийн ажил](/owner/tutorial/sar-buriin-ajil) (тоолуураас сарын хаалт хүртэл, шалгах газартай).
- 📘 Шинэ байгууллага бол эхлээд → [Эхний сар — шинэ owner](/owner/tutorial/ehnii-sar) (бүртгэлээс эхний е-баримт хүртэл, бодит алдаануудтай).
- ⚠️ Өмнөх сарын төлөлтийн е-баримтыг **дараа сарын 7-ны дотор** гарга. Түүнээс хойш автоматаар гарахгүй.

## 3. Эхний сард анхаарах 5 зүйл
- **Төлбөр ≠ Төлөлт.** «Төлбөр» нь төлөх ёстой дүн, «Төлөлт» нь төлсөн мөнгө.
- **Устгах биш, цуцал.** Төлбөр, нэхэмжлэх, төлөлтийг устгадаггүй, «Цуцлах» товчоор цуцалдаг.
- **Е-баримттай төлөлтийг цуцлахын өмнө** баримтаа «И-Баримт → Буцаах».
- **Мөр алга болвол** эхлээд огнооны 📅 шүүлтээ шалга. → [Жагсаалт хоосон](/owner/jagsaalt-hooson-shuult)
- **Товч бүрийн тайлбар** хэрэгтэй бол тухайн жагсаалтын **«?»** товчийг дар.
