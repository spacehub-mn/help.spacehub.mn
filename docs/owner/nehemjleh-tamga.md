# Нэхэмжлэх дээр нягтлан, тамга, гарын үсэг

> 🏢 Эзэмшигч, нягтлан · Вэб (app.spacehub.mn)

Нэхэмжлэхийн доод талд **Захирал**, **Нягтлан бодогч**-ийн нэр болон байгууллагын **тамга** гарна. Тэд хаанаас ирдэг, тамга гарахгүй бол юуг шалгахыг энд тайлбарлав.

## Юу хаанаас ирдэг вэ
- **Захирал** — байгууллагын карт дээрх **«Захирал/Эзэн»**.
- **Нягтлан бодогч** — нэхэмжлэх үүсэх үед сонгогдсон нягтлан. Объект дээр тусдаа **«Ерөнхий нягтлан»** сонгосон бол тэр хүн, үгүй бол байгууллагын карт дээрх **«Ерөнхий нягтлан»**.
- **Тамга** (гарын үсэгтэй хамт) — Spacehub багийн байршуулсан зураг. Хэрэглэгчийн карт дээрээс **оруулдаггүй**.

## Захирал, нягтланг сонгох
![Байгууллагын карт: Захирал/Эзэн, Ерөнхий нягтлан](/img/owner/nehemjleh-tamga-1.webp)

*Зураг 1. Менежмент → Байгууллага → өөрийн байгууллагын карт. Хүний нэрийг бүдгэрүүлсэн. Улаан дугаар = алхмын дугаар.*

1. **Менежмент → Байгууллага** цэсийг нээ.
2. Өөрийн байгууллагын картыг нээ.
3. **«Захирал/Эзэн»** талбарт захирлаа сонго.
4. **«Ерөнхий нягтлан»** талбарт нягтлангаа сонго. Жагсаалтад хүн алга бол эхлээд хэрэглэгчээр бүртгэ. → [Хэрэглэгч](/owner/list/User_ListView)
5. Баруун дээд талын **«Хадгал»** дар.
6. Өмнө үүссэн нэхэмжлэхэд шинэ нягтланг тусгах бол **Тооцоо → Нэхэмжлэх**-ээс тэдгээрийг сонгоод **«Нэхэмжлэх шинэчлэх»** дар. Энэ товч дүнг ч төлбөрийн одоогийн мэдээллээр дахин боддог. → [Нэхэмжлэхийн дүн зөрж байна](/owner/nehemjleh-dun-zoroh)

## Тамга оруулах
- Тамганы зургаа (гарын үсэгтэй бол хамт) **Spacehub багт илгээнэ**. Бид байршуулна.
- Вэбээс өөрөө оруулах боломжгүй. Хэрэглэгчийн карт дээр «Тамга», «Гарын үсэг» талбар харагдаж болох ч нэхэмжлэх тэдгээрийг **ашигладаггүй**.

## «Тамга солигдов» тохиргоо
Байрлал: **Менежмент → Байгууллага** → өөрийн байгууллагын карт → **Нэмэлт тохиргоо** → **Үндсэн тохиргоо** хэсэг. → [Байгууллагын тохиргоо](/owner/tohirgoo)

- **Унтраалттай** (анхдагч) — бүх нэхэмжлэхэд байгууллагын нэг тамга гарна.
- **Асаалттай** — тамгыг **нягтлан тус бүрээр** (нягтлангийн утасны дугаараар) ялгаж хайна. Тиймээс тамга гарахын тулд:
  - нэхэмжлэх үүсэх үед нягтлан сонгогдсон байх;
  - тэр нягтлангийн тамганы зургийг Spacehub баг байршуулсан байх ёстой.

  Аль нэг нь дутвал нэхэмжлэх дээр тамга **гарахгүй**.
- Энэ тохиргоог асаахаасаа өмнө Spacehub багт хандаарай. Тамганы зураг бэлэн болсны дараа асаана.

## Тамга гарахгүй байна — шалгах
1. **«Тамга солигдов» асаалттай юу?** Асаалттай бол байгууллагын карт дээр **«Ерөнхий нягтлан»** сонгогдсон эсэхийг шалга. Сонгоогүй байсан бол сонгоод («Захирал, нягтланг сонгох»), тамгагүй гарсан нэхэмжлэхүүдээ **«Нэхэмжлэх шинэчлэх»**-ээр шинэчил.
2. **Нягтлангийн нэр харагдаж байгаа ч тамга алга.** Нэр нь нэхэмжлэх дээр нягтлан хоосон бол байгууллагын картаас орж ирдэг. Харин тамга нь нэхэмжлэх үүсэх үеийн нягтлангаар хайгддаг. Нэхэмжлэх үүсэх үед нягтлан сонгоогүй байсан бол дээрх «Захирал, нягтланг сонгох»-ыг хий.
3. **Нягтлан сольсон, эсвэл нягтлангийн утас өөрчлөгдсөн.** «Тамга солигдов» асаалттай бол шинэ нягтлангийн тамгыг Spacehub баг байршуулах хэрэгтэй. Spacehub багт мэдэгд.
4. **Унтраалттай байхад тамга гарахгүй.** Таны байгууллагын тамга байршуулагдаагүй байна. Тамганы зургаа Spacehub багт илгээ.
