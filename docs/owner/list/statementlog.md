# Хуулга таталт (жагсаалт)

> 🏢 Эзэмшигч, нягтлан · Вэб (app.spacehub.mn) · Цэс: **Автоматжуулалт → Дансны хуулга → Хуулга таталт**

## Энэ юу вэ
Банкнаас **хуулга татах оролдлого бүрийн бүртгэл**: хэзээ ажилласан, хэдэн гүйлгээ татсан, алдаа гарсан эсэх. Хуулга татагдахгүй байна гэж сэжиглэвэл эндээс шалгана.

Нэгдсэн зургийг **Менежмент → Дашборд → Хуулга монитор**-оос харах нь илүү хялбар.

## Хэзээ хэрэглэх
- Банкны хуулга **хэзээ, амжилттай** татагдсаныг шалгах.
- Өнөөдөр хуулга ирээгүй үед — сүүлд ажилласан цагийг хар.
- Яаралтай татах бол **Дансны хуулга**-аас «Хуулга татах».

## Жагсаалт ба карт
Цэс: **Автоматжуулалт → Дансны хуулга → Хуулга таталт**. Хамгийн сүүлийн оролдлогыг харахын тулд **Хамгийн сүүлд ажилласан** баганаар буурахаар эрэмбэл.

![Хуулга таталт жагсаалт: Код, Байгууллага, Хамгийн сүүлд ажилласан, Нийт татсан хуулганы тоо](/img/owner/list/statementlog.webp)

*Зураг 1. Хуулга таталт жагсаалт. Дансны дугаарыг бүдгэрүүлсэн. Улаан дугаар = доорх мөрийн дугаар.*

1. **Код** — оролдлогын дугаар.
2. **Байгууллага** — таны байгууллага.
3. **Хамгийн сүүлд ажилласан** — таталт ажилласан цаг.
4. **Нийт татсан хуулганы тоо** — тэр удаа банкнаас ирсэн гүйлгээний тоо.

- Жагсаалтад мөн **Эхлэх огноо**, **Дуусах огноо**, **Эх сурвалж**, **Данс**, **Банк сервис, тохиргоо** багана бий.
- Мөр дээр дарвал карт нээгдэнэ:
  - **Шинэ хуулгын тоо** — өмнө нь байгаагүй шинэ гүйлгээ;
  - **Төлөв**: **Амжилттай** · **Алдаатай**;
  - **Алдааны мэдээлэл** — банкнаас ирсэн алдааны текст;
  - **Татсан хуулганууд** — энэ удаа татсан гүйлгээнүүд.

## Товчнууд
> ℹ️ Энэ жагсаалт **зөвхөн харах** зориулалттай. «Шинэ», «Устгах» товч ба тусгай товч байхгүй. **Сэргээх**, **Export** (Excel рүү гаргах), багана тохируулах л байна.

## Түгээмэл асуулт
- **Өнөөдөр хуулга ирээгүй.** Сүүлийн мөрийн **Хамгийн сүүлд ажилласан** цагийг хар.
  - Ажилласан, гэхдээ **Шинэ хуулгын тоо** 0 бол банкинд шинэ гүйлгээ байхгүй.
  - **Алдаатай** бол **Алдааны мэдээлэл**-ийг дэмжлэгт илгээ.
  - Огт ажиллаагүй бол дэмжлэгт шууд мэдэгдэ.
- **Яаралтай татах.** **Дансны хуулга** жагсаалтаас данс сонгоод «Хуулга татах», эсвэл «Хуулга татах (Excel)». → [Хуулгаас төлбөр бүртгэх](/owner/huulga-tolbor)
- **Жагсаалт удаан нээгдэж байна.** Энэ жагсаалт бүх мөрийг (олон арван мянга) нэг дор ачаалдаг. Ердийн шалгалтыг **Дашборд → Хуулга монитор**-оос хий.
