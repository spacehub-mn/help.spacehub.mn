# Тайлан

> 🏢 Owner, нягтлан · Вэб (app.spacehub.mn) · Цэс: **Тайлан**

## Энэ юу вэ
Бэлэн загвартай **тайлангууд**: нэгтгэл, дансны хуулга гэх мэт. Тайлан бүр **параметр** (хугацаа, объект, данс) бөглөсний дараа гарна. Тайлангийн жагсаалт байгууллага бүрт өөр байж болно.

Тайлангууд дугаартай. Ихэнх нь **«— Хурдан»** хувилбартай. Хурдан хувилбар нь илүү хурдан ачаална, тиймээс түүнийг хэрэглэ.
- **01. Нэгтгэл** — гэрээ бүрийн тооцооны нэгтгэл.
- **02. Тооцоо задаргаа**.
- **03. Түрээслэгчид**.
- **04. Эхний үлдэгдэл**.
- **05. Төлбөрийн задаргаа сараар**.
- **06. Дансны хуулга** — **Данс** параметрт зөвхөн таны эрхтэй данснууд гарна.
- **07. Гэрээний дугаар хэвлэх**.
- **09. Тоолуур заалт**.
- **10. Нэгтгэл задаргаа**.
- **11. Нэгтгэл сараар**.
- **12. Ebarimt Жагсаалт**.
- **13. Нэгтгэл задаргаа (Менеж, Цахил)**.
- **14. Төлөлтүүд сараар**.
- **16. Ашиглалт нэгтгэл задаргаа**.
- **17. Түрээс нэгтгэл задаргаа**.
- **19. Нэгтгэл хөнгөлөлт**.
- **20. Нэгтгэл бүгд**.
- **22. Ашиглалт, Түрээс задаргаа жилээр**.
- **23. Ашиглалт нэгтгэл задаргаа жилээр**.

Жагсаалтад өөр байгууллагын нэртэй (08, 15, 18, 21) эсвэл туршилтын («Report by …») тайлан харагдаж болно. Тэдгээрийг **бүү ашигла**.

## Тайлан гаргах
1. **Тайлан** цэснээс тайлангаа сонго.
2. **Хугацаа**, **объект** (шаардлагатай бол **данс**)-оо заавал бөглө. «Waiting for parameter values» гэж гарвал параметр дутуу байна.
3. Тайлан ачаалахыг хүлээ. Урт хугацаатай тайлан хэдэн секунд болно.
4. Тайлан харагчийн товчоор **хэвлэх** эсвэл **PDF / Excel** болгон татна. Харагч нь стандарт DevExpress харагч тул товчнууд англиар харагдаж магадгүй ❔.

## Жагсаалтыг Excel-ээр татах
Тайлангаас гадна ямар ч жагсаалтыг **Export** товчоор Excel-ээр татаж болно:
1. Жагсаалтаа нээ.
2. Хэрэгтэй баганаа нэм (багана тохируулах).
3. Шүүлтээ тохируул. → [Жагсаалт хоосон](/owner/jagsaalt-hooson-shuult)
4. **Export** дар.

> ℹ️ Жагсаалтын доторх «тайлан харах» товчийг санаатайгаар нуусан. Тайланг зөвхөн **Тайлан** цэснээс нээнэ.

## Тооцооны хуудас ба нэхэмжлэх
- **Нэхэмжлэх** — тухайн сард төлөх ёстой дүн. Харилцагч руу илгээдэг.
- **Тооцооны хуудас** (нэгтгэл) — эхний үлдэгдэл, бүх нэхэмжлэх, бүх төлөлт, эцсийн үлдэгдэл. Тооцоо нийлэхэд хэрэглэнэ.

## Түгээмэл асуулт
- **Тайлан хоосон гарсан.** Хугацаа, объект сонгоогүй эсвэл тухайн хугацаанд мэдээлэл байхгүй байна.
- **«06. Дансны хуулга»-д данс гарахгүй.** Таны хэрэглэгчид тэр дансны эрх байхгүй байж магадгүй. → [Эрхгүй, нэвтэрч чадахгүй](/owner/erhgui-nevtreh)
- **Нэгтгэл удаан байна.** «01. Нэгтгэл — Хурдан»-ыг ашигла.
- **Тооцооны хуудсыг нэхэмжлэх гэж илгээсэн.** Дээрх ялгааг хар.
