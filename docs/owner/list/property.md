# Объект (жагсаалт)

> 📋 Лавлах · 🏢 Эзэмшигч, менежер · Вэб (app.spacehub.mn) · Цэс: **Менежмент → Объект**

## Энэ юу вэ
Таны **барилга, объектуудын** жагсаалт. Объект бүрийн талбайн тоо, нийт талбай, **ашиглалтын хувь**, түрээсийн дүн харагдана.

Объектыг Spacehub баг анх тохируулна. Та энд мэдээллээ харж, засна.

## Хэзээ хэрэглэх
- Объект хэдэн хувь **түрээслэгдсэнийг** харах (**Ашиглалт**).
- Объектын **утас**, **м² үнэ**, **хаяг**, **данс** засах.
- Объект **«Автомат ажил»**-д орсон эсэхийг шалгах. → [Автомат ажлын 3 түвшин](/owner/concepts/avto-3-tuvshin)

## Товчнууд
- Жагсаалтад тусгай товч алга. Стандарт товчнууд: **Шинэ**, **Сэргээх**, хайлт, шүүлт. → [Цэс ба товчнууд](/owner/navigation)
- Шинэ объектыг Spacehub багтай тохирч нэмнэ — үнэ, талбайн тохиргоо хамт хийгдэнэ.

## Баганууд
- **УБ-дугаар** — үл хөдлөх хөрөнгийн улсын бүртгэлийн дугаар.
- **Объектын төрөл** — Оффис, Задгай зах, Орон сууц, Худалдааны төв, Авто зогсоол, Хаус хотхон, Жижиглэн талбай.
- **Нэр**, **Эзэмшигч байгууллага**, **Утас**.
- **М2 үнэ** — нэг м²-ийн үнэ.
- **Автомат ажил эхлэх өдөр**, **Автомат ажил** — сар бүрийн автомат тооцоо.
- **Талбайн тоо**, **Нийт талбай** — талбайтай (м² > 0) өрөөнүүд. Хуучин өрөө тоологдохгүй.
- **Ашиглалт** — **түрээслэгдсэн** бөгөөд **«Эзэнтэй»** тэмдэгтэй талбайн хувь (нийт талбайгаас).
- **Түрээс дүн** — нийт талбай × м² үнэ. Бодит гэрээний дүн биш, тооцоолсон дүн.
- **Туршилт дата** — эзэмшигч байгууллага нь туршилтынх эсэх (байгууллагын тохиргооноос).

## Карт
Мөр дээр дарж картыг нээнэ. Гол талбарууд:
- **УБ-дугаар**, **Нэр**, **Товч нэр**, **Зураг**, **Эзэмшигч байгууллага**, **Эхлэл огноо**, **Утас**, **Хаяг**, **Банкны данс** — заавал бөглөнө.
- **Имэйл**, **Давхар**, **Доод давхар**, **Төлбөрийн график төрөл**, **Барилгын план**.
- **Ерөнхий нягтлан** — төлбөр тооцоо хариуцсан хүн. Сонголтод танай байгууллагын ажилтнууд гарна. Толгой компанитай бол түүний ажилтнууд ч гарна. Түрээслэгч гарахгүй.
- Хадгалахдаа **«Хадгал»** дарна. Заавал талбар хоосон бол хадгалахгүй.

## Хуучирсан талбайг сэргээх {#talbai-sergeeh}
**«Хуучирсан талбай»** тэмдэгтэй талбай шинэ гэрээнд сонгогдохгүй, талбайн тоонд орохгүй. Объектын картын **«Өрөө/Талбай»** табд зураастай бичвэрээр харагдана.

1. Объектын картын **«Өрөө/Талбай»** табаас талбайн мөр дээр дар. «Өрөө/Талбай …» жижиг цонх нээгдэнэ.
2. **«Хуучирсан талбай»** чагтыг ав (сэргээх). Хуучруулах бол чагтал.
3. Жижиг цонхны **«Хадгал»** дар. Цонх хаагдаж, зураас арилна.
4. ⚠️ Одоо **объектын картын** баруун дээд булангийн улбар шар **«Хадгал»** (диск дүрс) товчийг заавал дар. Үүнийг дарах хүртэл өөрчлөлт **хадгалагдаагүй**.

- Табын нэрний ард **«*»** байвал хадгалаагүй өөрчлөлт байна гэсэн үг. 4-р алхмыг алгасаад хаавал өөрчлөлт алга болно.
- «Хадгал» дарсны дараа «*» арилахгүй бол объектын эсвэл аль нэг талбайн **заавал талбар** хоосон байна. Бөглөөд дахин «Хадгал» дар.
- **«Эзэнтэй»** тэмдгийг хөндөх шаардлагагүй.
- Объектын **«Талбай сэргээх»** товч «Хуучирсан талбай» тэмдгийг **өөрчилдөггүй**. Дээрх алхмаар сэргээ.

## Үйлчилгээг бүх гэрээнд нэмэх {#gereenuud-ruu-oruulah}
Объектод шинэ үйлчилгээ (жишээ нь бохир усны суурь хураамж) нэмээд, тэр объектын **бүх нээлттэй гэрээнд** нэг дор оруулна.
1. Объектын картын **«Үйлчилгээнүүд»** жагсаалтаас **нэг** үйлчилгээг сонго.
2. **«Гэрээнүүд рүү оруулах»** дар. Цонх нээгдэнэ.
3. **«Бодогдож эхлэх огноо»**-г шалга. Анхдагч нь дараа сарын 1. Үүнээс өмнөх саруудад тэр үйлчилгээ 0₮ бодогдоно.
4. **«Урьдчилан харах»**-аас хэдэн гэрээнд нэмэх, хэдийг алгасахыг уншина. Жишээ нь: «120 гэрээнд 2026-12-01-ээс нэмнэ · алгасна: аль хэдийн байгаа 15, хаагдсан/дууссан 3».
5. **«OK»** дар. «N гэрээнд «…» нэмэв» гэж гарна.

- **Хамрах гэрээ:** хаагдаагүй, огнооноос хойш идэвхтэй. Дуусах огноо өнгөрсөн ч огнооноос хойш хуваарьтай гэрээ орно.
- **Алгасах гэрээ:** тэр үйлчилгээ аль хэдийн байгаа, эсвэл хаагдсан/дууссан гэрээ.
- Зөвхөн түрээсийн гэрээнд ашиглалтын үйлчилгээ нэмэгдэнэ, гэхдээ **«Ашиглахгүй»** төлөвтэй. Зөвхөн ашиглалтын гэрээнд түрээсийн үйлчилгээ мөн адил.
- Гэрээний бусад үйлчилгээ өөрчлөгдөхгүй. Үнэ нь объектын үнээр, сонгосон огнооноос мөрдөгдөнө.
- ⚠️ Бүх гэрээнд **шууд бичигдэнэ**. Буцаах товч байхгүй. Урьдчилан харах тоог сайн шалга.
- Тухайн сарын төлбөр аль хэдийн үүссэн бол **Тооцоо → Төлбөр**-өөс «Төлбөр шинэчлэх».

## Архивласан объект {#arhivlasan}
- Жагсаалтын анхдагч шүүлт **«Идэвхтэй»** — архивласан объект харагдахгүй.
- Архивласан объектыг **«Архивласан»** эсвэл **«Бүгд»** шүүлтээр харна.
- Объектыг архивлах (нуух) бол Spacehub багт хандана.

## ⚠️ Анхаар
- Жагсаалт **устгах** товчгүй. Объектыг устгах бол Spacehub багт хандана.
- Олон айлын үнийг өөрчлөх бол → [Үнэ өөрчлөх](/owner/une-oorchloh)
- Жагсаалт удаан нээгдэж магадгүй. Хүлээгээд дахин оролд. → [Удаан ачаалах, гацах](/owner/gatsah-udaan)

## Түгээмэл асуулт
**Ашиглалт 0% байна.**
Талбайнуудын м² бөглөгдсөн, **түрээслэгдсэн** төлөвтэй, **«Эзэнтэй»** тэмдэгтэй эсэхийг шалга.

**Талбайн тоо бодит тооноос бага байна.**
Талбай (м²) нь 0 эсвэл хуучин гэж тэмдэглэгдсэн өрөө тоологдохгүй.

**Талбай гэрээнд сонгогдохгүй, алга болсон.**
«Хуучирсан талбай» тэмдэгтэй байж магадгүй. → [Хуучирсан талбайг сэргээх](#talbai-sergeeh)
