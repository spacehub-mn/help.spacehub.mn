# Тоолуурын заалтыг Google Sheet-ээс оруулах (тоолуурын кодоор)

> 🏢 Эзэмшигч, нягтлан · Вэб (app.spacehub.mn) · **Объектын карт → «Google Sheet»**

## Энэ юу вэ
Объектын олон тоолуурын сарын заалтыг Google Sheet-ээс нэг дор оруулна. Мөр бүрийг **талбайн дугаар** ба **тоолуурын кодоор** таньдаг.

Гэрээндээ тоолуурыг **тоолуурын кодоор** холбосон бол энэ хуудсаар оруул. → [Тоолуур нэмэх, солих](/owner/tooluur)

:::tip Хуучин «Тоолуур татах» цэс
**Автоматжуулалт → Тоолуур татах** нь гэрээний дугаар, нэг мөрөнд 3 тоолуураар ажилладаг хуучин арга. → [Тоолуур татах](/owner/list/UtilitySheet_ListView)
:::

## Google Sheet бэлдэх
- Тоолуурын **төрөл бүрд тусдаа хуудас** (таб) хэрэгтэй. Хуудасны нэр:
  - «Цахилгаан тоолуур»;
  - «Халуун ус тоолуур»;
  - «Хүйтэн ус тоолуур»;
  - «Газ тоолуур»;
  - «Эйр кондишн тоолуур».
- 1-р мөр гарчиг, заалт **2-р мөрөөс** эхэлнэ. Баганууд:
  - **A** — талбайн дугаар (апп дээрх талбайн кодтой яг ижил);
  - **B** — заалтын огноо;
  - **C** — тоолуурын код;
  - **D** — заалт.
- Хоосон нүд байвал «Зарим нүд хоосон байна…» гэж гарна. Хэрэггүй нүдэнд **n/a** гэж бич.
- Sheet-ээ Spacehub-тай **хуваалц**. Алхам нь хуучин хуудастай ижил. → [Sheet-ийг Spacehub-тай хуваалцах](/owner/list/UtilitySheet_ListView#sheet-huvaaltsah)

## Заалт татах, оруулах
1. Объектынхоо **картыг** нээ. → [Объект](/owner/list/Property_ListView)
2. Картын дээд талын **«Google Sheet»** товч дар. **«Барилгын өгөгдөл оруулах»** цонх нээгдэнэ.
3. **Өгөгдөл төрөл**-өөс тоолуурын төрлийг сонго. Жишээ нь «Цахилгаан тоолуур».
4. **GoogleSheet ID**-д Sheet-ийн ID-г бич. **SheetRange** өөрөө бөглөгдөнө, жишээ нь `Цахилгаан тоолуур!A2:D`.
5. **«Татах»** дар. Доорх **«Шинэ тоолуур»** жагсаалтад Sheet-ийн мөрүүд гарна. Энэ үед юу ч хадгалагдаагүй.
6. Мөрүүдээ шалгаад **«Оруулах»** дар.
7. «Шинээр амжилттай оруулсан: N» гарвал бүх мөр орсон.
8. Өөр төрлийн тоолуур байвал 3-аас давт.

Sheet-ийн ID нь Sheet-ийн хаягийн `/d/` ба `/edit` хоорондох урт бичвэр.

## Оруулахад юу болдог вэ
- Мөрийг **талбайн дугаараар** талбайд, тэр талбайн **идэвхтэй гэрээнд** оруулна.
- Тоолуурын код объект дээр байхгүй бол **шинэ тоолуур** үүсгэж, гэрээнд холбоно.
- Тухайн сарын төлбөрийн хуваарь гэрээнд байхгүй бол **хуваарийг үүсгэнэ**.
- Талбай **дундын** (нийтийн) бол тэр давхрын идэвхтэй гэрээ бүрт заалтыг нэмнэ.
- Оруулсан мөрүүд жагсаалтаас арилна. **Алгассан мөр шалтгаантайгаа үлдэнэ.**

## Дахин татах: давхардахгүй, дарж бичнэ
- Нэг гэрээ, нэг сар, нэг төрөл, нэг **тоолуурын код**-д заалт аль хэдийн байвал Sheet-ийн утгаар **дарж бичнэ**.
- Шинэ мөр давхардаж үүсэхгүй.
- Тиймээс буруу заалт оруулсан бол Sheet-ээ засаад 5–6-р алхмыг давт.

## Төлбөр шинэчлэх
- Энэ импорт **төлбөр, нэхэмжлэх үүсгэдэггүй**. Зөвхөн заалт бүртгэнэ.
- Тэр сарын төлбөр **аль хэдийн үүссэн** бол дүн нь өөрөө солигдохгүй.
- Заалт оруулсны дараа **Тооцоо → Төлбөр**-өөс тэр сарын төлбөрөө сонгоод **«Төлбөр шинэчлэх»** дар. → [«Төлбөр шинэчлэх»](/owner/list/Bill_ListView#tolbor-shinechleh)

## Алгассан мөр
Үр дүнд «Оруулсан: N / Алгассан: M» гарвал үлдсэн мөрийн **Алгасах шалтгаан**-ыг хар.

- **«Талбай олдсонгүй»** — A баганын дугаар объектын талбайн кодтой таарахгүй байна. Sheet-ээ засаад дахин тат.
- **«Идэвхтэй гэрээ байхгүй»** — тэр талбайд хаагаагүй гэрээ алга.
- **«Идэвхтэй олон гэрээ — тоолуурын эзэн тодорхойгүй»** — нэг талбайд олон гэрээ байна. Тоолуурыг зөв гэрээндээ гараар холбоод дахин оруул.
- **«Тоолуур гэрээн дээр цуцлагдсан»** — тэр кодтой тоолуурыг гэрээн дээр цуцалсан байна. Шинэ тоолуурын кодоо Sheet-д бич.

⚠️ Эхний заалт 0 атлаа хэрэглээ хэт их гарвал оруулаад анхааруулга харуулна. Тэр мөрийн эхлэл заалтыг шалга.

## Түгээмэл асуулт
- **«Талбаруудыг заавал бөглөнө үү» гэж гарлаа.** GoogleSheet ID эсвэл SheetRange хоосон байна.
- **«Forbidden» эсвэл «The caller does not have permission» гэж гарлаа.** Sheet-ээ Spacehub-тай хуваалцаагүй байна. → [Хуваалцах алхам](/owner/list/UtilitySheet_ListView#sheet-huvaaltsah)
- **Хуучин «Тоолуур татах»-аар уу, энэ хуудсаар уу?** Гэрээндээ тоолуурын кодоор холбосон бол энэ хуудсаар.
