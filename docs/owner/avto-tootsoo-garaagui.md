# Авто тооцоо, нэхэмжлэх гараагүй

> 🏢 Owner, нягтлан · Вэб (app.spacehub.mn)

Сарын эхэнд зарим айлд **автоматаар** тооцоо, нэхэмжлэх үүсээгүй бол доорх дарааллаар шалга.

## 1. Авто ажил ажиллаж байна уу
- **Автоматжуулалт → Авто ажил** — тухайн объект, **тухайн сарын** ажил байгаа эсэх, статус нь «**Ажиллаж байна**» эсэх.
- Ажил алга бол өмнөх сарын ажлыг сонгоод «**Next Auto Job +**», дараа нь «**Job Create**». «Job start» нь зөвхөн «Зогссон» үед хэрэгтэй. → [Авто ажил](/owner/list/AutoJob_ListView)
- **Авто ажил төрөл** зөв эсэх: «Төл, Нэх үүсгэх» уу, илгээх төрөл үү.

## 2. Гэрээ «Автомат ажил»-д орсон уу (3 түвшин)
Байгууллага, объект, гэрээ **гурвууланд** «Автомат ажил» тэмдэглэгдсэн байх ёстой. Гэрээ хаагдаагүй байх ёстой. Хаагдаад сэргээсэн гэрээнд «Автомат ажил» унтраалттай үлддэг. → [Авто тооцоо — 3 түвшин](/owner/concepts/avto-3-tuvshin)

## 3. Тухайн сарын хуваарь байна уу
- **Тооцоо → Төлбөрийн хуваарь** — тэр гэрээний тэр сарын мөр байгаа эсэх. → [Төлбөрийн хуваарь](/owner/list/ContractPaymentChart_ListView)
- Гэрээ дуусах огноо өнгөрсөн бол хуваарь үүсэхгүй. Гэрээг **сунга**. → [Гэрээ](/owner/list/Contract_ListView)

## 4. Гэрээнд үйлчилгээ байна уу
- Гэрээнд үйлчилгээ огт байхгүй бол **Гэрээ → «Үйлчилгээ татах»**. 10-26-ны шинэчлэлээс хойш үйлчилгээгүй гэрээнд объектын үйлчилгээг автоматаар нэмдэг болно ❔ (deploy-ийн дараа батална).
- Үйлчилгээ «Ашиглахгүй» болсон эсэхийг шалга. → [Үнэ өөрчлөх](/owner/une-oorchloh)

## 5. Тоолууртай гэрээ бол заалт орсон уу
- Ашиглалттай гэрээнд энэ сарын эсвэл өмнөх сарын заалт байхгүй бол гараар («Төлбөр +») тооцоо үүсэхгүй. Авто ажилд мөн адил байж магадгүй ❔. → [Тоолуур нэмэх, солих, цуцлах](/owner/tooluur) · [Төлбөрийн хуваарь → Тоолуур +](/owner/list/ContractPaymentChart_ListView#tooluur)

## Гараар нөхөх
Шалтгааныг зассаны дараа тэр айлын тооцоог **Төлбөрийн хуваарь**-аас **«Төлбөр +»** эсвэл **«Төл & Нэх +»**-ээр гараар үүсгэ. → [Сарын тооцоо гаргах](/owner/sar-tootsoo)
