> 🏢 Owner, менежер, нягтлан · Вэб (app.spacehub.mn)

Owner-уудын хамгийн их асуудаг асуултууд. Асуулт бүр хариулт байгаа хуудас руу холбогдсон.

## Гэрээ, харилцагч
- **«… давхцаж байна» гэж гараад шинэ харилцагч, гэрээ хадгалагдахгүй.** → [Шинэ гэрээ, харилцагч бүртгэхэд алдаа](/owner/shine-geree-aldaa)
- **Олон гэрээг нэг дор яаж сунгах вэ? Үнийг хувиар нэмэх үү?** → [Гэрээ](/owner/list/Contract_ListView) («Сунгах», «Шинэчлэх»)
- **Гэрээ хаагдахгүй байна / буруу гэрээг хаачихлаа.** Хаах цонхны «Зөвшөөрөх» чагтыг тэмдэглэ, үгүй бол «Зөвшөөрөх сонголтыг хийнэ үү!» гэж гарна. Олон мөр сонгогдсон эсэхээ шалга. Буруу хаасныг «Гэрээ сэргээх»-ээр буцаана. → [Гэрээ хаах](/owner/list/ContractSubLists#geree-haah)
- **Барьцааг гэрээнд яаж оруулах вэ? Давхар барьцаа үүссэн.** → [Гэрээ](/owner/list/Contract_ListView) («Барьцаа тохиргоо», «Барьцаа гараар оруулах»)

## Сарын тооцоо, үнэ
- **Энэ сарын тооцоо, нэхэмжлэх автоматаар гараагүй.** → [Авто тооцоо гараагүй](/owner/avto-tootsoo-garaagui)
- **Үнэ, тариф өөрчилсөн ч хуучин үнээр бодогдож байна.** → [Үнэ өөрчлөх](/owner/une-oorchloh)
- **Хөнгөлөлт тооцогдоогүй, нэхэмжлэх дээр гарахгүй байна.**
  - Тохиргооны хөнгөлөлт бол шалгах: **Хөнгөлөлт тохиргоо** идэвхтэй, тэр сарыг хамарсан эсэх; гэрээ «Хамрагдах гэрээнүүд»-д байгаа эсэх; **Төлбөрийн хуваарь** дээр «Хөнгөлөлт тооцохгүй» тэмдэглээгүй эсэх. Нэмэлт төлбөрт хөнгөлөлт үүсдэггүй. Дараа нь «Төлбөр шинэчлэх» → «Нэхэмжлэх шинэчлэх». → [Хөнгөлөлт тохиргоо](/owner/list/DiscountConfig_ListView) · [Хөнгөлөлт](/owner/list/Discount_ListView)
  - «Хугацаандаа төлбөл бонус» төрлийн бол төлөлт дээрх **«Бонус шалгах...»**. → [Төлөлт](/owner/list/Sale_ListView)
- **Төлөөгүй айл «бүрэн төлсөн» гэж харагдаж байна.** **Гэрээ** жагсаалтаас тэр гэрээг сонгоод **«Төлбөрийн төлөв шинэчлэх»**. → [Гэрээ](/owner/list/Contract_ListView) · [Төлбөр → Нэхэмжлэх → Төлөлт](/owner/concepts/tootsoo-nehemjleh-toloh)
- **Эхний үлдэгдлийг яаж оруулах, засах вэ?** → [Эхний үлдэгдэл](/owner/list/BeginBalance_ListView)
- **Алдангийг (өдрийн тогтмол дүн, хувь) яаж тохируулах вэ?** → [Алданги](/owner/concepts/aldangi)
- **Дулаан бодогдоогүй.** → [Дулааны төлбөр](/owner/concepts/dulaan)

## Нэхэмжлэх
- **SMS-ээр очсон дүн төлбөрөөс өөр байна.** → [Нэхэмжлэхийн дүн зөрж байна](/owner/nehemjleh-dun-zoroh)
- **Нэхэмжлэх дээр банкны данс харагдахгүй.** Төлбөр жагсаалтаас төлбөрүүдээ сонгоод **«Данс тохируулах»**. Дараа нь «Нэхэмжлэх шинэчлэх». Энэ товч дутуу дансыг л нэмдэг, буруу дансыг хасдаггүй. Буруу данс байвал гэрээний данс тохиргоог засна ❔. → [Төлбөр](/owner/list/Bill_ListView)
- **Нэхэмжлэх дээр тамга, гарын үсэг гарахгүй / «Захирал»-ын оронд «Нягтлан».** Нэхэмжлэхийн **Захирал**, **Нягтлан** талбарт хэн сонгогдсоныг шалга. Тэдний хэрэглэгчийн карт дээр **Тамга**, **Гарын үсэг** зургийг оруул. → [Хэрэглэгч](/owner/list/User_ListView)
- **Нэхэмжлэх очсон эсэхийг хаанаас харах вэ?** Нэхэмжлэх жагсаалтын **Илгээлт** багана. → [Нэхэмжлэх](/owner/list/InvoiceBill_ListView)
