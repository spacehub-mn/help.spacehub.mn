«SMS-ээр очсон дүн төлбөрөөс өөр», «нэхэмжлэх дээр өмнөх саруудын үлдэгдэл орж ирсэн» гэх мэт тохиолдолд уншаарай.

## «Төлөх дүн» юунаас бүрддэг вэ
```
Төлөх дүн  =  Өмнөх үлдэгдэл  +  энэ сарын Нийт  (бүхэл төгрөг рүү дээш бүхэлчилнэ)
```
- **Өмнөх үлдэгдэл** — нэхэмжлэхийн огноо хүртэлх бусад **төлөгдөөгүй** төлбөрүүдээс тэр огноо хүртэлх төлөлтийг хассан дүн. Илүү төлсөн бол «Илүү (…₮)» гэж хасах утгатай гарна. Төлбөрийн загвар нь тусдаа урсгалтай бол зөвхөн тэр урсгалынхыг тооцно.
- Тиймээс **Төлөх дүн** нь энэ сарын **Төлбөр**-өөс их байх нь хэвийн. Харилцагч өмнөх сард дутуу төлсөн гэсэн үг.
- SMS-д энэ **Төлөх дүн** явна.

## Нэхэмжлэх төлбөрийг автоматаар дагадаггүй
Нэхэмжлэх нь **үүсэх үеийнхээ** дүнг хадгална. Дараа нь төлбөрийг өөрчилбөл (заалт, хөнгөлөлт, үнэ засвал) нэхэмжлэх **хуучин дүнгээрээ** үлдэнэ.

Засах арга:
- **Тооцоо → Нэхэмжлэх → «Нэхэмжлэх шинэчлэх»** — сонгосон нэхэмжлэхийг төлбөрийн одоогийн мэдээллээр дахин бодно. Нэг удаад 20 хүртэл. Огноо нь сарын хүрээнээс хэтэрсэн бол сарын сүүлийн өдөрт татагдана. → [Нэхэмжлэх](/owner/list/InvoiceBill_ListView)
- **Тооцоо → Төлбөр → «Нэхэмжлэх шинэчилж илгээх»** — дүн өөрчлөгдсөн бол **шинэ** нэхэмжлэх үүсгэнэ. SMS чагт анхдагчаар унтраалттай. → [Төлбөр](/owner/list/Bill_ListView)

## Шалгах дараалал

![Төлбөр жагсаалт: Төлбөр шинэчлэх товч](/img/owner/nehemjleh-dun-1.webp)

*Зураг 1. Тооцоо → Төлбөр жагсаалтын «Төлбөр шинэчлэх» товч. Мөр сонгох хүртэл саарал байна.*

1. **Төлбөр** зөв үү? Заалт, хөнгөлөлт, үнээ шалга. Шаардлагатай бол мөрөө сонгоод **«Төлбөр шинэчлэх»** дар.

![Нэхэмжлэх жагсаалт: Нэхэмжлэх шинэчлэх, SMS илгээх](/img/owner/nehemjleh-dun-2.webp)

*Зураг 2. Тооцоо → Нэхэмжлэх жагсаалт. Хулганаа товч дээр аваачихад тайлбар нь гарна.*

2. **Нэхэмжлэх** төлбөртэйгөө таарч байна уу? Үгүй бол мөрөө сонгоод **«Нэхэмжлэх шинэчлэх»** дар.
3. Засварын дараа **SMS илгээх** товчоор дахин илгээ. Өнөөдөр нэг төлбөрөөр SMS явсан бол систем дахин илгээхгүй («өнөөдөр аль хэдийн илгээсэн»). Маргааш илгээ, эсвэл «Өөр дугаар руу илгээх»-ийг ашигла.

- Засвар хийсэн ч дүн зөрсөөр байвал **Өмнөх үлдэгдэл**-ийг шалга. Өмнөх саруудын төлбөр бүгд «төлсөн» эсэхийг хар. Төлсөн атал үлдэгдэл харагдвал төлөлт хуваарилагдаагүй байж магадгүй. → [Төлбөр → Нэхэмжлэх → Төлөлт](/owner/concepts/tootsoo-nehemjleh-toloh)
