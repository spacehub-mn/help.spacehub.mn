# Эрхгүй, нэвтэрч чадахгүй үед

## Энэ юунд хэрэгтэй
Товч саарал, «хадгалах эрхгүй» гэсэн улаан бичиг, эсвэл нэвтрэх үеийн алдаа гарч болно. Ихэнхдээ хэрэглэгчийн **эрх (role)** хүрэлцэхгүй эсвэл нууц үг солигдсон байдаг.

## Алхам
1. Алдааны бичгийг уншаад зураг ав — «...prohibited by security rules» гэвэл эрхийн асуудал.
2. Байгууллагынхаа **админ эрхтэй хүнд** хандаж эрх нэмүүл (шинэ нягтлан, ажилтан ажилд орсон бол).
3. Нэвтэрч чадахгүй бол **нэг удаагийн нууц үг (OTP)**-ээр нэвтэрч, шууд нууц үгээ соль.
4. Хоёр өөр хаягтай бол (app.spacehub.mn ба <компани>.app.spacehub.mn) **нэгийг** нь байнга хэрэглэ.
5. Эрх нэмүүлсний дараа програмаас **гараад дахин нэвтэр** — эрх шууд хүчинтэй болдоггүй.

## Түгээмэл алдаа
- Шинэ ажилтан хуучин хүний эрхээр орж байна — тус бүрд хэрэглэгч үүсгэ.
- Гэрээ оруулах хүн данс холбох шаардлагатай ч дансны мэдээлэл харах эрхгүй → админтай тохируулах.
- Тоолуурын заалт хадгалахад «ContractUtility ... prohibited» — эрхийн тохиргоо.
- Нууц үгийг Viber бүлэгт бичих — бүгд хардаг. Зөвхөн хувийн сувгаар эсвэл OTP.
