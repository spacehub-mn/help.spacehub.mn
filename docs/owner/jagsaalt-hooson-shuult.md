# Жагсаалт хоосон эсвэл айл «алга болсон» үед — шүүлтээ шалгах

## Энэ юунд хэрэгтэй
Жагсаалтад байх ёстой айл харагдахгүй байна уу? Ихэнхдээ өмнө тавьсан **шүүлт (filter)** эсвэл **хайлт** идэвхтэй үлдсэнээс болдог. Мэдээлэл устаагүй.

## Алхам

![Төлбөр жагсаалт: огнооны шүүлт, хайлт, баганын шүүлт](/img/owner/jagsaalt-hooson.webp)

*Зураг 1. Жагсаалт хоосон («No data to display») — шүүлтүүд хаана байдаг вэ («Төлбөр» жагсаалт жишээ).*

1. **Огнооны хүрээ**-г хар. Хайж буй айлын сар энэ хүрээнд орж байгаа эсэхийг шалга. Ороогүй бол дарж хугацааг өөрчил. → [Хугацаа зөв сонгох](/owner/hugatsaa-songoh)
2. Огнооны шүүлтийг бүрмөсөн арилгах бол хажууд нь байгаа **✕** товчийг дар.
3. Баганын толгойн **юүлүүр** болон доор нь байрлах шүүлтийн мөрөнд утга үлдсэн эсэхийг хар. Үлдсэн бол арилга.
4. **Хайлтын нүд**-нд үг үлдсэн бол арилга. Хайхдаа **гэрээний дугаараар** хай (лангуу, тоотын дугаараар биш).

**Үр дүн:** шүүлтүүдийг арилгасны дараа жагсаалтад бүх мөр гарч ирнэ. Мэдээлэл устаагүй.

Харагдахгүй хэвээр бол хуудсыг **F5**-аар шинэчил, эсвэл програмаас гараад дахин нэвтэр.

## Түгээмэл алдаа
- Сарын 1-нд жагсаалт «энэ сар»-аар шүүгддэг тул өмнөх сарын айл харагдахгүй болно → хугацааны шүүлтийг өмнөх сар болго ([Хугацаа зөв сонгох](./hugatsaa-songoh.md)).
- Хайлт хэсэгчлэн таарцаар хайдаг: «1234» гэж хайхад «551234», «901234» хамт гарч болно → бүтэн дугаараа шалга.
- Өөр owner (компани) сонгогдсон байвал тухайн компанийн гэрээ л харагдана.
