# Жагсаалт хоосон эсвэл айл «алга болсон» үед — шүүлтээ шалгах

## Энэ юунд хэрэгтэй
Гэрээ, нэхэмжлэх, хуулга, тоолуурын жагсаалтад байх ёстой айл харагдахгүй байвал ихэнхдээ өмнө нь тавьсан **шүүлт (filter)** эсвэл **хайлт** идэвхтэй үлдсэнээс болдог. Мэдээлэл устаагүй.

## Алхам
1. Жагсаалтын дээд мөрөнд **шүүлтийн тэмдэг (юүлүүр)** эсвэл баганын толгойд тавьсан шүүлт байгаа эсэхийг хар.
2. Хайлтын нүдэнд үг үлдсэн бол арилга.
3. Шүүлтийг **цэвэрлэх (✕)** товч дарж бүх мөрийг харуул.
4. Хайхдаа **гэрээний дугаараар** хай (лангуу/тоотын дугаар биш).
5. Харагдахгүй хэвээр бол хуудсыг **F5**-аар шинэчил, эсвэл програмаас гараад дахин нэвтэр.

## Түгээмэл алдаа
- Сарын 1-нд жагсаалт «энэ сар»-аар шүүгддэг тул өмнөх сарын айл харагдахгүй болно → хугацааны шүүлтийг өмнөх сар болго ([Хугацаа зөв сонгох](./hugatsaa-songoh.md)).
- Хайлт хэсэгчлэн таарцаар хайдаг: «1234» гэж хайхад «551234», «901234» хамт гарч болно → бүтэн дугаараа шалга.
- Өөр owner (компани) сонгогдсон байвал тухайн компанийн гэрээ л харагдана.
