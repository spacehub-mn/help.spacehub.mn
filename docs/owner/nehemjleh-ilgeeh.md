# Нэхэмжлэх үүсгэж илгээх

> 🏢 Эзэмшигч, менежер, нягтланд · Вэб (app.spacehub.mn)

> 🔄 **Гэрээ** → [Сарын тооцоо](/owner/sar-tootsoo) → **Нэхэмжлэх** → [Төлбөр ба хуулга](/owner/huulga-tolbor) → [Е-баримт](/owner/e-barimt)

## Энэ юунд хэрэгтэй
Нэхэмжлэх нь сарын төлбөрөөс үүсдэг. Харилцагч SMS, имэйл эсвэл аппын мэдэгдлээр хүлээн авч Qpay, Socialpay-аар төлнө. Нэг төлбөрт хэд хэдэн нэхэмжлэх байж болно, жишээ нь дүн өөрчлөгдөөд дахин илгээсэн үед.

Нэхэмжлэх үүсэхийн тулд эхлээд тухайн сарын төлбөр үүссэн байх ёстой: [Сарын тооцоо гаргах](./sar-tootsoo).

*Видео (дуугүй, хадмалтай). Нэхэмжлэх SMS-ээр илгээх.*

## Нэхэмжлэх үүсгэх
**Нэг төлбөрт:**
1. **Тооцоо → Төлбөр** цэсийг нээ.
2. Төлбөрөө сонго.
3. **Нэхэмжлэх +** товчийг дар.

**Олон төлбөрт нэг дор (дүнг шинэчилж):**
1. **Тооцоо → Төлбөр** жагсаалтаас төлбөрүүдээ сонго.
2. **Нэхэмжлэх шинэчилж илгээх** товчийг дар.
3. Нээгдэх цонхонд SMS явуулах сонголт анхдагчаар **унтраалттай** байна. Мессеж явуулах бол тэмдэглэ.
4. **Боловсруулах** дар.

Дүн өөрчлөгдсөн төлбөрт **шинэ** нэхэмжлэх үүснэ. Дүн өөрчлөгдөөгүй бол байгаа нэхэмжлэхийг дахин ашиглана. Хуучин нэхэмжлэхүүд хэвээр үлдэнэ. Бүрэн төлсөн, цуцалсан, гэрээгүй төлбөрийг алгасна.

## Илгээх

![Нэхэмжлэх илгээх: цэс, нэхэмжлэх сонгох, SMS / имэйл / мэдэгдэл](/img/owner/nehemjleh-ilgeeh.webp)

*Зураг 1. Нэхэмжлэх илгээх: цэс, нэхэмжлэх сонгох, SMS / имэйл / мэдэгдэл.* Улаан дугаар = доорх алхмын дугаар. Дарвал томорно.

1. **Тооцоо → Нэхэмжлэх** цэсийг нээ.
2. Илгээх нэхэмжлэхүүдээ сонго. Нэг юм уу олныг сонгож болно.
3. Сувгаа сонго:
   - **SMS илгээх** — нэхэмжлэх дээрх утас руу мессежээр. **Жирийн** эсвэл **Төлөөгүй** гэсэн хоёр сонголттой.
   - **Имэйл илгээх** — имэйлээр. Нэг нэг нэхэмжлэхээр (**Имэйл илгээх**) эсвэл багцаар (**Имэйл багц илгээх**) явуулна.
   - **Мэдэгдэл** — Spacehub аппын мэдэгдлээр.

![SMS илгээхийн өмнөх асуулт: сонгосон нэхэмжлэхийн тоо](/img/owner/nehemjleh-dialog-sms.webp)

*Зураг 2. Илгээхийн өмнөх асуулт.* Улаан дугаар = доорх алхмын дугаар. Дарвал томорно.

4. Асуултад **сонгосон нэхэмжлэхийн тоо** гарна. Тоо зөв бол «**Тийм**», буруу бол «**Үгүй**» дар.
5. Дуусахад хэд илгээгдсэн, хэд алгассаныг харуулна. Утасгүй эсвэл имэйлгүй нэхэмжлэх алгасагдана.

Харилцагч өөр дугаар руу явуулахыг хүсвэл нэг нэхэмжлэх сонгоод **Өөр дугаар руу илгээх** товчоор дугаараа оруулна.

## Хэвлэх
- **Хэвлэх** — сонгосон нэхэмжлэхийг хэвлэнэ.
- **Багц хэвлэх** — олон нэхэмжлэхийг нэг багцаар хэвлэнэ.

## Төлсөн эсэхийг харах
**Тооцоо → Нэхэмжлэх** жагсаалтын **Төлөлт** баганын өнгө:
- **Ногоон** — бүрэн төлсөн.
- **Улбар шар** — дутуу төлсөн.
- **Улаан** — төлөөгүй.

**Илгээлт** баганаас нэхэмжлэх очсон эсэхийг харна. Төлсөн айл «Төлөөгүй» хэвээр харагдвал нэхэмжлэхүүдээ сонгоод **Төлөв шалгах** дар — энэ нь **төлбөрийн төлвийг** үлдэгдлээр шинэчилнэ (Илгээлтийг биш).

## Анхаарах
- Нэг төлбөрийн нэхэмжлэхээр өнөөдөр SMS явсан бол дахин илгээхгүй («өнөөдөр аль хэдийн илгээсэн»). Төлөгдсөн нэхэмжлэх, суурин утас, доод дүнгээс бага нэхэмжлэхийг мөн алгасна.
- Олон нэхэмжлэх сонгохдоо шүүлтээ шалга. Буруу сар эсвэл бүх объект сонгогдсон байвал хүсээгүй хүмүүст мессеж очно: [Хугацаа зөв сонгох](./hugatsaa-songoh).
- Е-баримтыг нэхэмжлэх дээрээс биш **төлөлт** дээрээс гаргана.
- Төлөх хугацаа хэтэрсэн нэхэмжлэхийг автоматаар дахин явуулах тохиргоо **Тооцоо → Нэхэмжлэх → Нэхэмжлэх дахиж явуулах тохиргоо** дотор байна.

## Түгээмэл асуулт
**Харилцагч нэхэмжлэх ирээгүй гэж байна.**
**Илгээлт** баганыг хар. Илгээсэн бол дугаар нь зөв эсэхийг гэрээн дээрээс шалга. Шаардлагатай бол **Өөр дугаар руу илгээх**-ээр явуул.

**Дүн өөрчлөгдсөн, нэхэмжлэхийг яаж шинэчлэх вэ?**
**Тооцоо → Төлбөр**-өөс төлбөрөө сонгоод **Нэхэмжлэх шинэчилж илгээх** дар.

**Нэхэмжлэх жагсаалт хоосон байна.**
Шүүлт эсвэл хугацаагаа шалга: [Жагсаалт хоосон үед](./jagsaalt-hooson-shuult).
