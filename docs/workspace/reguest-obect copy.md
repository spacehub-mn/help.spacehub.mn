> 🏠 Түрээслэгч, оршин суугч · Гар утасны апп

:::info
Видео заавар шинэчлэгдэж байна.
:::

1. **Ажлын орчин** хэсэг дээр дарах. Орон сууцны бүртгэлд энэ хэсэг **Консьерж үйлчилгээ** гэж харагдана.
2. Түрээслэх хүсэлт илгээх гэж буй талбай дээр дарах.
3. **Санал тавих** товч дээр дарах.
4. Шаардлагатай мэдээллүүдийг бөглөх.
5. **Хүсэлт илгээх** товч дарах.
