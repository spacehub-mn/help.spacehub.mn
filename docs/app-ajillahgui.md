# Апп ажиллахгүй үед

> 🏠 Түрээслэгч, оршин суугч · Гар утасны апп — 🏢 эзэмшигч, менежер ч хэрэглэнэ

Аппад нэвтэрч чадахгүй, нэхэмжлэх нээгдэхгүй, «**200: Алдаа гарлаа**» гэх мэт мессеж гарвал доорх дарааллаар шалга.

## Түрээслэгч өөрөө шалгах
![Аппын шинэчлэлтийн асуулт: Шинэчлэх](/img/app-ajillahgui-1.webp)

*Зураг 1. Апп нээхэд шинэ хувилбар гарсныг мэдэгдэнэ. Улаан дугаар = алхмын дугаар.*

1. **Аппаа шинэчил.** App Store / Google Play-ээс Spacehub аппын **хамгийн сүүлийн хувилбарыг** суулга. Хуучин хувилбар хуучин серверт ханддаг тул алдаа гарч, төлбөрийн төлвийг буруу харуулж болно. Ялангуяа **Нэхэмжлэл табыг нээхэд «200: Алдаа гарлаа»** гарвал ихэвчлэн хуучин хувилбараас болдог. Шинэчилсний дараа ч гарсаар байвал байгууллагадаа мэдэгдэ.
2. Аппаас **гараад дахин нэвтэр**. Нэвтрэх нэр нь **утасны дугаар**.
3. Интернэт холболтоо шалга.
4. Болохгүй бол **дэлгэцийн зураг**-тай байгууллагадаа (СӨХ, түрээслүүлэгч) хандана.

## Эзэмшигч, менежер шалгах (вэб)
Айлаас «апп ажиллахгүй» гэж ирвэл:
1. **Менежмент → Харилцагч → Хэрэглэгч** — тэр айлын хэрэглэгч байгаа эсэх, **Нэвтрэх эрх** багана «Идэвхтэй» эсэх. Олдохгүй бол шүүлтийг **«Идэвхгүй»** болго. «Хаагдсан» бол мөрөө сонгоод **«Идэвхжүүлэх»**. → [Хэрэглэгч](/owner/list/User_ListView)
2. Хэрэглэгчийн **утас** зөв эсэх. Нэвтрэх нэр нь утас. Нууц үгээ мартсан бол «Эрх илгээх».
3. **Харилцагч** дээр хэрэглэгч холбогдоогүй бол «Хэрэглэгч мэдээлэл ...». → [Харилцагч](/owner/list/Customer_ListView)
4. **Гэрээ** идэвхтэй (хаагдаагүй) эсэх. Хаагдсан гэрээний мэдээлэл аппад харагдахгүй байж болно ❔. → [Гэрээ](/owner/list/Contract_ListView)
5. Айл аппаа **шинэчилсэн** эсэхийг асуу.
6. Бүгд зөв атал алдаа гарсаар байвал **айлын утас, гэрээний дугаар, дэлгэцийн зураг**-тай Spacehub-д мэдэгдэ. Апп шинэчилсэн ч «200» гарсаар байвал энэ нь апп талын алдаа байж магадгүй.

## Түгээмэл асуулт
- **Аппад зарим тоот харагдахгүй.** Тэр тоотын гэрээ тухайн хэрэглэгчийн харилцагчид холбогдсон эсэхийг шалга. Нэг хүн хэд хэдэн гэрээтэй бол аппад «Гэрээ сонгох»-оор солино. → [Гэрээ сонгох](/account/change-contract)
- **Төлсөн боловч аппад «төлөөгүй» харагдаж байна.** Аппаа шинэчил. Вэб дээр төлбөр «төлсөн» эсэхийг шалга. → [Төлбөр → Нэхэмжлэх → Төлөлт](/owner/concepts/tootsoo-nehemjleh-toloh)
- **Утасны дугаар солигдсон.** → [Бүртгэлтэй утасны дугаар солих](/account/change-number)
