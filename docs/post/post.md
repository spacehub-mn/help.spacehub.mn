# Бизнес зар оруулах

> 🏠 Түрээслэгч, оршин суугч · Гар утасны апп

:::caution
Дэлгэцийн зураг шинэчлэгдэж байна.
:::

## Энэ юу вэ
Объект доторх бусад хүмүүст зориулж зар, мэдээ нийтэлнэ.

## Хэзээ хэрэглэх
- Өөрийн бизнесийн бараа, үйлчилгээг сурталчлах үед.
- Объектын оршин суугчдад мэдээлэл түгээх үед.

## Алхам
1. Аппын доод цэснээс **Бизнес зар**-ыг сонгоно. Орон сууцанд энэ хэсэг **Мэдээ** гэж харагдана.
2. Доод баруун буланд байгаа **+** товчийг дарна. **Шинэ зар** цонх нээгдэнэ.
3. Зарын текстээ бичнэ (300 тэмдэгт хүртэл).
4. Шаардлагатай бол **Ангилал нэмэх**, зураг, **Хавсралтууд**-ыг нэмнэ.
5. **Нийтлэх** товчийг дарна.
6. Хэд хэдэн объекттой бол **Объект сонгох** цонхноос объектоо сонгоно.

## ⚠️ Анхаар
- Таны зар сонгосон объектын оршин суугчид болон эзэмшигчид харагдана.
